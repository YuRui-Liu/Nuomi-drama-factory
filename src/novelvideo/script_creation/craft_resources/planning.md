# 架构与规划

大纲：从核心欲望、恐惧及关系矛盾形成主线。主题与反命题由人物的不同选择体现；终局回应开端的难题。
人物：区分 Want（当下想得到什么）与 Need（必须面对或改变什么），标明行为弱点、核心关系和压力下的选择。配角有自己的诉求，而非轮流替主角解释世界。
语言指纹来自身份经历、对关系的态度和惯用策略，不能只换口头禅。角色掌握的信息必须有来源；特殊优势说明代价、边界和可被反制之处。
分集：以已确定人物目标组织阻力、行动、后果，说明策略改变如何导致下一事件；写清本集观众得到的阶段回报及下一步期待。终集允许收束。
场景：空间与规则为选择提供机会和限制。道具说明持有、使用及状态变化，不能事后凭空提供解决方案。规划中的首次出现不得冒充已写出场。
