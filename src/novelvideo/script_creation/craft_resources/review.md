# 独立结构审查

按全文实际场景逐一覆盖因果、动机、代价、关系、情绪积累、连续性和简报风格。先定位原文再解释叙事影响，不能用抽象的“不够精彩”作阻断结论。
先把用户明确的内容要求逐项映射到原文：人物核心矛盾是否真的改变了行为，目标时长是否容纳全部对白及动作，本集建立的期待是否获得具体变化。明确要求落空应给上下文双方证据，不得因格式正确或没有事实冲突就通过。审查写作任务的完成程度，而非只查错字和道具。
人物选择的后果可以是信任、关系、时间或资源变化，不要求危险行动；不要把“必须冒险”“每场必须冲突”等新要求强加给用户。能指出具体策略、回应和后果即可，口头争论也可能产生真实关系变化；分辨已发生的变化与仅宣称发生的变化。
提出缺失结论之前搜索全文，确认该信息没有已在前文动作或对白中出现；道具正常携带无需机械补一次拿起动作。核对广播等声音是在被听见还是被角色说出，防止把声音效果误写成播报台词。
重点检查关键选择有没有前因、代价能否影响人物、冲突是否被巧合或新规则轻易消解、人物是否知道其尚未获得的信息。
跨文档矛盾给出草稿和输入双方证据，区分推测与确证、候选计划与正文事实。信息不足应说明边界，不能捏造设定。
保留有效设计并给出原文依据。风格争议归建议；事实冲突、必要因果缺失、动机断裂和信息越界才可能阻断。缺失项引用受影响场景并说明缺少的功能。
复查不仅确认旧问题是否解决，还检查修订是否产生新问题。最终复查重点检查对白整合是否改变事实、目标、结果或用户限定范围。
