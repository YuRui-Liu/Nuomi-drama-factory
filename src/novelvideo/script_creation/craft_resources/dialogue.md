# 台词诊断与整合

逐场读完对白，判断每句话对谁说、想让对方做什么、为什么此刻说，以及对方的回应如何改变策略。
从角色经历、关系和压力下的表达方式判断声音是否可辨；潜台词是言说策略与真实目的之间的关系，不是人人都含糊其辞。
检查解释腔、双方已知信息的重复告知、超越人物知识范围的判断，以及能否由行动自然承载的信息。直白表达、重复、长句和沉默都须结合实际功能判断，不能机械删除。
有问题时给出原句、目的、修改目标或建议替换及理由；朗读检验自然度。不要为了金句牺牲人物立场，也不要强加停顿或固定小动作。
整合只处理有效阻断问题及必要相邻动作，保留场次、事实、人物目标和情节结果；越出范围的依赖留作待决定问题。
