# 场景写作

进入场景前确定人物要什么、谁或什么阻碍、失败将付出什么。把“人物发现问题”推进到“人物采取行动并承担后果”；给对手及配角真实的拒绝或交换条件。
改写已有剧本时，保留已确定事实不等于复述旧稿的动作顺序和对白。先找出原稿未进入戏的核心人物矛盾：角色设定里的弱点必须影响当场判断、策略或关系，不能用一句正确态度把矛盾提前化解。把本集希望观众期待什么、在哪里得到具体变化写入 scene_intents；正文用事件兑现，不写分析。
先在 scene_intents 设计因果骨架，再写正文：眼前目标 → 人物依据有限信息采取的策略 → 对方出于自身需求的回应 → 主角必须作出的取舍 → 可见后果 → 下一场为何发生。每项写本故事具体的人、物和行动，不写“制造冲突”“突出人设”等功能标签。不需要强行让每场具有同一结构，但本集主要矛盾必须完成可辨认的推进。
让人物弱点成为行动的原因，而非告白。例如“我太想相信了”只是总结；抢先承诺一项尚无依据的结果、拿公共资源换私人机会、为保住面子隐瞒关键限制，才会迫使别人回应。这些仅是机制示意，不要求故事照搬；取舍的代价可以是信任、时间、关系或资源，不必新增暴力、大事故和反派。错误行动必须实际发生并留下后果，不能让断电、电话或巧合在选择发生前替主角解围。
修订先重建问题所在的行动链，不要只增加“我不能把猜测当事实”之类说理对白。角色回到核实，应来自证据、他人反击或其行为后果，而不是作者让他突然变得正确。保留有效场景，避免为修一处问题无关扩写整集。
依用户时长分配场景任务。估算对白朗读与动作所需时间，为沉默、移动和反应留余量；超长时删去重复信息和同功能轮次，不靠快语速硬塞。不把估算时长宣称为已排演验证。
场景之间用行动后果连接，避免仅靠时间顺序串联。检查目标、策略、关系、资源、知识中哪些状态发生变化；安静场景可以承担消化后果或改变理解的作用。
阶段回报应回应此前建立的期待，让人物选择带来可感知的结果、关系变化或新的理解；有意识延迟回报时，交代阻力及延迟造成的代价，保留观众继续期待的具体依据，不设固定回报配额。
情绪通过期待、选择及结果积累，不能靠形容词宣告。反转重新解释已出现的信息，保留观众回看时能理解的依据，而非临时改规则。
每场检查谁知道什么、从哪里知道、何时知道。人物怀疑不能直接变成客观事实；续写继承位置、资源、关系和未解决问题。
对白是人物对彼此采取的行动。需要解释时让解释服务说话者眼前的目的，允许反驳、隐瞒或误解改变信息效果。
正文仅保留场次、动作、对白及必要表演提示；创作意图独立记录，不能以自评分数替代审稿。
