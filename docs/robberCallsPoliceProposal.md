# 《劫匪先报了警》创作提案 v1

状态：新作品候选，不覆盖《别开门》，未采用、未进入媒体制作。暂沿用六集、每集约两分钟；以下题材、画风、人物和情节均为本轮原创提案。第一集是用于判断观看兴趣的试读稿，时长尚未实测。

## 一句话故事

一个接到“金店防抢演习”兼职的临时演员，举着漏水的道具枪进店，却被柜员拉住：“先别演了，帮我拦住你们导演。”他这才发现，付钱雇他的人正提着店里的真黄金往外走，而自己是准备留给警察的劫匪。

故事围绕三个人、一个营业厅和一只装货箱展开。主角发现被骗后立即报警，不靠“为什么不报警”拖戏。等待警方到场的这段时间，三人争夺的是能说明事情原委的货物、证据与合作关系。

## 观看体验与画风

现代都市悬疑轻喜剧。危险是真实的，笑点来自阿程认真做一份荒唐兼职，以及三个人各自急迫、互不相同的需求，不用插科打诨消解危险。

建议采用二维赛璐璐漫画：清楚的线条、利落的明暗分区、可辨认的表情；金店冷白灯、红色促销牌、黄色外套形成鲜明色块。避免整片灰蓝夜景、写实人脸慢慢微动和连续面部特写。人物动作改变构图：柜台两侧、出口、货箱的位置始终让观众看得懂。

节奏以事件推进：进店表演 → 发现穿帮 → 货箱露馅 → 主动报警 → 拦住雇主。反应镜头服务决定，不把每次抬眼、移灯、看纸单独拉满一段视频。两分钟是目标，不为凑时长拉长停顿；H3 的片段长度不决定剪辑点。

## 核心人物

- **阿程，26 岁，临时演员。** 穿借来的黄色外套，刚收到三百元定金，做完还有一千七。他愿意认真完成工作，也怕得罪给工作的人。识破骗局后仍然害怕，但会拿自己的手机报警、挡住出口；不能写成突然精通刑侦的高手。
- **周宁，29 岁，金店柜员。** 闭店盘货时发现货物被转走，拒绝在虚假的交接单上签字。手机被店长拿走，她此前无法离开。阿程进店让店长分神，给了她争取帮助的机会。她知道账目，但不知道店长安排演员的完整计划。
- **罗启，40 岁，店长，也是阿程口中的“导演”。** 挪走店内代售首饰，打算把盘亏伪装成抢劫。以补发工资、追究失误和兼职尾款分别操纵两人。其计划依赖两人互不认识、听从安排；一旦合作，他就改用抢夺与威胁，不凭空增加同伙或超能力。

核心冲突：阿程想证明自己不是劫匪；周宁想保住货物并说清账目；罗启想带走货箱、让另外两人互相指认。

## 六集因果走向

| 集 | 当集行动与回报 | 如何推动下一集 |
|---|---|---|
| 1《枪漏了》 | 假演习被识破。阿程报警并主动挡住雇主，观众当集知道骗局是什么。 | 罗启退回店内，三人围着出口与货箱对峙。 |
| 2《谁签的字》 | 罗启指责周宁早已签收货物；她拿出当天盘点差额，说明自己拒签的是哪一笔。阿程把现场情况告诉接警员，不再听雇主指挥。 | 旧交接单确有周宁签名，她不得不解释此前替店长补签的记录，两人的信任出现裂口。 |
| 3《她也撒了谎》 | 周宁承认怕失业而补签过没有亲眼核过的货，但把今天拒签、追查差额的经过说清。阿程也交出自己的雇佣聊天，承认拿了钱。两人停止互相装无辜，决定把两份证据一起留下。 | 罗启无法再靠互相指认脱身，提出用货箱换手机和两人离开。 |
| 4《这回真演》 | 阿程假意接受，利用罗启仍把自己当听话演员的判断，配合周宁把货箱留在柜台内。表演能力第一次真正改变局面，不靠万能打斗。 | 罗启察觉货箱没跟上，扯住阿程的外套，争夺从话术变成身体阻拦。 |
| 5《别追箱子》 | 罗启推翻柜台边的货箱制造混乱。阿程放弃追逐滚落的首饰，先拉开被压住手臂的周宁；她利用柜台门挡住出口。两人的合作经受代价，不用反复假背叛。 | 货物散在现场、出口仍被堵住，罗启再也不能带着箱子从容离开；门外传来警方到场的声音。 |
| 6《演出结束》 | 阿程放下道具、举起空手，周宁说明谁拿过什么、签过什么。现场货物、聊天和账目交给警方调查。罗启被控制；周宁也如实交代补签，不靠一段喊话洗清所有责任。 | 事件闭合。阿程收到另一条“高薪临演”的消息，先追问拍摄地点、联系人和工作内容，没有立刻点接单。结尾留人物变化，不再强塞新凶手。 |

## 第一集试读：《枪漏了》

### 外／内 · 金店门口至营业厅 · 傍晚

△ 门上挂着“暂停营业”。阿程隔着玻璃看了眼手机。

△ 聊天最后一条：“防抢演习。员工知情。照词演，别真碰人。”下面是三百元转账。

△ 他收起手机，拉好黄色外套，推门进去。柜员周宁站在柜台内，罗启提着一只黑色货箱，正在出口旁。

阿程（努力压低嗓子）：都别动！抢劫！

△ 他举起道具枪。枪口落下一滴水，砸在玻璃柜台上。

△ 周宁看一眼水滴，再看罗启。罗启朝阿程小幅摆手，示意他继续，自己把货箱往身后藏。

周宁：枪漏了。

△ 阿程赶紧用拇指堵住枪口，嗓子一下恢复正常。

阿程：刚才还好好的……不好意思，重来。

△ 罗启已经拉开门。

周宁（指向他）：先别重来。把他拦住。

阿程：他是导演。

周宁：这里没摄影机。

△ 阿程看向罗启。罗启不接话，只把门拉得更开。

罗启：隐藏拍摄。别看我，接着演！

△ 周宁跨出柜台，抓住货箱提手。罗启猛地往外抽。箱扣挂住门框，箱子侧翻；一只首饰托盘滑出，金镯滚到阿程鞋边。

△ 阿程本能地弯腰捡。周宁没有去抢镯子，仍死死抓住箱子。

周宁：我们店的货。下午还在柜里。

罗启：道具！阿程，拿上，跟我走。

△ 阿程一手拿着镯子，一手拿着漏水的枪。看看罗启手里的箱子，又回头看空了一排的展示柜。

阿程：你不是说，员工都知道吗？

周宁：我只知道，他让我在空账上签字。我没签。

△ 罗启把货箱放回地上，松开提手，语气缓下来。

罗启：一千七我现在转。你先出去。

△ 阿程掏出手机。罗启以为他要收款，伸手替他拉门。

△ 手机显示正在拨打 110。

阿程：我要报警。我在金盛珠宝店……我拿的是水枪。

△ 罗启伸手抢手机。阿程向后一缩，第一次没有听他的安排。

阿程（对电话，急）：不是开玩笑！有人让我演抢劫，他正往外搬东西！

△ 罗启推门。阿程用肩膀顶住，手机开着免提。周宁把滑出的托盘拖回柜台旁，腾出手拉上门。

罗启（盯着阿程）：你还想不想拿钱？

△ 阿程看着他，手中的道具枪还在滴水。

阿程：想。你先别走。

△ 罗启看看门，又看看周宁，慢慢将货箱拖回脚边。

△ 金镯仍握在阿程手里。三个人隔着箱子，谁也不再说这是演习。

切黑。

## 本轮自查与边界

- 开场的演习聊天解释阿程为何持道具进店；周宁指出现场异常、货箱掉落以及罗启急付尾款，逐步促成阿程改变态度，不让他瞬间知道全部真相。
- 第一次骗局在第一集内揭示，且阿程主动报警。后续压力来自保住现场与相互信任，不靠藏着不说或禁止报警延长故事。
- 第三集的旧签字不是突然证明周宁是幕后主谋，而是她必须承担的小过错；最终不能写成警方只听主角一面之词就当场结案。
- 试读约两分钟，需按对白与动作实际表演校时；若偏长，先压缩重复反应，不删除报警和主动拦人的决定。
- 第四至第五集的具体身体调度尚需在正文中写清。分集走向是候选，不能据此直接生成分镜或视频。
- 画风仅是新方向建议，尚无视觉样张；不宣称已得到用户采用或观众验证。
