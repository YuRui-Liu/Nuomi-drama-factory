# 轻量单集链路实现核验

日期：2026-10-18。分支：feat/canvas。范围：已批准原型 17–23 的现有节点整合。

## 已实现

单集剧本直接生成现有分镜表；“制作宫格图”只提交缺失或变化的叙事组。宫格成功后将结果留在原节点，自动连接现有 MiniMax 导演台、准备拆分图，再连接现有视频组装。自动准备不提交视频生成请求。

默认菜单只展示单集剧本、分镜表、叙事组宫格、MiniMax 导演台、视频组装。资产和音频等自由工具折叠。旧画布节点保留读取兼容，新链路不创建旧导演管理／整集运行图。删除默认采用、交接门槛，审阅与连续性检查折叠。

本集资产补充按原文证据匹配基础和已存在的稳定变体；缺图就地提示并打开现有图像节点。撤销解除所属补充记录的自动连线，保留媒体和手动连线。生成变体仅将基础图用于生成上下文，不冒充变体结果。角色声音一键使用后创建／打开对应配音节点；外部配音仍可直接进入组装。

异步结果核对启动时输入；修改中的分镜不被旧结果覆盖。宫格的输出比例不冒充输入变化。预检同步占用生成状态，重复点击不重复提交；来源过期或缺少静态描述会释放状态。自动资产连线随来源删除同步移除，保留手动引用。
