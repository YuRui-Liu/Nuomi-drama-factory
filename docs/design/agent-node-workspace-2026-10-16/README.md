## 使用路径

U01 选中分镜 → U02 选择专家 → U08 查看五项配置与委托范围 → U03 专家执行并回传内容。修改人物状态时查看 U04；整集任务在 U09 追踪，交付在 U05 预览。U06／U07 是同一布局在紧凑视口的状态，不是额外业务页面。

这些箭头说明预期交互，不表示 Pen 已建立可点击跳转。当前交付是可编辑的状态设计；按钮未连接业务、状态和金额均为示例，播放器为明确占位，无真实影片。新稿无需重新确认已经批准的产品方向，只需审阅视觉与信息组织。
