### Agent 可执行路径

专业目录现有 **22 个岗位**，新增台词专家；既有配置引用保留历史版本，新能力通过新岗位修订发布。岗位配置不自动授予执行权限。

- 剧本：`inspect / review / rewrite` 使用固定集、文档及修订，改写返回待审提案。
- 导演：`preview_handoff / inspect / prepare / save_blocking / compile_blocking / edit_shot / edit_structure`。
- 整组制作：`render_groups / retry_render_groups / produce / retry_production` 复用正式组生产入口，不自行按镜头循环调用供应商。
- 声音：`prepare_design / design`、`prepare_dubbing / generate_dubbing / group_dubbing / audition`；专业参数使用受限叶子字段写入。
- 剪辑：允许编辑既有片段时序、音量、速度和字幕；不允许 Agent 用任意 URL 替换媒体身份或伪造 take 来源。
- 采用剧本、导演、声音及配音结果仍走真实用户契约。未知提交窗口保持 unknown，不通过重放隐式重复生产。

判定口径：

- 已接通：有界面／注册操作、服务和持久结果的对应路径；不代表真实供应商验收完成。
- 部分实现：有可用基础，但与已批准交互或执行合同存在差距。
- 未接通：在核对的产品路径中没有找到要求的完整操作。
- 未真测：实现或测试存在，但没有本次 E01 的真实产物证据。

## 5. Agent 可执行性

已有专业岗位目录不等于每项专业操作已注册。核对的新增节点能力表与适配器为：

| 已注册路径 | 边界 |
| --- | --- |
| `ideationNode.generate` | 生成立意候选 |
| `screenplayNode.plan` | 启动规划；不能代表完整的确认、正文改写和审稿 Agent 操作全集 |
| `directorWorkspaceNode.prepare` | 导演准备；不能代表场景调度／灯光／表情的版本编辑和融合操作全集 |
| `directorWorkspaceNode.save_blocking / compile_blocking / edit_shot` | 续作新增受限专业内容操作：绑定集／导演修订／场景／组／镜头，保存调度或创建候选，不采用、不生成媒体；已通过边界复核 |
| `characterVoiceNode.design` | 生成声音候选；采用保留真实人工契约 |
| `characterVoiceNode.prepare_design` | 本地编译声音设计预览；生成必须核对冻结输入与当前角色事实 |
| `audioNode.prepare_dubbing / generate_dubbing` | 独立持久准备与读取固定准备生成，不在 generate 中重新准备；已通过边界复核 |
| `audioNode.group_dubbing` | 按组范围准备并生成配音；不是独立 prepare/adopt/时间线替换合同全集 |
| `narrativeGroupStoryboardNode.validate` | 仅校验引用结构并输出 JSON，不证明对应导演修订和组存在；实际内容由固定版本接口读取 |

证据：`freezone/orchestration/capabilities.py`，`adapters/production.py`、`voice.py`、`dubbing.py`。旧节点及普通媒体操作仍存在，不能据此说 Agent 完全不可执行；也不能把通用画布数据 patch 当成专业内容版本服务已经接通。

交叉核对：续作在 `creation/node_execution.py` 增加严格的 `directorOperationInputs` 白名单，输入仍参与过期检测；真正写入通过专业版本服务，不以任意 `node.patch` 冒充业务写入。配音采用仍保留在真实用户路径中。目录和适配器测试覆盖具体注册操作，不能代表所有 PRD 专业能力已实现。

导演写操作使用持久 attempt journal：完成回执可恢复；内容已写入但完成回执未落盘时保守保持 unknown，不自动重放，需要人工诊断。该方案尚不提供内容存储与回执的跨存储原子事务。

组节点只对任务 metadata 明确绑定同修订、同单组的任务提供停止操作；范围未知或跨组任务回导演工作空间管理，本轮未补齐后端任务 metadata。已有视频入画布使用 `contextLink` 来源关系，不增加执行依赖。采用导演候选会失效同集方案及媒体缓存；无效集号不会回落到 E01。

声音新增操作可执行节点中已配置的声音／对白输入；通用 Agent `node.patch` 当前没有开放 `voiceDescription`、结构化声线及逐句表演参数的专业写入白名单。因此，“Agent 自主编写并修改全部声音设计参数”仍有缺口，不能由 prepare/generate 注册完成推定已具备。

`creation/professional_agents.py` 有创意、主笔、导演、分镜、站位、摄影、灯光、动作、表情、MiniMax 执行及声音等岗位。续作新增音色设计师、配音导演、配音执行师，目录共 21 个岗位；导演及六个相关专业岗位增加内容操作 v2，保留 v1 来源可解析。操作适配器的接通状态须以联合验证后更新的上表为准，角色配置本身不授予执行权限。采用继续保留真实用户授权，不为补 Agent 路由伪造人工 actor。
