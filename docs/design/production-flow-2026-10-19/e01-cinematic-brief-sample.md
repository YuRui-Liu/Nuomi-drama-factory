# 第 3 镜 · 导演样本（无付费）

用于验收“导演层”是否达标；通过后才批量重写 14 镜并重出。

## 旧版问题

旧 prompt 是元数据清单：count/shot/axis/blocking/lighting/performance 各一行。它告诉模型“有 3 个人、机位在东侧”，但没有告诉它：

- 这镜的戏眼是“威胁从林渡转移到幸存者”；
- 前 2 秒观众该看到什么；
- 丧尸怎么迈步、哪条腿拖、头晚多久转；
- 林渡的手放在哪、呼吸几次；
- 幸存者的重心和手指在做什么；
- 镜头为什么不动。

结果就是：三个人各站各的、丧尸齐步走、场景像拼贴。

## 新版导演 brief

    GEO (locked): 南北向主干道；东侧街角+灰护栏；西侧废车与碎片；北端坍塌高架封路；
    主光左前上方 5200K，影子落向右后；机位始终在道路东侧路缘，不越轴。

    镜头任务: 威胁从林渡身上转移到街角幸存者；观众在 2 秒内看懂“丧尸绕过林渡，去追背包的人”。

    首 2 秒: 丧尸的左腿先承重、右靴拖过沥青，躯干先转向街角；林渡的护喉手放下半寸，视线跟着丧尸的肩线走。

    节拍:
    0.0–1.0s 林渡侧身站在画面中央偏左，肩胛下沉，呼吸压低；背景 3–5 名感染者分散游荡，不同步、不同朝向。
    1.0–2.2s 丧尸左腿承重、右靴拖地，躯干先转，头晚半拍才转向街角；右手没有伸向林渡，肘先抬后垂。
    2.2–3.8s 幸存者脚跟蹭地后退，背包带被攥紧，膝盖内扣；丧尸绕过林渡肩侧，路线从画面左前景切向右侧街角；林渡侧身让开半步，没有接触。
    3.8–5.0s 丧尸继续压向幸存者，身体前冲半拍后停住；幸存者退到护栏边，背包贴胸；林渡留在两人之间，视线跟随丧尸路线，呼吸一次。

    表演: 林渡不伸手、不喊，恐惧在肩胛和呼吸；丧尸关节迟滞、手指不抓、视线锁定后不立刻伸手；幸存者的恐惧在手指和膝盖，不喊叫。

    运镜: Static Shot，机位在道路东侧路缘，平视中景；不 Pan、不 Push，靠人物在画面内的位移完成威胁转移。

    光: 5200K 左前上方主光，6500K 天空补光；影子落向右后；曝光优先背包轮廓与丧尸路线。

    声音: 风声、远处金属轻响、拖步擦沥青、背包带摩擦、三个人的呼吸；无配乐。

    连续性: 屏幕方向始终左→右；护栏在东侧；林渡不出画；结尾姿态可接第 4 镜“幸存者转身跑”。

## 与 H3 的对应

- GEO、首2秒、节拍、表演、运镜、连续性 → detailed_description；
- 风声/拖步/呼吸 → overall_soundscape；
- 无台词、无配乐 → non_diegetic_music = N/A。

## 验收点

- [ ] 首 2 秒有明确视觉事件（丧尸转向 + 拖步）；
- [ ] 丧尸运动有重量、延迟、非同步；
- [ ] 林渡有“不伸手”的主动表演；
- [ ] 幸存者有重心与手指细节；
- [ ] 机位/屏幕方向/轴线全程一致；
- [ ] 没有“缓缓推进”式空开场。
