# 现有节点上的项目机组协作

日期：2026-10-17。状态：交互规则已由用户逐项确认；本轮 Pencil 视觉稿待审阅。源文件：[nuomi.pen](E:/Proj/nuomi.pen)。[七页 PDF](export.pdf)。本稿替代 U 系列中该场景的通用内容卡片表达，不意味着整套界面已获批准。

## 已确认规则

- 项目机组持续存在，保留角色配置和创作上下文，按任务调度必要成员；也支持单独委托专家。
- 主创负责目标、预算、进度与交付；导演协调专业方案和冲突；专业成员直接调用其授权范围内的已有节点能力。
- 节点显示机组任务和当前执行成员；共享任务记录展示各成员修改、输入输出版本与交接，并可定位关联节点。成员配置、任务参与成员和实际执行记录分别保存，不能把待命成员误报为已执行。
- 委托绑定现有内容节点，Agent 状态依附节点；跨节点委托共用任务记录，不创建独立专业 Agent 内容节点。
- 授权覆盖时直接调整和执行；超出预算、范围才确认。
- 执行范围来自委托目标，依赖连线不构成执行授权。
- 通过本次必要检查的新结果自动采用，旧版本保留；下游锁定实际使用的版本。

## 现有代码依据与新增边界

- `frontend/src/features/canvas/nodes/StoryboardGenNode.tsx`：浮动标题、排版、首尾帧配对、叙事目标、逐镜导演设计、实际请求预览、模型参数、生成及两侧端口。
- `frontend/src/features/canvas/nodes/StaticPanelEditor.tsx`：`frames[].static_panel.lighting`（当前光线），同时包含构图、场景、人物位置及引用等字段。灯光师修改指定镜头的真实字段，而非只在聊天里描述。
- 本例明确采用叙事组路径，通过 `startCanvasRun` 执行。普通网格生成会创建下游 `exportImage` 结果节点，不能套用本例的产物落点。
- `frontend/src/features/canvas/nodes/VideoNode.tsx`：引用、生成模式、参数、预览及生成历史。此处只展开与当前委托相关信息。
- 新增待实现：专业委托绑定、节点 Agent 状态、跨节点任务定位、专业字段修改记录、叙事组结果版本比较与恢复、按目标推进下游。图中出现不代表已接通后端。
- 本体语义关系与执行依赖分开。此稿连线只表达节点输入依赖；字段版本变化用于计算影响，不把所有语义关系都画成生成连线。

## 交互细节

项目机组目录从画布机组入口或任务成员入口打开，关闭后恢复原选择和视图。目录的“待命”表示本任务未调用，不表示节点能力不可用；可执行性须单独根据实际接入、模型配置和授权判断。角色目录涵盖创意、主笔、编辑、导演、分镜、站位、摄影、灯光、动作、表情、美术资产、连续性、分镜图执行、MiniMax 执行、声音、剪辑、交付检查和主创统筹。

共享任务记录只收录实际参与成员。每项贡献关联稳定节点身份、输入版本、字段差异、结果版本和执行回执；选择“定位”聚焦原节点，不复制内容。完整记录可展开，图中 01–04 是本任务发生的事件，不构成所有任务的固定阶段。目录与记录是覆盖在同一画布上的按需面板，不新增阶段页面。

保留原节点编辑能力；点击状态展开本次委托。运行时禁用重复生成，手工修改须与冻结的执行输入版本区分；运行结束不得无条件覆盖较新的用户编辑，版本冲突保留结果并提示处理。比较只是预览，恢复旧版才改变当前采用版本，并重新计算下游影响。停止后续执行不能声称已经取消供应商任务。结果不明先查询，避免重复收费。
