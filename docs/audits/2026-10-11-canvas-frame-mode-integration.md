# 画布视频帧模式与引用接入验收

## 输入合同

- AI 逐视频片段推荐 `first` 或 `first_last`，返回真实画格 ID 和中文理由，不改写剧情、对白、时长或片段结构。
- 网页先展示推荐，再由用户应用。推荐期间输入变化后，旧建议不能覆盖当前编辑。手动调整标记 `selection_source=manual`；CLI 必须保留人工选择。
- `videoFramePairs` 保留旧字段名兼容历史数据，但尾帧可空。选择首尾模式必须显式指定结束画格，不能自动补相邻格。
- 人物基础形象进入 Ref，分镜裁图进入首帧／尾帧。整张分镜不进入 Ref。两类输入可在 H3 Ref 工作流中同时传递。
- 修改后的草稿、公开 CLI 与实际供应商请求使用同一准备和编译逻辑。历史视频保留 `resultRevision`，不冒充当前编辑的结果。

## 已修复根因

1. 分镜准备将静态画格强制要求为首尾配对，无法表达首帧模式。现已支持仅首帧与可选尾帧。
2. Ref 路径曾清除帧输入、加入整张分镜作为参考。现分离身份参考和画格锚点，保留显式帧。
3. Codex 将两个 Subject 定义写在同一行，引发 `reference_subject_mismatch`。现提供逐行模板及明确换行规则；校验诊断只保存协议标签与错误码，不记录提示词或密钥。

## 公开操作

`POST freezone/video-director/recommend-frames` 接收当前 `frames`、既定 `segments`，使用已保存的 `director_plan` runtime。返回建议，不静默写画布。

采纳后通过 `canvas nodes update` 的 `{"data":{"videoFramePairs":[...]}}` 保存，携带最新画布修订；再 `prepare-storyboard` 并核对实际 draft，最后提交 attempts。详见画布 Skill 的执行手册。
