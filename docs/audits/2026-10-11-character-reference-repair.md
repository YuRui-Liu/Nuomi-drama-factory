# 缺失角色引用修复验收

## 使用

在分组生成的「生成前引用确认」中，缺失角色卡片可点「生成角色形象」或「绑定已有角色」。新角色先确认剧情依据、名称、外貌和服装，再进入原有选角候选流程；已有角色可按名字搜索并明确选择身份。已有身份缺图时复用该身份，不重复创建。

生成候选仍需用户手动采纳。采纳后恢复原集、原规划和原分组引用；生成与绑定分开恢复。绑定失败可以单独重试，重新打开可恢复已采纳但尚未绑定的候选。来源已变化时要求重新确认，不将旧结果绑定到新规划。其他有效引用选择及临时上传保持保留。
