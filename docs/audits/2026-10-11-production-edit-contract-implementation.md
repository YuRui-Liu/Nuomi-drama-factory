# 引用、编辑执行合同与局部修复：实施记录

日期：2026-10-11。按当前会话授权内联修改；未提交、未部署，保留原有工作区修改。

## P0-2：资产存在与引用可用分开诊断

修复资产编辑页使用的 `PUT asset-bindings` 路径：保存本集选择后刷新活动导演方案的引用。此前另一个 episode PATCH 路径会刷新，但该入口不会，导致资产选择已保存而规划引用仍旧。

刷新失败时返回 `ASSET_BINDINGS_SAVED_REFRESH_REQUIRED`，明确告知选择已保存，避免把部分成功误报为完全未保存。

引用预览保留实体 ID、关联组、关联镜头、媒体版本，新增稳定诊断字段：

| issue_code | 含义 | 对应处理 |
|---|---|---|
| asset_not_bound | 当前规划没有绑定可用实体 | 核对已有资产并刷新绑定 |
| binding_confirmation_required | 身份或造型需要确认 | 确认绑定 |
| media_version_missing | 资产没有可用图片版本 | 补齐媒体版本 |
| media_unavailable | 图片路径不可访问或不是有效图片 | 修复媒体文件 |
| binding_type_mismatch | 资产槽与引用类型不一致 | 修正绑定 |

网页新增“从已有资产刷新引用”，调用既有活动导演版本刷新服务，然后重读预览；不生成图片。卡片显示中文原因、版本和关联镜头。必需引用不可用时仍阻止提交。

## P1-1：用户编辑到叙事组视频执行

保存视频设置与生成提交共用参数解析；明确拒绝未知参数和携带另一模型覆盖参数的请求。引用刷新不再把弹窗中已编辑的模型、风格、分辨率恢复为默认。

新任务保存 `execution_contract`：

- 模型、模式、画幅、生效工作流参数。
- 项目参数默认值与本组覆盖来源。
- 方案、设置、引用修订号及分镜/引用快照标识。
- 供应商工作流定义、参考策略和公开参数定义。
- 审查开关与分镜绑定合同。

执行时校验任务输入与合同一致，并核对工作流定义。输出 manifest 保存合同。历史任务无合同走明确兼容路径，不补造历史快照。摘要用于检测一致性，不是数字签名或防恶意篡改认证。

**覆盖边界：** 此次接入叙事组视频 API 及其 runner；生产 CLI 本来通过该 HTTP 服务提交，因此复用该行为。独立创作画布的节点执行器尚未接入相同合同；也没有新增全局风格、提示词模板的统一冻结机制。不能宣称全部创作入口已经统一。

## P2：局部修复成为可解释操作

复用已有单格提示词编辑、提交、历史版本操作，在提交前展示影响范围。根据镜头与视频片段映射列出受影响片段；映射缺失或目标没有映射时按整组影响处理。保留其他分镜图片，修复票据及完成记录保存影响信息，不自动提交付费视频。

新增运行器保护：只重试多片段组中的一个片段时，结果进入 `review`，返回独立 `segment_asset` 和 `requires_group_composition=true`；清单不发布整组 `physical_video`，组状态不登记该片段为整组成片。其他历史素材不删除。

**未完成的产品闭环：** 尚未增加“仅重做受影响片段并自动复用其他片段重新合成”的完整操作。当前图片修改仍保守标记下游组过期；影响预览不等于已实现片段级自动失效与合成。CLI 仍禁止代理循环单镜头/片段付费生产。
