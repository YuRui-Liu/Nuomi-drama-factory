# 分镜到导演台：首尾帧交接修复

## 交接规则

自动叙事画布默认 frames；用户明确手选 Ref 时保留该选择。H3 现有能力不允许主体参考与首尾帧混用。人物基础形象供分镜生图，整张网格不能直接作为某片段的首帧。

分镜节点新增 `videoFramePairs`，保存镜头 id、首画格 id、尾画格 id、动作描述、时长。画布新增配对编辑器。后端按明确的画格 ID 裁图并绑定，不按相邻格猜测；静态画格需分别声明 start/end。缺失引用、同一画格冒充首尾、selected 关键瞬间冒充端点均报错。旧无静态合同的单首帧方案仍保留 I2V 兼容，不代表已有尾帧。

准备结果与执行校验共用包含配对字段的摘要。配对变化后旧导演草稿失效，必须重新准备；保持用户原有手工编辑冲突检查。

## 原 E2 尚需制作的内容

G1 现有四格是关键瞬间，不是四镜的八个起止画面；其中还存在前轮记录的角色动作错位。此次没有把这些旧图冒充端点，也没有生成新的首尾图。后续应先设计每镜起止状态并生成对应画面，再完成视频交接验收。当前结论是交接规则和编辑入口已修复，原 E2 首尾素材与成片尚未完成。
