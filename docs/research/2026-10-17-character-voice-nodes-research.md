# 角色音色与配音节点调研

日期：2026-10-17。状态：调研依据；用户已确认节点边界、模式、机组、局部返工和试听交付，书面设计见 [声音节点 PRD](../superpowers/specs/2026-10-17-character-voice-nodes-design.md)。下文保留调研时的提案与备选供追溯。

用户已指定：Qwen3-TTS 负责角色音色设计，IndexTTS2 负责声音克隆。本轮未部署模型、未生成音频；模型文档能力不等于当前供应商工作流已开放能力。

## 1. 官方依据与适用边界

| 来源 | 核实结论 | 对本项目的影响 |
| --- | --- | --- |
| [Qwen3-TTS 官方 README](https://github.com/QwenLM/Qwen3-TTS#python-package-usage)、[VoiceDesign 模型卡](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign) | VoiceDesign 使用 `generate_voice_design(text, language, instruct)`，输出音频及采样率；VoiceDesign、Base、CustomVoice 是不同用途的模型。 | 采用 1.7B VoiceDesign 生成音色候选，试听文案与声音描述分开保存；不能把反复调用视为同一角色的稳定声线。 |
| [IndexTTS 官方仓库](https://github.com/index-tts/index-tts#usage)、[v2 推理代码](https://github.com/index-tts/index-tts/blob/main/indextts/infer_v2.py) | v2 以 `spk_audio_prompt` 和 `text` 克隆语音；有情绪参考、向量、文本控制。公开 v2 未开放论文中的精确时长控制；当前主仓库同时包含 2.5。 | 明确记录 v2 模型与供应商版本；不借用 2.5 参数。原版参考音频会截到 15 秒，导入时应让用户选择有效片段，供应商另有要求时以其契约为准。 |
| [ElevenLabs 专业音色提示指南](https://elevenlabs.io/docs/eleven-creative/voices/voice-design) | 将音高、共鸣、质感与情绪表达区分；试听文本应匹配设计意图，口音不同于语调。 | 借鉴描述方法和试听比较方法，不移植其模型标签、参数、定价或效果保证。 |

Qwen 官方示范的同系列复用路线是 VoiceDesign → Base；本项目按用户要求改为 VoiceDesign 样本 → IndexTTS2。两者之间传递音频资产，不传递专用模型嵌入。跨模型声线保持程度须后续实际试听，现阶段不宣称验证通过。

## 2. 已有项目基础

- `src/novelvideo/media_capabilities/tts/models.py` 已有 `VoiceSpec`、`VoicePerformance`、`CharacterVoiceDesign`，可以分别承载声线、表演、试听文本。
- `voice_prompt.py` 已有声学描述编译器，提取音色维度并检查部分矛盾；不需要再建另一套提示词字符串拼接入口。
- `segments.py` 已有台词规范化、版本关联的稳定片段标识，以及互斥的情绪请求。应优先从结构化剧本取台词，避免依靠删除所有括号来猜测哪些内容要朗读。
- `runninghub_voice_design.py`、`workflow_variants.py`、`generators/indextts2_fal.py` 已提供相关执行基础。具体参数必须由实际 provider/workflow 能力声明校验，不能把原版模型签名直接当成托管接口。
- 既有 [角色声音设计规格](../superpowers/specs/2026-09-23-character-voice-design.md) 是复用参考；历史规格中的现状描述需以当前代码为准。
- 当前角色资产面板已具备设计、候选、试听及采用入口；`task_backend/runners/voice_design.py` 生成结果明确为 `published: False`。`candidate_store.py::approve` 核验人工 actor/reason、角色摘要新鲜度、音频质检和目标引用并发变化，通过后才写入角色声音引用。画布应复用这套流程。
- 当前 RunningHub Qwen 工作流使用节点 14 的文本、节点 15 的指令，语言 Auto 留在已发布工作流中。因此节点不能提前承诺可调语言参数已生效。
- `freezone/audio_node.py` 已通过角色参考音频调用 IndexTTS2；`audioNode:speech/music` 已有可执行适配器。Qwen 音色设计尚无对应画布操作。Agent 的 `node.run` 还需精确节点、操作、次数和版本等 scoped grant；能力目录声明不等于执行授权。

## 3. 专业提示词模式（本项目提案）

保存三层内容，编译时按模型能力选择字段；不能把整份导演说明直接发给情绪分析器。

| 层 | 内容 | 编译去向 |
| --- | --- | --- |
| 声线身份 | 年龄感、音区、共鸣、质感、咬字、语言/口音、稳定节奏 | Qwen VoiceDesign 的 `instruct`；采用后绑定参考音频版本 |
| 台词表演 | 对谁说、意图、潜台词、情绪及强度、重音、停顿、气息 | Agent 的配音表演单；仅支持的情绪信息进入 IndexTTS2 控制，其他项保留为试听验收要求 |
| 朗读文本 | 已采用剧本的准确台词、读音说明、台词 ID | TTS 的 `text`；读音替换如改变文本应保留可审查映射 |

原创示例，需试听验证而非效果承诺：

**声线描述**：普通话，青年男性，中低音区，胸腔共鸣适中，声线清晰略带颗粒感，咬字利落，语速自然；基调克制，避免持续耳语或夸张播音腔。

**试听文本**：门还开着。我进去看看，你在这里等我。

**某句表演单**：对同伴说；意图是阻止对方冒险；表面镇定、内心紧张；“别进去”重读，随后短暂停顿；不喊叫。

**实际台词**：别进去。我听见里面有人。

**情绪文本模式的可提交候选**：克制的紧张和担忧。详细重音与停顿继续保存在表演单，不承诺情绪向量能精确表达它们。

情绪模式建议为：沿用参考表现、情绪文本、情绪参考音频、专家向量。一次选择一种；沿用参考不等于模型保证中性。未开放的模式应说明原因。时间目标保存为编辑要求，生成后记录实测长度，不能伪造精确时长参数。环境混响、电话滤镜、空间感放在混音阶段，避免污染长期复用的声线参考。

## 4. 节点及 Agent 操作提案

推荐方案 A：**角色声音资产节点 + 现有音频节点的配音模式**。

1. 角色声音节点关联角色和身份/年龄变体，提供“设计音色（Qwen3-TTS）”“导入参考”“已有声音”来源模式。候选可试听比较，采用后生成不可变声音版本。
2. 音频节点的“角色配音”模式引用声音版本与准确台词，使用 IndexTTS2。它可以是叙事组声音任务的画布视图；底层分段是执行细节，不改变叙事组生产单位。
3. “剪辑与声音”引用已采用的配音结果。更换声线只标记受影响台词，保留旧成片和旧声音引用；重配由明确动作触发。
4. 原视频声音已满足要求时继续复用，不能因有声音节点就自动重配。试听生成、采用声线、批量配音、采用配音、导出是独立动作。

备选 B：一个声音节点同时容纳角色资产与全部配音任务。入口更少，但跨集共享声线与单集台词版本混在一起，依赖及局部返工更难表达。

以下是拟议操作语义，尚不是已安装的工具名称：

| 操作 | Agent 职责 | 输出及边界 |
| --- | --- | --- |
| `voice.prepare_design` | 音色设计师从角色资料形成声线规格和试听稿 | 结构化候选方案，不调用音频生成 |
| `voice.generate_candidate` | 音色设计师调用 Qwen 执行适配器 | 任务 ID、候选音频、有效参数；不自动采用 |
| `voice.adopt` | 用户明确采用，Agent 可提交采用建议 | 复用人工采用校验，形成声音版本、角色变体关联、参考音频哈希；不伪造人工 actor |
| `dubbing.prepare` | 配音导演生成叙事组表演单 | 台词与版本引用、情绪模式、缺失依赖、生成范围 |
| `dubbing.generate` | 配音执行师调用 IndexTTS2 适配器 | 可恢复任务及候选 take；不自动覆盖时间线 |
| `dubbing.adopt` | 采用指定 take | 版本化音频引用及时间线更新提案 |

共同契约应包含项目、节点、角色/身份、剧本与声音版本、台词或叙事组范围、操作幂等标识、provider/model/workflow 版本。返回任务状态、实际生效参数、拒绝或不支持的参数、产物及错误。操作必须注册到可执行适配器及 Agent 权限中，目录角色名称不代表已接通。

## 5. 后续验证范围

讨论后的验收范围为一名角色、一组真实 E01 对白，验证 Qwen 候选采用 → Index 克隆 → 实际试听 → 时间线引用，再通过支持的生产入口扩展整集。测试目标为声线、台词完整性、明显表演偏差及最终播放，不默认加 ASR 或反复付费质检。具体边界以声音节点 PRD 为准。
