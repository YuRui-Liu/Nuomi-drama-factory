# 剧本与分镜

## 功能概览

剧本页根据剧集和图谱生成或修改 Beat 文本；分镜页把 Beat 组织为镜头组，生成草图、布局和首尾帧等图像输入，供音视频阶段使用。

## 适合谁看

适合编剧、导演、美术、测试和研发核对文本 revision、镜头组和图像产物是否来自当前输入。

## 用户操作

1. 选择剧集和目标 Beat，生成或编辑剧本内容。
2. 检查对白、旁白、角色、场景和道具引用。
3. 在分镜页按镜头组预览并生成草图或正式图像。
4. 修订后重新生成受影响的 Beat 或镜头组，再进入音频和视频。

## 业务流程

```mermaid
flowchart LR
    A[选择剧集与 Beat] --> B[生成或编辑剧本]
    B --> C[保存文本与 revision]
    C --> D[生成镜头组草图/图像]
    D --> E{图像任务}
    E -->|completed| F[展示镜头与首尾帧]
    E -->|failed/cancelled| G[保留旧产物并提示处理]
    F --> H[交给音频/视频阶段]
```

1. 用户生成或编辑 Beat 文本并保存。
2. 系统按当前文本、资产和镜头布局生成图像任务。
3. 成功后写入草图、布局或帧资产；失败或取消不覆盖旧结果。
4. 下游读取当前 Beat 与镜头产物继续生产。

## 业务规则

- Beat 是生产和任务刷新的基本单元；镜头组是分镜并行与布局单元。
- 角色、场景、道具引用必须落在当前项目作用域内；未知 opaque id 会被拒绝。
- 生成任务带 revision，旧 revision 的晚到结果不能覆盖新内容。
- 草图布局与正式帧是不同产物；不要把草图存在误写成视频已就绪。
- 手工镜头仍可生成对白或旁白音频，手工静音镜头才会跳过发声。

## 状态与异常

文本或图像任务按统一任务状态展示。常见异常包括 revision stale、引用数量或画幅不支持、模型调用失败、部分镜头成功和取消后仍有短暂后台工作；最终以服务端终态和产物查询为准。

## 产品验收

- 编辑后的 Beat 文本和 revision 可重新打开并被后续任务读取。
- 镜头组能预览引用、布局和生成结果，失败项可单独重试。
- 旧 revision 的结果不会覆盖新 revision。
- 产物路径在项目 output 内，页面能区分草图、帧和最终视频。
