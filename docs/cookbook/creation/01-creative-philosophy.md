# 漫剧创作哲学：先让观众追下去

这页适用于把小说、短故事或原创设定改造成连续的 AI 漫剧。它讨论创作判断，不把某一种题材、画风或时长当成系统硬约束；平台规格、预算和团队能力仍应由项目自行决定。

## 适用场景

- 还在选择改编方向，需要判断一个段落是否值得视觉化。
- 已有角色和世界观，但成片像“插图配旁白”，缺少戏剧推进。
- 多人协作或多模型生成时，需要一套共同的取舍语言。

## 核心观点

漫剧的最小单位不是“好看的画面”，而是一次可感知的变化：人物知道了新信息、关系改变、目标受阻，或观众重新理解了一个线索。创作时先确定本场的情绪与因果，再决定镜头、旁白和素材。生成能力越强，越要把选择权放在叙事目的上。

一个实用优先级是：因果清楚 > 人物选择可信 > 情绪有落点 > 视觉有记忆点 > 细节华丽。视觉风格可以随项目调整，但观众必须能回答“谁想要什么、为什么现在做、做完发生了什么”。

## 判断标准

用四个问题审查一个创作单元：

1. **变化**：开头和结尾之间，至少有一个状态发生变化吗？
2. **选择**：变化是否由人物的行动或不行动造成，而非旁白替人物宣布？
3. **代价**：行动是否带来风险、误会、机会或新问题？
4. **记忆点**：是否有一个动作、道具、构图或台词能让观众复述本场？

没有变化的段落可以压缩成过渡；只有设定说明的段落应改写成冲突中的信息；只有漂亮画面的段落要补上人物目的。

## 推荐工作流

1. 从原文提取“欲望—阻力—转折—余波”，暂不写镜头提示词。
2. 为每集写一句可验证的承诺，例如“她必须在三分钟内让仇人相信自己失忆”。
3. 把承诺拆成若干 Beat，每个 Beat 只承担一个主要变化；需要连续动作时保留明确的前后因果。
4. 先锁定角色关系、关键道具和情绪曲线，再进入[剧集图谱与拆解管线](../pipelines/02-episode-graph.md)。
5. 用[剧本与语义管线](../pipelines/04-screenplay.md)产出可供分镜、配音和剪辑复用的文本。
6. 生成素材后回看“变化是否仍然可读”，必要时删画面、改动作，不用更多特效掩盖叙事缺口。

## 正反例

**正例（悬疑前提可调整）**：女孩在停电的电梯里听见母亲的声音。她先按下报警键，再发现声音来自自己口袋里的旧录音笔；录音最后说出只有母亲知道的地址。画面、声音和道具共同改变了她的判断，并留下下一集的问题。

**反例**：镜头依次展示电梯、女孩特写、城市夜景，旁白说“她感到不安”。没有具体行动或新信息，观众无法知道不安会改变什么。可将“听见声音”变成她选择隐瞒报警，并让这个选择制造后续风险。

## 常见失败

- 把“风格统一”误当成“内容统一”：人物每场都摆同一种姿势，情绪却没有变化。
- 用旁白讲完冲突，再用画面重复一遍，导致节奏拖慢。
- 为了展示模型能力加入无关转场、粒子或镜头运动。
- 只按原文段落切集，没有给每集设置承诺、升级和回收点。
- 把一次生成结果当成定稿，忽略角色、道具和空间的连续性检查。

- 需要检查图像、声音和视频分别由谁生成，沿[分镜与图像](../pipelines/05-storyboard.md)、[声音与音频](../pipelines/06-audio.md)、[视频生成](../pipelines/07-video.md)查看对应页面行为。

## 检查清单

- [ ] 我能用一句话说清本集承诺，以及观众会追问的问题。
- [ ] 每个 Beat 都写出了人物目的、阻力和可见变化。
- [ ] 至少一个关键转折由人物选择触发，而不是旁白宣布。
- [ ] 已标出可删的设定说明和只提供装饰的镜头。
- [ ] 角色、道具、场景引用已交给资产管线复用，并确认最终预览仍读得出因果。
