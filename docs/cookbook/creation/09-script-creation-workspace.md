# 剧本创作工作台：从设定到制作交接

工作台适合先写一个可修改的故事，再按集推进。打开项目的「剧本创作」页，从「从创作预设开始」进入。模型任务需要在「设置 → 运行时与媒体 → 文本任务路由」配置 `script_creation`；交接后若要运行场次解析与校对，还需配置 `episode_normalization`。任务入队时会冻结路由设置，修改设置后应重新发起失败的任务。

## 建立文档

在设定弹窗中选择单集或连续剧、集数、时长、题材、受众、风格和故事想法。可在选项中搜索，也可输入自定义值再选中。保存后出现「创作简报」；左侧文档树是正文入口，右侧是 AI 协作。可以逐篇写作，也可以用「创建空白文档」建立大纲、人物小传、场景设计、道具设计、分集梗概与第一集剧本。空白模板只是编辑起点，不算已写正文。

「生成故事框架与首集」按大纲、分集梗概（连续剧）、人物、场景、道具、第一集的顺序运行。它只生成首集。连续剧要在分集梗概中写明目标集的实质内容，再点击「按此风格续下一集」；未完成的集不能跳过。选中某集时以该集作为续写起点；选中其他文档时，从已写且连续的最后一集续写。已有正文会保留，模型结果成为待审阅候选。

已有制作来源可用「导入已有剧本继续打磨」复制进工作台。导入文档可独立编辑，保存、恢复或采纳候选不会自动改写制作来源；只有明确确认交接才更新来源。

## 修改、审阅和检查

点击「编辑 Markdown」直接改正文。编辑会自动保存；「立即保存」可主动提交。保存失败可重试；若服务器已有新版本，先比较两份正文，再选择使用服务器版本或保留本地修改并保存。版本历史能查看差异并显式恢复，恢复会产生新修订，旧修订仍可追溯。浏览器重挂载后的本地草稿会恢复；若其基线落后，会显示冲突，先解决再运行 AI 任务。

在正文选段后打开「候选审阅」，选择选段、当前场或当前集，并输入改稿要求。模型只提供候选；对照差异后可采纳或丢弃。采纳按保存版本和精确文本范围校验，多个候选合并采纳为一次原子更新。正文或版本变化后重新选段，旧位置不能沿用。

「关联检查」先选当前集，检查已保存的实际版本；事实冲突带来源和目标的逐字证据，创作建议单独显示。若选择待采纳候选并点击「检查若采纳影响」，结果属于假设，采纳后应对实际版本重新检查。可为有意安排填写原因；证据修订变化后结果会过期。勾选需要修改的目标文档，再生成对应候选，其他文档不会被自动改写。检查失败或过期时应重试或重查。

## 资产关联与交接

在「资产关联」中选人物、场景或道具设计条目，明确选择已有制作资产，或新建文字档案。关联使用稳定 ID，不能凭同名自动绑定；名称修改后仍可追踪。出现位置要区分 planned（计划）与 written（已写）：计划集数不证明已经出现在剧本中，已写位置应指向保存的剧本修订。文字档案和关联操作不会启动生图、音色或视频任务。

每集完成后点击「确认本集并交接制作」。先核对正文修订、所选参考文档和资产、关联检查的确认理由，再看新旧差异；明确选择更新范围后确认。交接会冻结不可变快照并用来源版本校验提交。已有制作来源在确认前不会变化，冲突会要求重新预览。若场次解析或派发失败，交接记录保留已完成步骤，可在原记录重试；不要靠重复创建交接来猜测成功。差异中的确定文本变化与推测影响分开显示，未选择更新的受影响媒体会提示复核。更新文字不等于自动生成画面、音频或视频。
