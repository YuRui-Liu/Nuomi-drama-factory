# 角色一致性：固定身份，允许变化

这页适用于角色会跨多个场景、镜头、集数或媒体模型出现的漫剧。它不要求角色永远同一表情或同一服装；一致性应服务于身份辨识和剧情变化，而非把角色冻结成一张立绘。

## 适用场景

- 同一角色在不同镜头中脸型、发型、年龄感或服装明显漂移。
- 角色参考图很多，但团队仍无法判断哪张是当前采用版本。
- 角色需要经历受伤、伪装、成长或时间跳跃，既要变化又要认得出来。

## 核心观点

把角色拆成三层：**身份锚点**（脸部比例、发色、体态、标志性物件）、**可变状态**（表情、姿势、服装污渍、伤势）和**叙事状态**（关系、目标、秘密、情绪）。生产时固定第一层，按场景更新第二层，用第三层指导动作和台词。参考图是证据，不是替代角色设定的魔法提示词。

## 判断标准

- 观众在无台词静帧中能凭两三个身份锚点认出角色。
- 变化有来源：服装、伤势或表情变化能回指剧情事件，而不是随机漂移。
- 角色卡写的是可观察特征（“左眉尾有浅疤”），不是难以执行的抽象形容词（“很有气质”）。
- 同一集内的参考、提示和采用资产指向同一版本；例外状态有明确标签。
- 角色的动作、说话方式和选择与其目标/关系一致，不只是外观一致。

## 推荐工作流

1. 为每个主要角色建立一页角色卡：身份锚点、禁用变化、可变状态、关系和本集目标。
2. 选择一张正面、一张侧面和一张带典型表情的参考；记录版本和适用前提。
3. 在[生产资产管线](../pipelines/03-production-assets.md)中区分候选、采用和废弃参考，不把同名文件当作版本管理。
4. 写分镜/提示词时先引用角色身份，再追加动作、景别、光线和状态；不要用十几个近义外观词稀释锚点。
5. 每完成一组镜头，做“相邻镜头对照”和“跨集抽样”，发现漂移先定位是参考、提示、姿态还是后期问题。
6. 对伪装、成长、受伤等大变化建立新状态标签，保留与基础身份的关联，再交给[分镜与图像](../pipelines/05-storyboard.md)和[视频生成](../pipelines/07-video.md)。

## 正反例

**正例**：角色“林舟”的身份锚点是短黑发、左眉尾浅疤、偏瘦体态；第 4 集因爆炸增加右臂绷带，标签写为“林舟·受伤后”。绷带随剧情出现，脸部锚点仍稳定，观众能同时读出身份和事件后果。

**反例**：每个镜头都重新写“年轻、英俊、黑发男子”，一场戏里发型长度和脸型不断变化；为了修正又把所有参考图塞进提示词，结果模型混合出新角色。应选定采用参考并把变化写成状态，而不是堆描述。

## 常见失败

- 只锁脸，不锁体态、声音、道具或行为习惯，角色仍然难辨。
- 把服装连续性当作绝对规则，忽略换装、天气和剧情时间跳跃。
- 角色卡写满审美词，没有可检查的正反例。
- 同一角色存在多个未标注的“最终版”，下游各自缓存不同参考。
- 发现漂移后直接重生成全部镜头，既浪费成本又掩盖真正的输入问题。

## 软件入口

- 先从[角色·场景·道具](../product/03-production-assets.md)确认资产采用规则，再从[音频与视频](../product/05-audio-and-video.md)确认角色视听产物的状态与验收点。

- 角色声音、对白一致性：对照[声音与音频管线](../pipelines/06-audio.md)；最终连续性在[合成与导出](../pipelines/08-compose-export.md)复查。
- 项目和任务入口、日志查看方式见[启动与本地开发](../start-software.md)。

## 检查清单

- [ ] 每个主要角色都有 2—4 个可观察身份锚点和明确禁用变化。
- [ ] 参考图已标注版本、状态和采用/废弃关系。
- [ ] 当前镜头的服装、伤势、表情变化都能回指剧情前提。
- [ ] 我已做相邻镜头对照，并抽查至少一处跨集镜头。
- [ ] 漂移问题已定位到参考、提示、姿态、声音或后期中的具体环节。
