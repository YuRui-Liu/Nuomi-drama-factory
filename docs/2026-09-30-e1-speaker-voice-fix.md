# E1 第 3 组声画错配修复

## 已查证的原因

- 居民丙的已有角色图为女性；资产性别和声音特征原先为空。
- r2 使用 H3 原生音轨，三条对白的 `voice_descriptor` 均为空；动作描述把居民丙写成 him/his。
- 已保存的视频引用包含居民乙，却没有本组实际说话的居民甲、居民丙。
- 视觉规划记录了提桶人物与文字身份冲突，但旧门禁只阻挡挂载位置和动作阶段冲突。
- 上轮仅验收限量牌位置，不能据此认定对白声画一致。

## 修复范围

1. 视频生产从角色资产加载声音特征，按角色名或唯一别名绑定。缺少声音、身份不唯一或声音事实冲突时，在供应商视频提交前报错。
2. 声音映射进入规划输入及缓存输入；编译前将资产声音写入每条匹配的对白，覆盖模型猜测。
3. 视觉规划明确人物、道具持有人与说话人对应关系。`prop_holder`、`speaker_identity`、`speaker_voice` 冲突不再放行。
4. 通过项目 API 保存居民丙女声、岑砚与居民甲各自男声方向，并将第 3 组引用改成这三人及水箱区场景。
5. 保留 r2，复用现有修正分镜，提交第 3 组 r3，16:9。任务：`5021cfc6-4415-4b70-b7ea-c185594ce770`。
