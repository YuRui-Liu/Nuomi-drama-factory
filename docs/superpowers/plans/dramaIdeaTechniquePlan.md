# 立意与案例手法节点实现计划

**目标：** 补齐独立立意节点与案例手法节点，并将已确认的手法用于分镜和 H3 规划。

**架构：** 复用现有 production 成果、版本引用与采用接口，节点负责交互；手法案例保留来源，并按 H3 模式及时长约束使用。Agent 负责生成立意和组织镜头，不新增独立模型调用链。

**技术栈：** TypeScript、Vue、Bun、Zod、已有节点插件与 production API。

1. 新建立意节点，支持保存创作简报、读取并编辑候选、采用确定的立意，提供 Agent 绑定和读取入口；已有明确立意可直接填写。
2. 从本地 Nuomi 手法库吸收手法和案例，保留案例与手法关联、来源及适用条件，新建案例手法节点。
3. 将已选择的手法固定到指定分镜或 H3 生成段，验证版本及兼容性，并接入 Agent 提示词组织；变更后沿用生产成果依赖过期机制。
4. 执行受影响包的类型检查、构建与必要的无付费手动验证；不新增测试文件，不提交现有无关修改。
