## 接入边界

项目机组复用固定版本 Agent 的项目采用记录，单次任务复用委派与 AgentRuns；媒体执行复用 RunStore、Scheduler、NodeAdapter。保留现有内容节点、编辑器和依赖连接，不增加独立专业 Agent 内容节点。

真实节点修改和执行必须分别经过能力、委托范围、输入版本与执行授权检查。次数上限不是货币金额上限；未完成价格计量不能声称可按人民币预算精确限额。提交状态不代表成果交付。

## 本批使用路径

1. 在现有画布选择内容节点，打开画布助手；在项目机组中按需展开专业目录，将所需专业 Agent 加入项目。
2. 选择直接委托某一成员，或由主创与候选专家协作；成员采用记录固定版本，任务记录保留当时的成员身份。
3. 引用选中节点，明确允许修改字段或执行的具体操作，并设置执行次数上限。模型配置可用后输入目标并发送。
4. 查看真实运行记录与节点产物，点击节点定位到画布。系统只自动回填已验证且版本仍匹配的结果；旧媒体留在历史证据中。
5. 提交结果未知时保留原任务，恢复继续核实同一次执行；停止禁止后续采用，不将其描述为供应商已取消。发生用户编辑冲突时保留生成产物并展示冲突。

本批不包含完整 PRD 中尚未实现的所有制作能力，也未证明真实供应商可生成完整成片。节点操作是否可用以实际能力目录为准，专业角色声明不会自动安装适配器或扩大授权。
