# DramaClaw 风格、立意与案例手法节点设计

日期：2026-10-28。状态：对话设计已批准，书面规格待用户审阅。

## 目标与范围

以本地 `/Users/liuyuxiang05/Liu/Nuomi-drama-factory` 为吸收来源，为 Toonflow 增加独立立意、风格、案例手法节点。用户选择了全部节点化方案：画布连线表达参考关系，不采用共用侧栏作为主要入口，也不将全部能力藏在通用制作成果弹窗中。

风格用于复现指定视觉特征；案例手法用于组织镜头及 MiniMax H3 提示词。采用手法不等于保证模型复现效果，成片须人工核对。此次不扩展发布、收藏、远端同步、素材抓取或自动批量视频生成能力。

## 节点职责与交互

### 立意节点

输入创意及制作约束，生成三个候选方向；支持编辑单个候选、局部重做和采用。已有明确立意时允许直接填写并采用，不强制生成三个方向。

候选至少表达一句话立意、主角与核心冲突、故事看点、最终抉择，复用现有 idea 语义。采用后以版本引用交给全剧规划；候选生成不自动采用。

### 风格节点

浏览并选择基础或扩展风格，展示视觉描述、避免项和来源。采用记录携带条目版本及内容快照。

每部作品只采用一个默认风格，作为资产、分镜和视频提示词的共同依据。节点的作品默认状态须明确显示；仅创建节点不自动替换已采用默认风格。镜头可通过风格节点连线显式指定覆盖，覆盖替代默认风格，不自动混合互相冲突的两套描述。

### 案例手法节点

浏览案例、镜头写法与关联手法。节点展示采用的案例依据、动作节拍、表演、运镜、结束构图及适用条件，通过连线作用于指定镜头或 H3 生成段。

用户可直接指定案例或手法，此指令即授权采用，无需重复确认。未指定时 Agent 根据剧情、镜头目的及 H3 条件推荐，说明适用原因，用户确认后采用。

连到包含多个镜头的成果时必须选择具体镜头或生成段，不能默认应用于全部内容。首轮每个目标采用一个手法方案；多个输入发生冲突时要求明确选定，不按连接顺序暗中覆盖。

### H3 方案节点

综合当前剧情、有效风格、手法快照和素材约束组织执行提示词。引用案例的镜头表达方法，保持当前人物、场景、剧情和对白，不引入案例原有故事。

先生成可审阅方案，再沿用既有媒体执行及额度授权流程。手法节点不是媒体素材，文本参考不能填入图片或视频素材槽位。

## 数据流与边界

主线为：立意采用 → 全剧规划与剧本 → 正式分镜 → H3 方案 → 视频生成。作品默认风格贯穿视觉生成；局部风格与手法通过明确目标引用进入分镜或 H3 方案。

画布连线表达用户意图，服务端保存并校验对应的成果版本引用、目标镜头／生成段标识及采用快照。Agent 与界面使用同一业务操作，不仅靠前端连线临时拼接提示词。拒绝跨作品引用、无效目标及循环依赖。

节点交互放在所属插件；跨节点共享的库结构、引用类型和业务组件放在 `packages/nodeShared`，通过公开子路径使用。`packages/nodeScaffold` 保持通用节点基础职责。服务端沿用 production 的保存、采用、依赖判断，提示词组织规则放入所属创作 Skill／Agent 能力。

## 更新、兼容与错误处理

- 库更新不修改已采用快照；用户主动重新选择时才产生新版本。
- 替换立意、默认风格或手法后，受影响的下游成果标记待更新，保留已有方案和媒体，不自动执行付费任务。
- 默认风格变化只影响实际继承它的镜头；显式覆盖镜头不因该变化失效。修改局部手法只影响其目标及下游。
- 修改后的上游须被下游重新采用或核对后才能作为当前有效方案继续生成；历史成果仍可查看。
- 旧项目没有新节点或引用时保持现有行为，不自动补风格、手法或重写提示词。
- 来源条目缺失时，已有完整快照仍可查看和使用；新选择缺失条目时报错。无效引用、缺失素材、目标不明确或内容损坏不静默跳过。
- 将来源手法的模式名称映射到 Toonflow H3 模式；按当前实际 provider／工作流能力与手法条件的交集判断兼容性，不直接照搬来源时长上限。无明确映射时禁止自动套用。
- 模式、时长、首尾帧或素材条件不兼容时说明冲突，提出可调整方案，不擅自更换模式或丢弃约束。
- 文件保存沿用统一文件入口与原子快照写入；保存失败保留编辑状态并向用户报告，不返回成功。

## 验收与验证边界

实现阶段显式执行受影响包的既有类型检查、构建和必要手动验证；新增服务端路由时先生成路由注册。按仓库要求不新增测试模块、自检文件或测试依赖。

手动核对以下链路：

1. 立意节点创建、候选生成／编辑／采用，已明确立意直接采用，下游读取采用版本。
2. 默认风格与镜头覆盖均进入实际提示词，局部覆盖优先且不污染其他镜头。
3. 用户指定与 Agent 推荐确认两条手法采用路径均可用，具体目标及来源可追溯。
4. 手法进入 H3 提示词的动作、运镜与结束构图描述，保持当前剧情与素材身份。
5. 不兼容条件被阻止并说明原因；写入失败、缺失目标不产生虚假成功。
6. 重新打开作品后采用快照仍在；库更新不改写旧方案；上游变化正确标记相关下游且不自动生成视频。
7. 旧项目无新引用时保持原有工作方式。

实际样片验证沿用用户已有明确算力授权范围；没有授权时不因文档或代码验证自动发起付费生成。样片需分别核对风格、主体连续性、运动方向、动作节拍和结束构图。报告区分编译结果、手动链路结果和实际生成效果。
