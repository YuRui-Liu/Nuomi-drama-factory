# 叙事组图风格、角色与场景参考设计

## 背景

当前叙事组图使用独立的轻量生成链路。任务 payload 未包含项目视觉风格或资产选择，生成 Prompt 在 Render 阶段固定使用 `finished cinematic frame`，且 `ImageGenerationRequest` 没有传入 `references`。因此，动漫项目可能生成 3D/写实画面，角色身份与场景结构也无法利用项目已有参考资产保持一致。

## 目标

- 叙事组图默认注入项目视觉风格 Prompt。
- 默认引用本组镜头实际出现角色的身份图，缺失时回退角色默认肖像。
- 默认按本组镜头的 `scene_id` 引用场景主参考图。
- 用户可在生成前关闭整类引用或逐张取消角色、场景参考图。
- 所有取消选择仅对本次生成有效，不持久化到叙事组或整集。
- 保持旧客户端、split-only 和现有 revision 行为兼容。

## 非目标

- 不为风格增加图片参考；风格只通过项目风格 Prompt 生效。
- 不引用场景反向图、DirectorWorld 控制图或全景视图。
- 不把叙事组图整体迁移到完整 `nanobanana_grid` 管线。
- 不增加长期保存的用户引用偏好。
- 不改变单镜 Render、草图网格或视频生成的既有资产规则。

## 方案决策

采用后端统一解析、前端只展示和取消的架构。后端是引用来源和路径的唯一可信边界，前端不拼装文件路径或 URL。相较于前端分别查询并拼装资产，此方案避免规则漂移和跨项目路径风险；相较于复用完整 Render 管线，它只引入本需求所需能力，回归面更小。

## 用户交互

生成 Sketch 或 Render 叙事组图前，打开“引用确认”面板：

- “视觉风格”显示项目风格名称与风格 Prompt 摘要，默认启用，可整体关闭。
- “角色参考”显示自动匹配的 Identity 图或默认肖像回退、覆盖镜头，默认全部启用；支持总开关和逐张取消。
- “场景参考”显示按 `scene_id` 匹配的场景主参考图和覆盖镜头，默认全部启用；支持总开关和逐张取消。
- 生成按钮显示最终将提交的图片参考数量。
- 无图、回退和因上游数量限制未提交的项目均明确显示原因。
- 关闭面板后不保存选择；下次打开重新按当前项目资产解析并默认全选。

## API 契约

### 引用预览

为指定项目、集数、叙事组和阶段提供引用预览接口。响应包含：

- `style`: 风格 ID、名称、Prompt、默认启用状态和警告。
- `character_references`: 不透明引用 ID、角色名、identity ID、来源类型、缩略图 URL、覆盖 beat、默认启用状态和警告。
- `scene_references`: 不透明引用 ID、scene ID、场景名、来源类型、缩略图 URL、覆盖 beat、默认启用状态和警告。
- `limits`: 上游图片参考上限、默认选中数量和被裁剪项目。

缩略图 URL 仅用于同项目内的授权预览；生成请求不回传文件路径或缩略图 URL。

### 生成请求

现有生成与重生成端点接受可选请求体：

- `use_style: bool`，默认 `true`。
- `selected_character_reference_ids: list[str] | null`。
- `selected_scene_reference_ids: list[str] | null`。

字段为 `null` 或旧客户端不发送请求体时，使用后端当前解析出的默认全选集合。空列表表示该分类明确全部取消。后端在入队前或 runner 执行时重新解析并校验不透明 ID，不接受任意客户端路径。

split-only 端点不接受或使用这些字段，只切割已有网格。

## 后端组件边界

新增叙事组引用解析单元，职责如下：

1. 从项目配置加载并解析 `visual_style` 对应的风格 Prompt。
2. 从本组 beats 提取角色名与身份标记。
3. 为每个实际出现的身份选择 Identity 图；缺失时选择角色默认肖像；均缺失时生成无图警告。
4. 从 beats 提取 `scene_id`，为每个实际场景选择场景主参考图；缺失时生成无图警告。
5. 对引用去重，汇总覆盖 beat，产生稳定、不透明的引用 ID。
6. 应用用户本次选择和图片数量上限，输出最终 Prompt 片段、图片路径和审计元数据。

该单元复用现有项目配置、身份解析、资产路径与授权能力，但不依赖前端状态，也不承担图片生成或任务状态写入。

## 生成数据流

1. 前端打开引用确认面板并请求后端预览。
2. 后端按当前项目配置、beats 和磁盘资产返回默认引用。
3. 用户临时关闭分类或取消单图。
4. 前端只提交开关与保留的不透明引用 ID。
5. 后端重新解析当前资产，验证 ID 属于该项目和叙事组；未知或越权 ID 返回 422，合法 ID 对应资产已失效时跳过并记录警告。
6. runner 构造最终 Prompt 与 `ImageGenerationRequest.references`，调用现有 GRSAI 图片能力。
7. 成功后沿用现有网格保存、切割、revision 和任务状态流程。

## Prompt 规则

最终 Prompt 按以下顺序组成：

1. 项目视觉风格硬约束。动漫风格必须明确二维动画、线稿/赛璐璐特征，并禁止照片写实与 3D 渲染。
2. 网格行列、阅读顺序、无文字/标签/重叠等结构约束。
3. 每格 beat 的画面描述。
4. 角色参考图与角色/身份的对应说明。
5. 场景参考图与 `scene_id` 的对应说明。

Render 阶段移除固定的 `finished cinematic frame` 媒介暗示，改成由项目风格决定渲染媒介。Sketch 阶段继续要求黑白分镜草图；项目风格只约束人物造型和二维/三维媒介倾向，不把草图提升为成片渲染。

## 图片引用顺序与上限

上游最多提交 9 张图片参考。顺序与裁剪优先级固定为：

1. 角色 Identity 图。
2. Identity 缺失后的角色默认肖像。
3. 场景主参考图。

同类内部按覆盖 beat 数降序，再按首次出场顺序排序，以保证结果稳定。超限项目在预览中标记为“因上限未提交”，不能静默丢弃。风格仅使用文本 Prompt，不占图片额度。

## 错误与降级

- 项目风格缺失或无效：回退项目默认风格并返回警告，不使用固定电影写实描述。
- Identity 图缺失：回退角色默认肖像；两者均缺失时保留角色文字描述并返回警告。
- 场景主参考图缺失：保留场景文字描述并返回警告，不阻断生成。
- 用户取消全部图片：允许纯 Prompt 生成；风格开关独立生效。
- 预览后资产被删除或替换：生成时重新校验，失效项跳过并记录警告。
- 伪造、跨项目或不属于当前叙事组的引用 ID：不解析为路径，生成请求返回 422 校验错误。
- GRSAI 失败：沿用现有任务失败和 revision 状态记录，不覆盖上一版成功图片。
- split-only：不解析引用，也不调用图片提供商。

## 兼容性

旧客户端不发送请求体时，等价于视觉风格、角色和场景三类全部按当前默认规则启用。现有路由别名、任务类型、输出目录、切图逻辑和 revision 记录保持不变。生成与重生成使用同一解析和选择规则。

## 测试策略

### 后端单元测试

- 动漫风格进入最终 Prompt，且包含禁止写实/3D 的约束。
- Identity 图优先，缺失时回退默认肖像。
- 只解析当前叙事组实际出现的角色和 `scene_id`。
- 引用去重、覆盖 beat 汇总、顺序稳定。
- 超过 9 张时按角色优先、覆盖数和首次出场顺序裁剪。
- 分类关闭、单图取消和全部取消正确生效。
- 伪造或跨项目引用 ID 不能转化为路径。

### API 契约测试

- 预览响应包含来源、类型、覆盖 beat、缩略图 URL、默认状态、上限和警告。
- 旧空请求保持默认全选行为。
- 空列表表示明确取消该分类。
- split-only 不触发资产解析或图片生成。

### Runner 测试

- `ImageGenerationRequest.references` 收到最终选中的实际图片。
- 最终 Prompt 包含风格、角色/场景映射和 beat 描述。
- 提供商失败不覆盖上一版成功结果。

### 前端测试

- 三类引用默认开启。
- 总开关与逐张取消状态一致。
- 生成按钮显示最终图片数量。
- 关闭并重新打开面板后恢复后端默认选择。
- 回退、缺图和超限状态可见。

## 验收标准

- 动漫项目的叙事组 Render 不再因固定 Prompt 默认偏向 3D 或照片写实。
- 角色 Identity 图存在时，同一身份跨镜头使用对应参考；缺失时明确回退默认肖像。
- 场景主参考图存在时，按 beat 的 `scene_id` 自动加入。
- 用户可在生成前关闭风格、关闭角色/场景分类或逐张取消图片。
- 用户选择仅影响本次生成，且不能提交任意本地或跨项目路径。
- 参考图超限、缺失或失效均有可见且可测试的降级行为。
