# 创作节点与项目设置交互设计 A

日期：2026-10-17。状态：设计已确认，用户已授权子代理分工实现。

## 目标与已确认方向

画布节点显示成果摘要、准确状态、版本和一个主要入口，长内容进入大工作区。返回恢复画布位置和选择。沿用 Nuomi 深色界面与现有强调色，不把示例状态作为真实项目数据。

本轮用户已确认专业剧本阅读优先、导演方案与媒体生成分离、出图节点宫格模式及拆单帧、可选生成模型高清剪裁、角色声音与正式配音分离、项目设置左右分栏。

## 专业剧本

默认阅读正文，左侧定位关联文档与场次。显式进入编辑；选段后展开主笔修改入口。修改结果先比较再采用。保存生成新版本，不覆盖已采用引用。采用与交接分别操作：预览差异并确认交给导演，不自动开始媒体制作。保留规划确认、任务停止及失败恢复能力，按当前阶段显示，避免同时堆满工具栏。

## 导演与画布生成链路

默认组分镜审阅：左侧场景与叙事组，中间图板/镜头表/时间预演，右侧选中组或镜头的详情。调度、来源审阅和版本信息按需展开。时间预演使用已有媒体或诚实占位，不调用生成。

导演工作区仅编辑、采用方案和审阅回传结果，不直接生成图片或视频。采用后提供“在画布中打开组分镜”，以项目、集、组及导演版本定位复用节点，避免重复创建。

连接顺序：导演方案 → 组分镜 → 出图节点（宫格模式）→ 独立单帧 → 后续处理或视频节点。以叙事组组织，不将生产单元改成逐镜头任务循环。镜头顺序、描述及角色场景参考传递至出图节点，明确显示来源版本。

## 宫格与拆帧

宫格模式在出图节点内选择布局、模型、参数和参考素材，显式发起生成并展示进度、失败及重试。生成结果可回显分镜图板，但执行入口仍在出图节点。

拆帧先选择格子、确认顺序和裁切范围，再输出独立单帧节点。布局与镜头数量关联；空格不映射镜头。每帧保留源宫格结果版本、格位置、裁切范围及镜头映射。

- 默认直接裁切：只裁切已有图片，不调用模型。
- 可选“高清剪裁”：用户明确要求用生成模型重新提取高清单帧，允许画面细节变化。开启后选择支持参考图的已配置模型，按模型能力展示尺寸与参数。未配置模型不可提交。
- 保留原始裁切与高清结果供对比和选择。高清提取显式启动并说明模型用量；按帧显示成功或失败，仅重试失败帧，不重跑已成功结果。
- 上游修改提示来源已更新，保留旧图和旧帧，不自动覆盖或重新生成。重复加入同一来源帧时定位已有节点；新结果保留独立版本。

## 角色声音

工作区负责选择角色、设计音色/导入参考/复用声音、生成试听候选、试听和采用音色。试听生成需显式触发，不是正式剧本配音。

候选采用和画布节点绑定具有不同含义：采用使声音成为角色可引用版本；绑定固定节点使用的准确版本。新声音不自动更新已绑定节点或旧配音。保留现有“已试听，确认适合角色”的采用要求。

正式配音通过连接独立配音节点执行：角色声音节点 → 配音节点 → 音频结果。工作区返回画布不自动发起正式配音。无角色、无候选、未采用及已绑定状态分别引导下一步。

## 项目设置

左侧四类导航，右侧直接嵌入内容：项目 Agent、默认风格与手法、创作对象与约定、创作模板。消除入口弹窗再叠加内容弹窗的路径，保留现有类别能力和权限。

项目 Agent 管理项目成员与专业配置，不自动委托执行；创作对象与约定复用现有对象关系与约束；模板保留固定版本、应用预览与明确确认。三个类别的详细表单沿用现有业务字段，本轮不扩张数据模型。

默认风格与手法从真实目录选择并固定版本，右侧说明影响范围。配置优先级为节点、分组、画布、项目中最近一层明确配置；禁用本级与取消本级继承不可混同。项目设置入口默认作用于项目，局部调整仍在节点上下文进行。

按类别保存或采用，不建立含糊的跨类别一键提交。固定配置保存前预览范围与版本；没有有效变更时禁用提交。保存不会改写已有产物或自动生成。切换分类、离开时保护未保存草稿，失败保留输入。

## 通用状态、可访问性与验证

所有异步操作区分待执行、进行中、成功、失败、来源过期；防止重复提交，错误在对应区域给出恢复动作。选择、保存、采用、绑定和生成不互相隐式触发。旧上下文异步结果不得写入新项目或节点。

长内容局部滚动，主操作保持可见；窄窗口导航收拢、详情按需打开。正文约 14–16px，辅助文字至少 12px，状态不只靠颜色表达。键盘可操作，关闭面板返回触发入口，切换和关闭保护草稿。

实现验证需覆盖版本隔离、无隐式生成、节点复用、宫格镜头映射、直接裁切不调用模型、高清模式显式调用与单帧失败恢复、声音采用/绑定区分、设置作用范围及草稿保护。浏览器验证使用固定数据，不为验收付费生成。
