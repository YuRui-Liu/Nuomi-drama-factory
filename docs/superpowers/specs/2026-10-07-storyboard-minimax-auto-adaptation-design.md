# 叙事组分镜到 MiniMax 的自动适配

日期：2026-10-07。状态：方案和书面规格已获用户批准，进入实现。

## 目标与边界

修复画布叙事组分镜接到 MiniMax H3 后没有逐镜头输入的问题。用户确认每格代表独立镜头，并选择自动适配，不增加独立拆图节点。生产单位仍是叙事组：一个组视频节点持有多个片段，经现有 Director 时间线一次编排；禁止改成逐镜头调用供应商的脚本循环。

已有问题：编排适配器把上游图片统一追加到 references；没有把分镜单格绑定到片段首帧。现有 Director 校验禁止 references 与首尾帧混用。单纯增加连线不足以修复。

## 数据流与职责

1. 分镜节点保留整组图、行列数、逐镜头描述和时长。拆图服务读取实际图片，按从左到右、从上到下输出单格资产，不使用仅供显示的 CSS 裁剪。
2. 每个单格记录来源节点、来源图片版本或内容指纹、格序号、裁剪矩形、输出资产 URL。拆图结果保存在分镜节点，刷新后可恢复并预览。
3. 独立的适配逻辑把单格资产映射到 Director draft.segments；每格对应一个稳定片段 ID，firstFrame 使用该格，lastFrame 默认空。不得把相邻独立镜头当成首尾帧。
4. 前端显示和编排提交复用同一适配契约；提交前冻结来源版本、片段、模式及提示词，避免画布显示与实际请求不一致。
5. 新计划生成逐格结构化镜头信息。旧画布优先恢复已有镜头计划；无可靠逐格描述时显示待补全，不能将整组提示词复制到所有片段或凭空猜测映射。

## 图片与时间规则

规则宫格使用明确的行列及整数像素边界裁剪，覆盖全部有效格；支持不能整除的图片尺寸。生成提示词要求等大、无文字、无边框的格子。旧图有留白或不规则分隔时允许调整裁剪区域，不声称自动识别任意边框。

单格按组视频目标画幅等比缩放并补边，不拉伸或静默裁去主体。原始裁剪资产保留。缺失图片、无效行列、空格或不可解码图片阻止适配并定位原因。

优先采用逐镜头计划时长；仅有组总时长时按有效镜头数均分，以当前 H3 帧率对齐，余数确定性分配，请求总帧数保持不变。现有 H3 适配器还会将每段实际生成帧数向上对齐到 17k+5，因此实际生成时长可能增加：例如 18 秒均分四段，请求每段 4.5 秒，实际每段 124 帧，合计约 20.67 秒。准备结果和界面分别显示请求时长与实际对齐时长；不修改供应商帧数规则，也不声称两者相同。若现有能力校验拒绝时长则显示具体片段错误，不自动缩短组时长。画面提示词采用对应镜头描述，加组级风格约束。

## 模式与编辑保护

自动适配选择 frames 模式，提交投影清空 references；角色参考及整组分镜图继续用于上游创作，不作为该次视频请求的主体参考输入。手动 Ref 模式保留，显式选择 Ref 后不自动切回。首帧模式和 Ref 模式的参数在最终提交入口统一校验。

保存自动生成字段的基线和来源指纹。来源未变化时重复适配幂等，不重复创建片段或资产。来源变化时旧绑定标记过期，禁止提交旧帧。没有手动改动的字段可重建；检测到用户修改时保留修改并显示冲突，用户选择保留或重新适配后才提交。用户手动添加的尾帧不得被后台静默清除。

画布先持久化适配结果再提交生成；版本冲突重新读取并提示，不覆盖他人的更新。拆图或适配失败不触发付费请求，可重试复用成功资产。

## 现有画布恢复

通过公开画布 API/生产 CLI 更新当前画布。重新读取最新状态，以实际存在的分镜图片为准；此前第 1、4 组已有图片，可以拆图，其他组等待图片输出后适配。保持节点 ID、既有连线、原图及视频结果。已产生视频但来源变化时标记过期，不删除旧视频。

## 验收

- 图像测试：2×2 和非方形宫格顺序、非整除尺寸、无效图片、目标画幅处理及重试幂等。
- 契约测试：N 格生成 N 个片段，各自首帧 URL 正确，尾帧默认空；总帧数保持；缺失描述明确阻塞。
- 模式测试：frames 最终请求没有 references；手动 Ref 保持原行为；直接按钮和编排入口一致。
- 状态测试：重生成失效、手动编辑冲突、刷新恢复、保存版本冲突均有覆盖。
- 画布验证：逐格预览与片段首帧一致，检查真实提交入口冻结的数据及任务回写。使用现有公开生产入口进行组级视频验收，报告实际成功、失败或阻塞，不把模拟提交当成已出视频。

## 不包含

不增加独立拆图节点，不实现跨镜头自动变形转场，不重构其他供应商，不批量重做已有素材，不通过直接供应商脚本绕过生产入口。
