# 场景环境提示词质量门设计

## 背景与问题

单集场景规划调用统一的 `enrich_scene_environment_from_context()` 生成基础场景的 360° 环境提示词。当前实现只检查“正面、左侧、右侧、背面”四个标题是否存在；当模型调用异常或输出缺少标题时，`_ensure_directional_environment_prompt()` 会把内部写作规则拼成结果并正常落库。

现网 `test2 / 广播站设备走廊` 的数据库记录、编辑弹窗和实际场景主图 prompt 文件均包含“最能代表地点身份”“根据原文证据”“布置与场景功能一致”“合理连续补全”等元指令，证明污染发生在后端生成与落库阶段，而不是前端展示阶段。该场景主图已经使用污染后的提示词生成。

## 目标

- 只允许具体、可视、可直接用于出图的基础场景空间合同落库。
- 模型首次输出不合格时自动定向重试一次。
- 第二次仍不合格时终止场景规划，不静默降级、不生成场景参考图。
- 重新规划能够识别并修复历史元指令模板，不覆盖正常提示词或用户手工内容。
- 提示词被修复后，保留旧参考图但明确标记其需要重新生成。

## 非目标

- 不自动删除历史场景图片。
- 不自动提交付费图片重生成任务。
- 不改变派生场景的时间、天气和剧情状态管理。
- 不修改项目视觉风格选择或图片模型路由。

## 质量合同

### 结构要求

最终 `environment_prompt` 必须包含七个固定段落：`正面：`、`左侧：`、`右侧：`、`背面：`、`光源：`、`材质/风格：`、`禁止元素：`。

四个方向段落必须各自包含具体可见的空间实体或固定设施，并描述实体之间的方位、连接或纵深关系。光源段落必须给出固定光源种类与方向。材质段落必须给出墙、地、顶、门窗或固定设施中的至少两类材质信息。

### 禁止内容

最终结果不得包含“最能代表地点身份”“根据原文证据”“布置与……功能一致”“合理补全”“合理连续补全”“可为……”“必须构成完整 360 度”“使用中性默认状态”“保持 interior/exterior/nature 场景”等元指令，也不得包含要求模型执行写作动作的“应当、需要、请、不要复制”等表达。

基础场景不得固化人物、人物动作、临时剧情道具、字幕、水印或单次剧情事件。出现时间只用于理解空间用途，不能把深夜、黄昏、暴雨等光照状态烘焙进基础场景；这些内容继续由派生场景或时间 plate 表达。

## 生成与重试流程

1. 场景规划器收集场景名、室内外类型、原文场次证据和故事梗概。
2. 第一次调用场景 enrich 模型，得到结构化 `SceneEnrichment`。
3. 纯函数质量检查器检查七段结构、方向具体性、光源与材质信息、元指令和剧情污染。
4. 合格结果直接构造 `NovelScene`。
5. 不合格结果不进入兜底模板；系统把具体问题列表和被拒绝输出附加到同一场景上下文，进行一次修复调用。
6. 第二次结果再次执行同一质量检查。
7. 第二次仍不合格或调用异常时抛出 `SCENE_PROMPT_QUALITY_FAILED`，包含场景名和问题摘要。任务失败且不写入该场景。

模型调用异常也允许进入第二次调用；不存在返回元指令模板的成功路径。

## 历史数据修复

新增严格的历史污染识别函数，只匹配当前已知兜底模板的稳定短语组合。单独出现普通词语不视为污染，避免覆盖用户内容。

重新规划场景时，正常且非污染的非空提示词继续保留；命中历史污染模板的提示词视为需要 enrich，重新经过两次调用与质量门。修复成功后更新 `environment_prompt`，并在场景记录中写入机器可识别的“参考图需重新生成”状态。已有主图、反向图和全景图继续保留，不自动删除或重新付费生成。

场景资产界面在该状态下显示“提示词已更新，现有参考图来自旧提示词，请重新生成”。任一新的场景参考图成功采纳后，清除对应的过期状态；在所有受影响参考图更新前，不把旧图描述为与新提示词一致。

## 数据边界

- `cognee.pipeline` 负责提示词质量检查、重试和错误定义。
- `AssetCompiler` 负责在重新规划时识别历史污染并触发 enrich，不复制质量规则。
- SQLite 场景记录保存修复后的提示词和参考图过期状态。
- 场景 API 只暴露状态；前端只显示状态和重新生成操作，不在前端修补提示词文本。
- 场景参考图 runner 在成功采纳新版本后清除相应过期状态。

## 错误处理

失败消息格式为 `SCENE_PROMPT_QUALITY_FAILED: <场景名>: <问题摘要>`。任务中心显示该错误，场景规划不得报告“完成”。若一批场景中任一新建或历史修复场景未通过质量门，整次规划任务失败，避免出现部分场景已落库、部分场景未落库的模糊结果。现有正常场景不受影响。

## 测试设计

- 质量检查器接受包含七段、具体实体、光源和材质的有效提示词。
- 质量检查器拒绝当前截图中的元指令模板。
- 首次无效、第二次有效时只保存第二次结果，并验证调用两次。
- 两次无效时抛出 `SCENE_PROMPT_QUALITY_FAILED`，不返回 `NovelScene`。
- 首次调用异常、第二次有效时可以恢复。
- 重新规划会替换历史污染模板，但不会覆盖正常提示词和用户手工提示词。
- 修复历史提示词后，现有参考图被标记为需要重新生成。
- 新参考图成功采纳后清除对应过期状态。
- 单集场景规划任务收到质量错误时状态为失败而不是完成。

## 验收标准

- 新生成的场景环境提示词不含任何已知元指令模式。
- `广播站设备走廊` 重新规划后得到具体的空间实体、设施、材质、固定光源与四向关系。
- 两次不合格时不落库、不出图，并在任务中心显示明确错误。
- 当前已有坏提示词能够通过“重新规划场景”修复。
- 已由旧提示词生成的参考图不会被静默视为有效，也不会被自动删除或付费重生成。
