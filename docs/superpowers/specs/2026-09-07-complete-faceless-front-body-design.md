# 身份三视图完整无面部正身设计

## 背景与根因

Identity Sheet v2 的中间面板原本用于提供角色正面体型与服装信息，同时避免成为第二个脸部身份源。当前实现把该目标解释成“无头正面全身”：生成提示要求颈部以上为空，确定性合成器又将中间面板顶部 22% 覆盖为背景色，QC 还把任何头部都视为缺陷。

因此截图中的头部缺失不是模型随机裁切，而是提示、合成和 QC 三层共同执行的既定行为。它错误损失了发型外轮廓、头身比例、颈肩连接和完整构图。

## 目标

- 中间面板保留从头顶到脚底的完整正面全身构图。
- 保留头发、头型、耳部外轮廓、颈部和头身比例。
- 中间面板不出现眼睛、眉毛、鼻子、嘴唇等可识别五官，不成为额外脸部身份源。
- 删除对头部区域的确定性覆盖，不再产生断头或上沿裁切效果。
- QC 接受完整头部轮廓，只拒绝可识别人脸、五官或额外脸部。
- 用户界面明确说明“无面部”不等于“无头”或“裁切”。

## 非目标

- 不修改左侧 3/4 脸部母版的构图规则。
- 不修改右侧背面全身规则。
- 不修改普通角色头像生成。
- 不引入人脸检测、分割、模糊或贴片式后处理依赖。
- 不迁移既有版本元数据。

## 方案

### 生成提示

中间面板从 `HEADLESS FRONT FULL BODY` 改为完整无面部正面全身：

- 人物必须正面、中立站立，从完整头顶到完整鞋底全部入镜。
- 头部、头发、耳部轮廓和颈部必须完整，不得被画面边缘裁切。
- 面部区域采用与当前画风一致的平滑中性表面，不生成眼、眉、鼻、嘴、胡须或其他可识别面部特征。
- 不允许面具、面纱、物件、血腥伤口或空洞替代面部，避免引入新的服装/道具语义或恐怖效果。

左侧 Portrait 继续是唯一的面部身份权威；中间面板只提供完整比例、发型轮廓与服装正面信息。

### 确定性合成

删除 `FRONT_HEAD_SAFE_ZONE_RATIO` 以及中间面板顶部背景覆盖。合成器继续：

1. 按 50% / 25% / 25% 分割模型候选图。
2. 将 Portrait、正面全身、背面全身分别等比缩放并居中拼入固定面板。
3. 保留正面源面板的全部有效内容，不执行面部涂抹或头部裁除。

现有 `fit_crop` 仍负责把各面板适配到固定画布。提示词要求主体在安全边距内完整入镜，以避免等比居中适配时切到头脚。

### QC

保留稳定问题码 `front_face_detected`，但更新其语义：

- 允许完整头部、头发、耳部外轮廓和颈部。
- 检测到眼睛、眉毛、鼻子、嘴唇、可识别人脸、面具上的脸或额外人脸时才置为 `true`。
- 头顶或脚底被裁切归入稳定布局失败；不再把“有头部”本身当作失败。

不新增供应商特定错误码，保持 API 与现有前端问题映射兼容。

### 兼容性与命名

持久化元数据中的面板键 `front_headless` 已存在于历史版本、API 响应和前端类型中。本次保留该机器键，避免迁移旧资产；仅更新其运行时语义与用户可见文案。

中文标签改为“无面部正面全身”，英文标签改为“Faceless front full body”。说明文案明确其保留完整头身，只隔离可识别五官。

## 数据流

1. 角色身份生成器编译新的完整无面部正身提示。
2. 图像模型返回 50% / 25% / 25% 三面板候选。
3. 合成器替换左侧 Portrait，并原样保留中间、右侧面板的有效图像内容。
4. QC 检查左侧唯一脸源、中间无可识别五官、右侧无回头露脸及整体一致性。
5. 前端展示旧机器键对应的新“无面部正面全身”标签和解释。

## 错误处理

- 模型若在中间面板生成可识别五官，QC 以 `front_face_detected` 拒绝候选，不通过裁切来掩盖。
- 模型若裁掉头顶或脚底，QC 以布局/状态一致性失败拒绝候选。
- QC 不可用时继续沿用现有 fail-closed 行为，不自动采用候选。

## 测试策略

先增加失败测试，再修改生产代码：

- Prompt 测试：要求完整头顶到脚底、保留头部轮廓、禁止可识别五官；不再包含 `HEADLESS`、`neck up empty` 等语义。
- 合成测试：给中间源面板头部区域写入独特色块，断言输出顶部对应内容被保留，而不是背景灰。
- QC Prompt 测试：断言完整头部被允许，只有具体五官/可识别人脸触发 `front_face_detected`。
- 前端测试：断言中文/英文显示“无面部正面全身 / Faceless front full body”，且说明不再描述无头策略。
- 回归测试：运行 identity sheet、identity QC、角色状态版本组件的定向测试及相关类型检查。

## 验收标准

- 新生成的中间正身从头顶到脚底完整可见，没有顶部灰色覆盖或断头。
- 中间正身保留发型外轮廓、头型与颈肩连接，但没有可识别五官。
- 左侧 3/4 Portrait 仍是整张图唯一的可识别脸部。
- 错误生成可被 QC 拒绝，而不是由合成器裁掉头部伪装成合格。
- 既有 `front_headless` 元数据无需迁移，历史版本仍能正常展示。
