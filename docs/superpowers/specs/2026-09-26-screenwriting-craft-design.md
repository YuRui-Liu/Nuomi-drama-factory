# Nuomi 剧本技能创作升级设计

日期：2026-09-26。状态：用户已确认设计方向；书面规格待审阅。

## 1. 目标与范围

升级 `nuomi-drama-scripts`：人物具有具体欲望、矛盾和关系质感，同时具备短剧的冲突、情绪回报和追更吸引力。保留项目自身题材与气质，不把所有作品统一写成打脸升级剧。不承诺平台留存数据或专业质量可由自动检查证明。

本次覆盖技能入口、创作参考模块、项目模板、审稿流程、使用说明和创作验证样稿。保持现有单集格式、导出协议和文件交接边界。媒体生成、平台发布、后端产品改造、全剧重写不在范围内。

《山海拾遗》用于验证通用方法；候选改写保存为独立评估材料，不直接覆盖原稿或改变已确认事实。正式替换原稿属于后续修订任务。

## 2. 诊断依据

- 来源台账已有 short-drama，但工艺模块主要停留在原则与字段，缺少可操作步骤、对照片段和审稿证据要求。
- 已抽读 E001、E002、E010、E030、E038、E045、E060；角色职业和知识边界清楚，私欲与关系弱点展开不足。部分分歧迅速收束为核验、记录和协商。
- E045、E060 部分动作说明在解释没有违反设定，挤占可表演内容。E038 的“不用再热水了”体现动作与潜台词，应保护此类有效写法。
- 对 60 集去除 frontmatter 后统计，双破折号仅 2 处。因此标点不得作为 AI 味或创作质量的充分判据。
- 现有全剧自审以结构、连续性和制作约束为主，缺少对场景博弈、关系变化和情绪兑现的证据审查。

## 3. 方案选择

采用创作与审稿流程重构。语言修补只能处理表层；固定时间点和反转配额容易增加机械感，均不作为主方案。

统一创作逻辑：私人欲望带来选择，选择触碰他人利益，阻力逼迫角色改变策略，结果改变处境或关系，观众得到情绪回报并期待下一步。允许安静场景和留白，只要其注意力与情绪功能具体。

## 4. 模块职责

| 文件或模块 | 职责与输入输出 |
|---|---|
| `SKILL.md` | 路由、前置条件与样稿关卡；将工艺要求置于创作阶段，格式要求留在交付阶段 |
| `references/story-development.md` | 从简报得到私人欲望、自我欺骗、代价、关系矛盾和人物弧线；与圣经事实约束衔接 |
| 新增 `references/character-and-dialogue.md` | 人物声音、对话策略与潜台词；输入人物和场景目标，输出角色行为依据及对白修订方法 |
| `references/screenplay-craft.md` | 场景双方目标、策略变化、可见行为、转折与退出状态；不要求每场都争吵或不可逆升级 |
| `references/short-drama-rhythm.md` | 开场失衡、集内回报、集尾压力及下集兑现；区分好奇、危机、关系与情绪期待 |
| 新增 `references/language-editing.md` | 识别作者说理、设定解释、无效否定句、重复与虚假停顿；配原创正反例及适用边界 |
| `references/review-rubric.md` | 分开记录创作、连续性和交付结论；每个问题包含原句或场次、影响、返工要求与复核证据 |

按阶段加载相关模块，不把全部参考文件塞入每次任务。分析字段保存为创作工作材料，不进入可交付剧本。优先扩展已有文件，新增模块仅承担独立职责。

## 5. 创作流程

### 人物与关系

主要角色至少明确：当下想得到的具体东西、不能承认的动机、习惯性应对方式、关系软肋、愿意支付与拒绝支付的代价。用一件可演事件证明矛盾，不以性格形容词或口头禅替代人物。

每条主要关系说明双方各想从对方获得什么、各自误解什么、什么行为会伤害信任。不得为制造戏剧性强加悲惨身世或违背既有人设。

### 场景与短剧节奏

重要戏剧场景明确目标、阻力、尝试、策略变化和结果；过渡、余波与静观场景明确情绪或叙事作用即可。事件必须由已建立的条件和角色选择支持。

开篇尽快给出可感知的异常或失衡、角色当下目的和失败代价，避免先讲世界观。每集兑现一个有具体证据的观看回报；结尾压力须由正文产生并在后续承接。终集允许完整收束。

钩子可来自选择、谎言、关系、危机、发现或情感余波。禁止通过无缘由遮挡信息、突然来人和无意义断句代替悬念。不设固定秒数、反转配额、金句数量或打脸比例。

### 对白与语言编辑

对白先确定说话者想让对方做什么，再选择试探、诱导、威胁、讨好、回避等符合角色的策略。允许直说，也允许口误、沉默和答非所问；不能为了潜台词而把所有话写成谜语。

用词、句式、观察对象和关系中的态度共同区分声音。检查角色名遮挡、台词互换和设定复述，结果须结合上下文解释，不以口头禅数量判断个性。

完成场景与对白后单独编辑语言：删去作者评语、对未发生套路的说明、动作与对白的信息重复、工整的主题总结和无效停顿。破折号与省略号按真实打断、改口、犹豫保留，不设置零容忍规则。不得删掉有信息或情绪作用的否定句。

## 6. 样稿校准与旧项目兼容

新项目在既有简报、圣经、节拍关卡之后，先完成代表性样稿与创作审查，再进行长篇批量生成。样稿覆盖开篇、关系冲突、情绪回报；短项目可用不同场景覆盖，不强制新增三集。

旧项目先读取已确认稿件和审查，定位局部问题并做影响分析。保留事实、原典边界、人物知识状态和上下集承接；若改进依赖架构变动，单独列出冲突及备选方案，由用户确认后调整架构。

样稿审查未解决 P1 时返回对应工艺步骤，不以填满字段或格式通过解锁批量创作。用户明确要求继续时保留未解决项和草稿状态，不把风险写成已通过。

## 7. 验证与验收

《山海拾遗》采用 E001（开篇）、E045（关系冲突）、E038（重大损失）为代表样本。实施时先读取各自上下集、圣经与相关节拍，再形成原稿/候选稿对照及影响分析。禁止通过更改死亡事实、增加能力或破坏题材气质换取刺激。

每份对照至少说明：保留的有效部分、主要缺陷、改写后的行为因果、对白策略、情绪回报、钩子与承接，以及仍有争议的部分。按以下维度给出具体文本证据：

1. 人物是否为自己的欲望行动，选择是否付出代价。
2. 场景是否发生策略或关系变化，而非只有信息报告。
3. 对白能否体现人物和关系，是否适合开口表演。
4. 观众获得什么回报，又为何期待下一步。
5. 是否减少无效说理、重复与停顿，同时保住有效留白。
6. 事实、连续性、原典与交付格式是否保持一致。

用户对样稿效果的判断是创作质量的最终校准依据。编写者自审必须明确标注，不冒充独立编辑或观众测试。没有实际留存实验，不宣称优化了平台数据。

技能验证包括路由与模板可用性、引用路径、既有契约检查及候选单集格式检查；不以文档关键词测试证明创作能力。无需运行与本次文档技能改动无关的后端、媒体或前端全量测试。
