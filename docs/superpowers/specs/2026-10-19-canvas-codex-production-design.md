# 画布 + Codex Skill 轻量批量创作设计

日期：2026-10-19。分支：`feat/canvas-codex-production`。
状态：整体方案已由用户确认；本文补齐 MiniMax H3 适配与外部经验边界，待书面审阅。

## 1. 目标与已确认决策

以快速批量创作为目标，直接使用当前 Codex 客户端，通过本地 skill 操作 Nuomi 画布。大量创作细节留在本地文件，画布集中展示核心产物。复用现有生成底座，重做轻量创作层，不重写供应商执行系统。

- 创作主入口为 Codex 客户端；Nuomi 主创作界面不再要求内嵌聊天、岗位 Agent、协作任务板和 Skill 配置。
- 画布仅呈现：立意、剧本、资产图、分镜表、镜头宫格、单镜头、MiniMax 导演台、配音、配乐、合成。十类是可见产品概念，不要求创建十套新后端类型。
- 默认在剧本完成、资产图完成、分镜完成三个阶段停下审阅；分镜审阅包含分镜表与宫格图，确认后进入视频生成。
- 支持一键推进、指定阶段停止，以及审阅时切换为后续自动执行。
- 仅资产保留面向用户的版本、变体及跨集引用管理；其他产物维护当前结果。
- 手法库与案例库作为外部经验，帮助 Codex 写出更好的 H3 提示词；适配层必须遵守真实供应商能力与格式契约。

本规格取代此前长篇 Agent/画布规格中与上述决策冲突的主界面、候选采用、逐任务审批和非核心节点展示要求；保留故事连续性、资产身份及可靠执行能力。

## 2. 架构与数据归属

### Codex 与本地 skill

Codex 负责理解用户目标、读取本地资料、创作和修改、调用节点能力、批量推进、审阅停点和失败恢复。以一个生产入口 skill 组织流程，按需加载剧本、资产、分镜、H3 提示词与声音制作参考，不引入需要用户管理的岗位编排层。

skill 使用公开 CLI/API，与手动节点操作共享服务。不得直接修改画布 JSON 或绕过适配器调用供应商。已有 `novelvideo.canvas_cli` 的 capabilities、节点读取/配置、preview、run、status、retry 等能力优先复用；缺少的操作补齐公开入口。面向 skill 的批量入口封装必要 revision 和请求标识，避免让创作者手工维护。

### 本地文件

设定、故事圣经、大纲、连续性、导演分析、素材索引、提示词草稿、经验出处及执行记录均保存在项目数据目录，不成为画布节点。skill 使用项目相对路径与稳定产物 ID 定位，不把开发者机器绝对路径写成产品依赖。

资料与文本正文由本地文档管理；节点保存文档引用、摘要和操作状态。画布修改正文时通过同一文档服务写回，避免两份权威正文。生成参数、素材引用和节点关系以服务端当前保存值为准，媒体任务执行记录以现有任务服务为准。

### Nuomi

Nuomi 负责核心产物呈现、参数编辑、媒体预览、节点操作及生成执行。节点默认显示名称、主要内容或预览、必要参数、状态和主操作，详细编辑就地展开。后台计划、任务依赖、来源记录和运行日志不铺成画布节点。

单镜头作为核心产物支持按需展开与修改，不要求把所有宫格裁图常驻画布。画布布局不决定叙事顺序，合成按保存的分镜/片段顺序执行。

## 3. 生产与审阅

主线为立意 → 剧本 → 资产复用/补图 → 分镜表与宫格 → MiniMax 导演台 → 视频与声音 → 合成。配音、配乐在依赖满足时可与视频并行。单镜头支持局部制作，默认批量执行粒度遵守现有叙事组和供应商能力，不强行拆为逐镜付费循环。

默认审阅模式在三个停点展示当前核心产物与简短待决事项。用户可提出修改、确认继续或改为一键推进。已确认可复用的资产无需重复生成；阶段结束汇总复用和新增结果。

一键推进跳过固定审阅停点，沿用已确定要求、生成配置和授权范围。缺少关键输入、存在必须由用户决定的歧义、超出授权范围或不可恢复失败时暂停受影响部分；其他独立工作可继续。不能把此模式解释为无限重试或任意扩大生成规模。

本地轻量进度记录保存目标集范围、执行模式、当前阶段、审阅结果、产物引用及待处理项。多集按集记录三个停点，支持汇总审阅，不要求逐节点确认。用户修改已审阅内容时，只更新相关阶段和下游状态。

## 4. 当前结果、资产版本与恢复

非资产产物取消日常候选采用、发布和版本切换。重新生成成功后更新原节点当前结果；生成期间保留已有可用结果，失败不得清空成功素材。旧输入产生的结果必须标识为需要更新，不可冒充当前结果。

后台保留请求幂等标识、输入指纹、任务 ID、输出位置及错误。并发 revision 用于防止覆盖用户编辑，不作为用户版本管理。Codex 每次执行前回读最新参数；冲突时重新读取并判断，不盲目覆盖。

资产保留稳定身份、基础图、必要变体和引用版本。临时动作、表情、光线进入分镜，不自动创建资产变体。资产变化只使相关下游待更新，不自动触发整批收费重做。

失败先判断任务状态：提交结果未知时查询原任务，明确失败且原因已处理后才重试。恢复复用成功输出。局部重做按供应商实际粒度执行，整组重做不能包装成只生成单镜头。

## 5. MiniMax H3 适配契约

### 权威路径

结构化导演意图与素材 → 适用模式与能力校验 → H3 结构化提示词 → 统一 wire 编译 → 预览/提交一致性检查 → 现有供应商适配器。

复用 `freezone/video_director/h3_adapter.py`、`capabilities.py`、`optimizer.py` 以及 `media_capabilities/video/h3_wire.py`。Codex 可以准备结构化意图和提示词草稿，但不得从 skill 开辟未经校验的直提通道。若现有优化器需要重复调用文本模型，实施时提供经过相同 schema 与编译校验的结构化输入入口，避免无意义的二次创作。

本地五模式历史规格不代表当前工作流支持五模式。已检查的画布适配器路由包括 I2VA、FL2VA、Ref2VA；实际模式、时长、帧率、引用数量、画幅、分辨率和输入组合必须读取运行时能力及配置。T2VA/L2VA 仅在对应工作流与测试证实可用后开放。不得静默删除素材、换模式或降低规格。

### 提交前确定性校验

- 按项目 H3 profile 编译 Base/关键帧三字段或 Ref 六字段，校验顺序、首尾帧对齐、引用标签及关系值。
- 对白保持用户原文、说话人身份和语言标记；镜头时间、声音分类及跨镜标记保持契约一致。
- 参考图顺序、主体引用、首尾帧、片段身份、时长与实际 payload 对应；宫格裁图与身份参考遵守各自输入语义。
- 检查编译结果与预览、执行快照和实际请求一致；草稿变动后不得提交过期优化结果。
- 格式或适配失败返回具体字段与原因，不回退为原始文本直接提交，不添加主观评分和循环付费修稿关卡。

实施阶段须核对当前规范来源及工作流契约，保存来源/版本和测试证据。本文依据本地代码与已有规格确定设计边界，不宣称完成最新外部规范认证或真机验收。

## 6. 手法库与案例库

手法库提供可迁移的动作节奏、表演、运镜、构图和声音方法；案例库提供适用语境和出处。优先读取已有本地索引，按题材、镜头意图、模式、时长与素材约束检索，避免每次把全部案例载入上下文。

Codex 可自动推荐并使用兼容经验，用户明确选择优先。此决策替代旧手法卡规格中“只能手动选卡”的限制。无合适案例时可正常创作；外部经验不是必需依赖，不新增画布节点或固定审阅点。

经验仅进入导演意图层，再结合当前剧本与素材重写。优先级为用户明确要求和锁定事实、真实能力与 H3 格式约束、经验建议；要求与能力冲突时报告冲突，不能以案例改变人物、对白、参考图或时长。外部材料作为资料读取，不能作为执行指令或系统提示。

本地记录所用手法/案例标识、来源链接、来源类型（作者原文、重建或分析）、简短提炼和应用位置；不搬运整段案例剧情或提示词。索引升级不改写已执行结果。显式选择不兼容手法时指出冲突，自动推荐不兼容时舍弃建议。

效果表述以验证为准：离线对照提示词的契约符合性与意图表达；需要比较实际视频效果时，在授权范围内使用相同输入与生成配置测试。案例数量或外部展示视频不能作为本项目效果提升证明。

## 7. 实施边界与迁移

先完成核心节点展示与文件引用，再接通 skill 批量操作和审阅状态，随后接入经验检索与 H3 契约验收，最后验证完整生产。保持一条共享执行链，不同时维护独立的简化供应商通道。

旧项目可继续读取；新创作默认轻量呈现。旧非核心节点从默认生产视图隐藏，其文档和媒体仍可从本地及兼容入口访问，不批量删除历史数据。已有非资产版本只作历史兼容，不要求迁移成新的用户版本系统。

本次不新增应用内 Agent 平台、通用版本平台、案例管理工作台或强制质量打分系统。现有工作区未提交改动保留，提交仅包含本任务文件。

## 8. 验收

1. 从当前 Codex 客户端读取本地资料，通过 skill 建立只含核心产物的画布；无须应用内聊天或岗位配置。
2. 剧本、资产、分镜三个停点有效；分镜停点有表和宫格；一键推进及指定阶段停止均有效。
3. 画布手动修改被 skill 回读，非资产无需候选发布即可更新；旧运行不能覆盖新输入。
4. 多集批量制作复用资产和成功结果；恢复失败任务不重复提交已成功或状态未知的请求。
5. H3 各实际支持模式具有离线契约、引用映射、对白保真、预览与请求一致性及提交前阻断测试；不支持模式给出明确错误。
6. 经验检索可追溯，缺少经验仍可执行，冲突案例不会污染剧情事实或绕过编译器。
7. 在用户授权的项目与生成范围内完成一集，核对剧情顺序、关键对白、声音和播放；交付同一画布内可播放成片。自动测试通过与供应商任务成功均不能替代成片验收。
