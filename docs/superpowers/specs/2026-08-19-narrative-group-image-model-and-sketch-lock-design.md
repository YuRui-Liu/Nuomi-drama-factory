# 叙事组真实图片模型绑定与草图强构图锁定设计

## 背景

当前项目有两套图片模型配置：旧逐镜链路使用 `LingShan-G2`、`LingShan-NB-2` 等 NewAPI 逻辑模型名；叙事组多宫格链路则绕过项目的草图/实图选择，草图与实图均固定使用 `grsai-main` 的默认模型。当前实图生成也未把草图多宫格或草图格作为输入，因此草图不能约束实图的机位、透视、人物站位和动作。

本设计只改叙事组图片链路。旧逐镜链路及其 LingShan 逻辑别名继续兼容，不在本次范围内移除。

## 目标

1. 叙事组草图与实图分别绑定真实 `provider_id + model`，界面不再显示 LingShan 逻辑别名。
2. 草图成为实图的强构图控制资产，约束格位、机位、透视、景别、人物站位和动作轮廓。
3. 首次实图整组生成，坏格可单独修复并确定性回填，不重跑其他格。
4. 项目保存默认模型，每个叙事组允许只对本次任务临时覆盖。
5. 每个结果可追溯到实际渠道、模型、草图 revision、约束模式和格位 revision。
6. 失败和过期任务不得覆盖上一版有效资产。

## 非目标

- 不删除旧逐镜链路的 `sketch_image_selection`、`render_image_selection` 或 LingShan 模型映射。
- 不在本次接入 GRSAI 之外的新媒体渠道执行器；数据契约保留 `provider_id`，便于后续扩展。
- 不引入 ControlNet、姿态骨架或新的本地视觉模型。
- 不改变现有叙事分组规则和 H3 视频时间线契约。

## 已确认的产品决策

- 约束模式：默认强构图锁定。
- 模型选择：每阶段独立选择真实渠道与真实模型。
- 默认草图模型：`grsai-main / nano-banana-2`。
- 默认实图模型：`grsai-main / gpt-image-2`。
- 生成粒度：首次整组图像编辑，随后支持单格修复。
- 无有效草图：默认阻止；用户可二次确认后显式无约束生成。
- 配置层级：项目默认值加组级单次覆盖，覆盖不反写项目配置。

## 架构

### 真实模型选择

新增稳定值对象：

```text
ImageModelBinding
├─ provider_id: string
└─ model: string

NarrativeGroupImageDefaults
├─ sketch: ImageModelBinding
└─ render: ImageModelBinding
```

项目配置保存 `NarrativeGroupImageDefaults`。任务提交时将最终解析后的 `provider_id + model` 写入不可变 payload。组级覆盖只影响该次提交，不修改项目默认值。

`ImageModelResolver` 负责：

- 查找已启用的真实媒体渠道；
- 验证凭据可用；
- 验证渠道支持所选真实模型；
- 返回执行客户端及规范化模型名；
- 在入队前拒绝逻辑别名、未知模型和禁用渠道。

旧 LingShan 配置继续服务旧逐镜链路。叙事组 API 和任务 payload 不接受 `LingShan-G2`、`LingShan-NB-2`、`newapi_gpt_image2` 或 `newapi_nanobanana2`。

### 输入构建器

`NarrativeGroupRenderInputBuilder` 构建两种输入：

- `build_group_input`：整组草图多宫格加组内参考图；
- `build_cell_input`：目标草图格加该镜相关参考图。

输入构建器不调用供应商，只负责确定性选择、排序、标注和哈希。参考图职责必须显式记录为 `sketch_control`、`identity`、`scene` 或 `style`。

### 生成执行器

`NarrativeGroupRenderEngine` 提供：

- `render_group`：整张草图多宫格实化，随后自动切分；
- `render_cell`：实化单个草图格，原子替换目标实图格，重新拼合实图多宫格。

执行器不负责解析项目设置；只接受已冻结的模型绑定和已构建输入。

## 数据流

### 草图阶段

1. 使用现有场景/时间连续性规则分组，每组最多九镜。
2. 解析项目草图默认绑定和可选的组级单次覆盖。
3. 输入镜头描述、身份图、场景 Master 和风格参考。
4. 调用真实草图模型生成草图多宫格。
5. 确定性切分草图格，保存整图、格图、revision 和实际模型。

现有布局保持不变：一至四镜为 2×2，五至六镜为 2×3，七至九镜为 3×3。

### 实图整组生成

参考顺序固定：

1. 当前草图 revision 的整张草图多宫格，职责为 `sketch_control`；
2. 本组角色身份图，职责为 `identity`；
3. 本组场景 Master，职责为 `scene`；
4. 项目风格参考，职责为 `style`。

草图控制图永远占据第一参考位且不得被裁剪。其余参考图超过渠道上限时，按镜头覆盖数量降序、首次出现顺序升序裁剪。

程序编译的提示词必须表达以下不可变规则：

- 将第一张图的草图多宫格转换为最终画面；
- 不得改变行列数、格位顺序、裁切、景别、机位、透视、人物站位和动作轮廓；
- 身份参考只约束人物身份、脸、年龄和服装；
- 场景参考只约束建筑、材质和固定陈设，不得覆盖草图构图；
- 风格参考只约束画风、色彩和光影；
- 不生成边框、文字、编号或额外格子。

生成成功后验证多宫格尺寸和可切分性，再确定性切分至镜头资产。质量验证失败时保留旧版本。

### 单格修复

单格修复只提交：

1. 对应草图格；
2. 该镜涉及的身份图；
3. 该镜场景 Master；
4. 项目风格参考。

成功后先在临时位置生成新格和新组合图；两者验证通过后再原子发布。其他格文件和 revision 保持不变。目标格 revision 自增，组合图 revision 自增。失败时原格和原组合图不变。

### 无草图生成

草图缺失、切分失败或 revision 过期时，默认禁用实图生成。用户可以从旁路操作选择“无草图继续”，经二次确认后提交 `allow_unconstrained=true`。

无约束任务：

- 不上传草图；
- 永久记录 `constraint_mode=unconstrained`；
- UI 不得显示“草图锁定”；
- 仍记录实际渠道、模型和输入参考哈希。

## 状态与溯源

实图阶段增加以下信息：

```text
provider_id
actual_model
source_sketch_revision
constraint_mode: strong | unconstrained
combined_revision
cell_assets[]:
  cell
  beat_id
  path
  revision
  source_sketch_revision
  constraint_mode
  provider_id
  actual_model
```

整组和单格任务均冻结预期草图 revision。写入结果前再次比较当前 revision；不一致时任务以 stale 结束，不覆盖当前资产。

历史记录保留每次整组生成和单格替换的来源。回滚组合图时必须同时恢复对应格位映射，不能只恢复图片文件。

## API 与界面

项目设置新增“叙事组图片模型”：

- 草图模型绑定；
- 实图模型绑定；
- 选项来源于已启用媒体渠道及其真实支持模型。

组级生成请求可以携带可选 `provider_id` 和 `model`。省略时继承项目默认。响应和任务详情返回最终冻结的真实绑定。

组卡片显示：

- 继承项目默认或本组临时覆盖；
- 实际渠道和模型；
- 来源草图 revision；
- 强构图锁定或无草图约束；
- 每格 revision、状态和“单格重绘”入口。

草图有效时主按钮为“按草图生成实图”。草图无效时主按钮禁用，旁边显示“无草图继续”；该操作必须二次确认并明确说明构图可能漂移。

## 错误处理

- 渠道未配置、禁用或凭据失效：入队前拒绝。
- 渠道不支持模型：返回包含 `provider_id/model` 的明确校验错误。
- 供应商积分不足：保留供应商真实原因并显示具体渠道。
- 参考图缺失：列出具体角色、身份、场景或草图格。
- 格数、尺寸或切分不合法：标记质量失败，不发布新资产。
- 单格修复失败：保留原格和原组合图。
- revision 过期：返回 stale，不覆盖新状态。

## 迁移与兼容

- 不改写现有 `sketch_image_selection` 和 `render_image_selection`。
- 不把旧 LingShan 别名静默映射成新的 GRSAI 任务值。
- 已有项目首次读取新设置时，若 `grsai-main` 已启用且支持默认模型，则建立默认草图/实图绑定。
- 若真实渠道不可用，设置页显示未配置，生成入口禁用并给出配置指引。
- 已有无来源信息的实图继续可查看，但标记为 legacy；再次生成后才写入新溯源字段。

## 测试

### 后端契约

- 项目默认保存真实 `provider_id + model`。
- 组级覆盖进入任务快照但不修改项目配置。
- 未知模型、禁用渠道和缺失凭据在入队前失败。
- 旧 LingShan 值不能进入新叙事组任务。

### 输入与提示词

- 草图多宫格始终是实图请求的第一参考图。
- 草图控制图不会因参考超限被裁剪。
- 其余参考图按固定优先级和排序规则选择。
- 提示词包含全部强构图不可变规则。
- 单格修复只携带该镜相关参考图。

### 任务与资产

- 整组实图只调用一次图片模型并自动切分。
- 单格修复只调用一次单图生成。
- 成功只替换目标格并重新拼合整图。
- 失败保留原格和原整图。
- stale 任务不能覆盖新 revision。
- 无草图任务必须显式记录 `unconstrained`。

### 前端

- 选择器显示真实渠道和模型。
- 支持项目默认与组级临时覆盖。
- 草图无效时默认阻止实图生成。
- 无草图继续必须二次确认。
- 单格修复只刷新目标格和组合预览。
- 任务详情显示实际模型、草图 revision 和约束模式。

## 验收标准

1. 草图和实图可以分别绑定真实 GRSAI 模型。
2. 正常实图可确认继承草图的格位、机位、透视和人物位置。
3. 单格修复不改变其他镜头资产和 revision。
4. 所有新结果可追溯到渠道、模型、草图 revision 和约束模式。
5. 任意失败或过期任务都不会覆盖上一版有效资产。
