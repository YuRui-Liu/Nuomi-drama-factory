# 导入结果首页与本集资产绑定原型设计

日期：2026-09-29。用户已选择 A：结果首页＋导入向导，并恢复剧集列表及三类资产解析、绑定入口。本文仅约束 HTML 原型，正式软件待集中评审后实施。

## 范围与视觉约束

延续 V6 统一外壳、顶部导航、深色与荧光黄绿色；不改全局剧本创作。修改导入模块和剧集列表/本集资产面板，不重做资产中心和其他工作室。保留知识图谱入口及原有冲突、失败、版本保护。

## 导入结果首页

默认显示“导入概览 / 导入历史 / 知识图谱”三个页签。已有内容时，首屏展示已导入剧集数、最近导入结果和剧集摘要，主按钮为“进入剧集制作”，次按钮为“继续导入”。未导入时显示简洁空态，主按钮为“导入剧本”。

配置收为项目类型、视觉风格、处理流程摘要及“编辑配置”。编辑在独立抽屉中完成，保存不提交导入；失败保留输入，变更处理流程时展示影响。演示工具收在统一辅助入口，不与业务主按钮并排。

## 导入向导

继续导入打开宽面板，依次为：1 选择文件或粘贴正文；2 检查分集与冲突；3 确认导入。第一步用切换控件区分多文件与正文，不同时堆叠两个输入区。

第二步以逐集表格显示名称、目标集号、字数、冲突及处理方式，可校正集号、选择覆盖或跳过；重复集号和未处理冲突阻止下一步。第三步显示新增/覆盖/跳过数量与配置摘要，明确提交范围。

返回上一步不丢输入；提交中禁止重复提交。失败留在当前步骤并可重试；离开未保存内容提供保留/放弃/取消。完成后返回概览并显示结果，提供进入剧集制作和查看知识图谱。

历史按批次展示时间、结果、逐集数量；展开查看集号、动作和失败原因。入口不重复堆叠在每条历史下。历史记录不作为新的可编辑导入草稿。

## 剧集列表和本集工作台

列表每集显示人物、场景、道具关联数量及各自状态，独立提供“解析人物”“解析场景”“解析道具”；另有“进入制作”。人物界面沿用原角色/身份模型，不把同一角色的不同身份强行合并。

工作台标题区域固定“← 返回剧集列表”和“本集资产”。返回保留列表位置及筛选；再次进入保持该集制作阶段。未保存编辑先处理离开保护。切集更新所有面板的 episode，不遗留上一集任务或绑定。

## 解析与资产绑定

三个入口打开同一个本集资产抽屉，按人物/场景/道具分类。显示已关联资产、解析状态和“重新解析”。提交明确针对本集已保存源文；源文未保存时先提示保存，不偷偷解析旧稿。

解析任务状态包括排队、运行、成功、失败、取消和提交未知；任务中心与抽屉使用相同任务 ID。未知状态先查询，禁止重复提交。只模拟任务，不访问真实生成服务。

完成后显示识别项、原文依据及关联结果：已匹配资产、可选既有资产、需新建项和歧义项。沿用原模型能够明确解析的关联；歧义需用户选择，不静默合并或覆盖既有资产。补充调整通过明确“保存绑定”生效；“新建并绑定”显式创建对象，取消不创建。

人物绑定具体身份，场景/道具绑定资产 ID；可打开资产中心对应对象并返回本集。解除绑定仅移除本集关联，不删除项目资产。更改后同步列表数量与本集引用选择；已生成媒体保留，受影响引用提示复核，不自动重生成。

## 模块与数据流

support 原型负责导入向导、概览和历史；production 原型负责列表、当前集与资产抽屉；assets 原型继续管理资产实体。统一外壳转发带 episode、assetType、assetId 的上下文和绑定事件。三种解析复用流程状态，但各自维护结果、任务及绑定，不能共享一个完成标志。

新增本地演示事件以类型与目标集定位，更新依赖面板；旧导入、运行时和任务消息保持兼容。原型数据是示例，不承诺真实自动抽取精度或后端已支持新的审核界面。

## 验收

1. 已导入与空项目首屏各只有一个明确主操作；历史和配置不挤占导入输入区。
2. 文件/正文切换、向导前进后退、重复集号、覆盖确认、失败重试和离开保护均保留正确输入。
3. 从本集返回列表、重新进入、切集后阶段和对象正确。
4. 三类解析各完成一遍；人物歧义选择、既有场景绑定、新道具创建、解除本集绑定可见且可回读。
5. 第1集绑定更改不误写第2集；任务状态和返回目标正确；未知提交不产生第二个任务。
6. 资产中心修改与本集引用衔接，既有图片/视频不丢失；旧 V6 主链保持可用。
7. 浏览器检查桌面布局、抽屉滚动与键盘焦点；状态测试覆盖失败和对象隔离。记录实测与未测项，不提前标全部通过。
