# 立意节点 PRD

日期：2026-10-17

状态：核心交互已由用户逐项确认；本文为确认结果归档，尚未实现。

## 1. 目标与边界

让用户从故事想法起步，在项目构思画布选择题材、探索立意、采用方向，并显式交给主笔创作 E01。遵循 Agent／节点为中心、画布承载创作内容的已确认总体设计。

立意节点是独立节点。题材选择是创作输入，不代表立意已经确认。采用立意不自动启动剧本、图片或视频生成。完整 E01 成片仍须经过剧本及制作交接、叙事组分镜图、组视频和整集合成；本节点完成不等于整集完成。

## 2. 已确认的用户决策

1. 新增独立的“立意／创作简报”节点。
2. 复用已有剧本设定器的交互，支持预设、主题材与融合题材、受众、角色、背景、看点、画风、篇幅和故事种子。
3. 默认生成 3 个立意方向供比较；支持编辑、单个候选重新生成，以及直接填写并采用自己的立意。
4. 候选展示一句话立意、主角与核心冲突、故事看点、人物最终抉择。
5. 采用后保留其他候选，固定采用版本；点击“创作 E01”才启动主笔。
6. 主笔先输出关联的大纲、人物设定及目标集计划，用户确认规划后才启动 E01 正文与自动审改；保留来源版本、失败续跑和已有正文的候选修改机制。

第 6 项根据后续用户选择细化：先规划确认，再写正文。完整合同见 [专业漫剧剧本节点 PRD](2026-10-17-professional-screenplay-node-design.md)，不以当前简报功能已实现该链路。

## 4. 画布交互

### 4.1 创建与编辑

用户从节点菜单创建立意节点，也可由获授权的主创／创意师创建。默认放在当前构思画布，不强制先建集。节点收起时展示故事种子、题材摘要和采用状态；展开进入设定器。

复用选择器的分类抽屉和预设交互。切换预设保留故事种子与篇幅；撤销预设不覆盖随后手动编辑的字段。中文输入法组合输入期间不提交自定义项。保存失败保留输入并显示可重试错误。

### 4.2 比较候选

“生成立意”调用创意师，以已保存的简报版本为输入，默认返回 3 张可比较的候选卡。候选明确关联本轮输入及生成任务。候选本身不是项目事实。

每卡支持编辑、采用、单个重新生成。单个重生成产生新修订并保留历史，不覆盖其他卡或已采用版本。用户可直接创建自写候选并采用，不要求先调用模型。

### 4.3 采用与继续创作

采用动作固定具体候选修订，并展示当前采用方向。其他候选保留。节点展示“创作 E01”动作；只有用户点击或给出等价明确指令才提交主笔任务。

该任务读取采用的立意与简报快照，先创建／关联规划文档和节点，停在“待确认规划”。用户点击“确认方案并创作 E01”后才生成正文并自动审改。已有正文时交付修改候选，不静默覆盖。节点可显示运行、失败、已完成等真实任务状态，并能定位下游成果。

## 5. 内容与版本契约

以下是产品语义，具体 API 字段与存储迁移在实现计划中确定。

| 对象 | 必须保留的信息 |
| --- | --- |
| 创作简报 | 题材、受众、设定、故事种子、篇幅及修订标识 |
| 立意候选 | 稳定标识、修订、四项可读内容、来源简报修订、作者／Agent、任务来源 |
| 采用记录 | 候选修订、采用时简报修订、采用人及时间 |
| 创作任务 | 授权目标、采用快照、目标集、任务标识与实际结果引用 |
| 画布投影 | 关联内容标识、布局、展开状态；不另造与文档分离的正文真相来源 |

一个立意节点可以保留多轮候选，但只有一个当前采用方向。用户可以创建多个立意节点探索不同故事；主笔任务必须明确读取哪一个采用版本，不自动混合。

已采用内容编辑后形成新修订，旧采用记录继续有效，并提示新旧差异；重新采用才改变后续任务输入。上游变化将已关联下游标记为需评估，不自动重写剧本、重生资产或购买媒体。

## 6. Agent 与权限

创意师负责提出候选、解释差异和局部修改；主笔读取采用版本推进剧本。采用权限与生成权限分开，不能由“创意师”角色名称或委托关系推断采用许可。

沿用已实现的具体节点授权、任务记录和停止／恢复语义。停止保留已完成候选；提交结果不明时查询原任务，不能以重新点击为由重复提交。任务提交成功只代表开始执行。

## 7. 异常与恢复

- 未采用立意时，“创作 E01”说明缺少采用方向，不暗选第一张。
- 简报尚未保存或版本冲突时先解决保存问题，不用过期内容悄然启动。
- 重复点击复用同一提交身份，避免并发创建重复剧本任务。
- 生成失败保留简报、旧候选和已采用版本，显示失败原因并支持原范围重试。
- 已有 E01 时，展示继续／修改已有内容的语义，不创建第二份同集正式剧本。
- 人工编辑与 Agent 回填冲突时保留双方内容，提示差异；不按最后写入者覆盖。

## 8. 验收要求

1. 用户在构思画布可创建、编辑、保存并重新打开立意节点。
2. 选择器既有交互可用，用户输入不会因关闭、保存失败或撤销预设丢失。
3. 一次生成可比较的 3 个候选，单卡重生成不改动其他候选。
4. 自写立意可以直接采用；采用动作本身不发起剧本／媒体任务。
5. “创作 E01”使用确切采用修订，输出可定位的关联成果与真实任务状态。
6. 立意变化保留下游已完成产物，并显示来源差异。
7. 失败、停止、恢复及重复提交不造成无声覆盖或重复生成。
8. 最终真机验收从本节点起步，经专业剧本与正式生产入口生成可播放 E01；缺失环节和阻塞必须分别记录，不能用模拟供应商测试代替成片证据。
