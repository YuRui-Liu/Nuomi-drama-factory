# NuomiDrama 前端品牌重塑设计

## 背景

当前前端同时存在 DramaClaw、SuperTale 与“虾导、虾画、虾集、虾塘、虾镜”等多套品牌和功能隐喻。用户无法仅凭名称判断栏目用途，登录页、应用顶栏、翻译文案、SEO 元数据和设置说明也缺少统一的产品身份。

本次设计将用户可见品牌统一为 **NuomiDrama**，并把产品表达从概念化的“虾系宇宙”调整为专业、直接的 AI 短剧制片语言。内部兼容标识不随视觉品牌迁移，避免破坏已有数据、接口和发布流程。

## 产品定位

NuomiDrama 是面向短剧、漫剧与 AI 视频团队的一体化制片工作台，帮助创作者把故事文本稳定推进为可复用资产、分集内容、镜头画面和最终成片。

核心价值：

- 长流程：覆盖剧本导入、资产建设、剧集制作、镜头生成、音视频与合成。
- 一致性：角色、场景和视觉风格可以跨镜头复用。
- 可控性：每个生产环节可以检查、调整和重做。
- 项目化：结果沉淀在项目中，而不是成为一次性的聊天记录。

目标用户包括独立 AI 短剧创作者、2–10 人内容团队，以及负责批量生产与质量控制的导演、制片和运营人员。

品牌气质定义为：**专业、克制、有创作温度**。

## 品牌名称与标志

- 正式英文品牌：`NuomiDrama`
- 中文产品名称不另造缩写，界面以英文品牌字标为主。
- Logo 使用单色几何 `N`：两条错位的剪辑切口或时间轴片段构成主体，负形表达画面推进方向。
- Wordmark 使用 `NuomiDrama`，其中 `Nuomi` 字重 600、`Drama` 字重 400，字距约 `-0.02em`。
- 标志必须在 18–24px 尺寸下保持清晰，并提供图标、横向字标和单色反白三种资源。

明确禁止：

- 米粒、饭团、龙虾、摄影机或场记板拟物图形。
- 伪国风印章、书法字和装饰性东方纹样。
- 依赖紫蓝渐变、霓虹光晕或粒子宇宙背景建立品牌。
- 使用 `DC` 作为新品牌缩写。

## 信息架构与命名

用户可见导航统一使用四个汉字：

| 原名称 | 新名称 | 功能范围 |
| --- | --- | --- |
| 所有项目 / 首页 | 项目中心 | 项目列表、创建与最近制作 |
| 虾料 | 剧本导入 | 导入小说、剧本及其他故事文本 |
| 虾塘 | 资产中心 | 角色、声线、场景与道具 |
| 虾镜 | 剧集制作 | 分集、剧本、分镜、音视频与合成 |
| 虾画 | 创作画布 | 自由节点、素材编辑与复杂镜头制作 |
| 虾格 | 视觉风格 | 风格配置、参考图与项目默认风格 |
| 虾条 | 任务中心 | 生成任务、进度、失败和重试 |
| 虾导 | 糯米助手 | 基于项目上下文的 AI 助手 |
| DramaClaw TV | 作品广场 | 案例与社区作品展示 |

原“虾画 / 虾集”二段模式切换不再作为用户可见的一级概念。稳定导航直接呈现主要功能；如果代码中仍需保留原路由分组，只作为内部路由结构存在。

上下文操作使用自然动作，不机械复用栏目名称：

- “打开虾画”改为“进入画布”或“画布编辑”。
- “肖像虾画”改为“编辑肖像”。
- “本集虾画”改为“本集画布”。
- “在虾镜中提取”改为“在剧集制作中提取”。

## 品牌语气

文案使用短句、直接描述用户下一步能完成的事情。生成任务明确显示状态、输入来源与失败原因，不把普通操作包装为“魔法”“施法”或抽象的创作宇宙。

推荐表达：

- “从故事到成片，一站完成。”
- “让角色、场景和风格贯穿每个镜头。”
- “生成完成，可继续调整。”
- “糯米助手可能出错，请核对关键剧情与资产信息。”

用户可见层禁用：

- DramaClaw、DC、SuperTale。
- 虾导、虾塘、虾画、虾镜、虾料、虾格、虾条、虾集。
- “开启创作宇宙”“无限可能”“AI 赋能”“一键大片”等模糊或夸张表述。
- 无功能价值的大段中英混排装饰文案。

## 视觉方向：Editorial Black

主产品采用专业编辑台视觉，而非品牌展示网站风格。

### 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| Background | `#0D0E10` | 主工作区 |
| Surface 1 | `#14161A` | 侧栏和基础面板 |
| Surface 2 | `#1A1D22` | 选中项和嵌套区域 |
| Raised | `#20242A` | 弹层和高层级控件 |
| Border | `#2A2F37` | 主要边界 |
| Text | `#F2F4F7` | 主文字 |
| Muted | `#9299A5` | 辅助信息 |
| Brand | `#E5FF5C` | 主操作、当前步骤、进度和品牌焦点 |
| Focus | `#BFE6FF` | 键盘焦点环 |
| Success | `#52D89B` | 成功状态 |
| Warning | `#F3B85B` | 警告状态 |
| Danger | `#F06B72` | 错误和破坏性操作 |

酸柠黄是唯一品牌强调色，不铺满大面积背景，不与成功状态混用，也不对普通卡片添加发光效果。

### 字体与尺寸

- UI：Inter Variable + Noto Sans SC。
- 数字、任务编号、时间轴：Geist Mono 或等价等宽字体。
- 标题字重 600，正文 400–450，不使用超宽字距。
- 圆角：4 / 6 / 8 / 10px 四档。
- 间距：4 / 8 / 12 / 16 / 24 / 32px。
- 顶栏高度：56px。
- 固定侧栏宽度：232px。
- 控件高度：32 / 36 / 40px。
- 高层面板阴影：`0 12px 32px rgba(0, 0, 0, 0.28)`。

卡片主要依靠 1px 边界、表面明度差和留白形成层级，减少玻璃拟态和漂浮阴影。缩略图、分镜和素材内容应成为工作台的视觉主体。

## 关键页面

### 登录品牌页

- 左上展示 24px 几何 `N` 与横向字标。
- 主文案左对齐：“从故事到成片，一站完成”。
- 主操作使用酸柠黄，次操作使用中性描边。
- 右侧直接展示真实的“竖屏预览 + 资产参考 + 时间轴”产品组合，不使用抽象光效。
- 背景只允许极低对比度网格，不使用全屏渐变。

### 项目中心

- 左侧固定导航承载全部四字栏目，糯米助手在底部独立入口。
- 主区展示项目封面、制作状态、集数、镜头数和最后更新时间。
- 项目卡片使用真实缩略图，不使用彩色渐变首字母头像。
- 进度和当前生产状态才使用品牌色。

### 剧集制作

- 左栏：剧集或叙事组列表。
- 中栏：9:16 / 16:9 分镜与媒体工作区。
- 右栏：属性、参考图和生成配置。
- 顶栏显示项目面包屑、画幅选择器和主要制作动作。
- 当前阶段使用底部 2px 品牌色标识。
- 糯米助手提供侧栏入口和右下 40px 快捷按钮，不使用卡通形象。

## 组件与交互

- 交互目标不小于 40px。
- 键盘焦点使用可见的 2px 焦点环，正文对比度不低于 4.5:1。
- 动效短促、精确，无弹跳和无意义光晕；用于状态切换时建议 120–180ms。
- 加载状态优先使用与内容结构一致的骨架屏，不以居中转圈占据主工作区。
- 选中状态使用品牌色细线或小面积标记，不整块高亮为荧光色。
- 空状态直接说明缺少什么、为什么需要以及下一步动作。

明暗主题继续支持，但 NuomiDrama 的主品牌展示和默认专业工作台以暗色 Editorial Black 为准。亮色主题采用中性暖灰表面，不重新引入另一套品牌语言。

## 替换范围

用户可见层必须替换：

- 登录页和全部 cinematic 文案。
- 应用顶栏、Logo、favicon 与品牌资源。
- 浏览器标题、description、canonical、Open Graph 和 Twitter 元数据。
- 中英文 locale 中的品牌名、栏目名、说明、错误提示和 ARIA 标签。
- About、作品展示、设置说明、社区入口和公开 Provider 展示名。
- 所有“虾系”导航、按钮、提示、助手默认名称与头像首字。
- 候选能力等会直接展示给用户的 SuperTale 文案。

内部兼容层保持：

- API 路径、请求字段和响应字段。
- `provider = "dramaclaw"` 等机器值。
- `supertale-*` 与 `dramaclaw:*` localStorage / IndexedDB Key。
- npm 包名、Python 包名、任务类型和内部协议标记。
- GitHub 仓库、安装包地址和下载解析逻辑；界面只调整其显示标签。
- 许可证、迁移记录与兼容说明中确有必要保留的历史品牌名称。

## 组件边界

建立一个统一的品牌组件与配置边界：

- 品牌配置：产品名、短描述、公开链接和可见标签。
- Logo 组件：图标、横向字标、反白模式和尺寸。
- 登录页、顶栏、favicon/SEO 分别消费同一品牌配置，不再硬编码多份名称。
- 导航仍使用 i18n key；只替换用户可见值，不更改现有路由标识。

该边界允许未来更换品牌资源而不触碰业务组件，也能避免登录页与主应用再次出现品牌漂移。

## 错误处理与迁移

- 品牌图片加载失败时显示文本字标 `NuomiDrama`，不得回退到 DramaClaw 资源。
- 旧 localStorage 和 IndexedDB 数据继续读取，不做批量重命名或清除。
- 外部链接仍指向现有可用地址；链接标签使用 NuomiDrama 或中性功能名。
- 未完成迁移的用户可见旧名称视为缺陷，由自动扫描和页面测试阻断交付。
- 不自动修改用户项目内容、项目名称、生成提示词历史或导入文本中的原始品牌词。

## 测试与验收

### 自动化检查

- 品牌组件的图标、字标、反白和无障碍名称测试。
- 导航测试覆盖八个四字名称和正确路由。
- zh/en locale 扫描：用户可见键中不得残留旧品牌和“虾系”名称。
- 登录页与应用顶栏测试必须引用统一品牌组件。
- index.html 元数据测试覆盖 title、favicon、OG 和 Twitter 字段。
- 兼容性测试确认 API machine value、storage key 与包名没有被误改。

### 视觉验收

- 登录页、项目中心、剧集制作三处均显示统一 NuomiDrama 品牌。
- 常规用户路径看不到 DramaClaw、SuperTale 或“虾系”名称。
- 1440px 桌面宽度下导航不截断；较窄桌面宽度仍保留清晰层级。
- hover、active、focus-visible、loading、empty、success、warning、error 状态均符合新 Token。
- 真实内容密度不低于现有工作台，不因品牌升级牺牲生产效率。

## 非目标

- 不重命名仓库、Python 包、npm 包、API 和数据库字段。
- 不迁移或清空已有浏览器存储。
- 不重构与品牌展示无关的生成流程和业务逻辑。
- 不在本次品牌升级中引入吉祥物、营销活动系统或新社区功能。
