# 角色声音档案与非语言兽声设计

日期：2026-09-23

状态：方案 B 的两节设计已获用户确认；本文供书面规格审查，尚未实施。

范围：角色声音准备、Qwen3-TTS 提示词、候选验收、素材版本与批量恢复。

## 1. 目标与边界

修复角色年龄统一变成青年、年龄槽位不影响提示词、非语言角色误生成人类试听等问题。批量生产按剧集需求补齐声音素材，自动复用合格结果，仅将不确定或缺少能力的任务交给异常处理。

采用方案 B：来源事实与声音创作分离，复用已有 VoiceSpec，增加持久化版本、统一提示词编译与质量检查。方案 A 仅修年龄默认值和槽位，不能处理非语言角色与批量生产；方案 C 的完整音效、音乐、混音系统超出本轮范围。

本轮不重构图像或视频生成，不合并角色别名，不建立完整音效平台。兽声先作为可引用素材保存，不因此宣称已完成视频时间线自动混音。设计批准不代表真实模型生成授权；此前图片预算不转作声音预算。

## 3. 数据契约

### 3.1 来源事实

保存年龄（精确年龄或原文年龄段）、物种/形态、发声模式、原文明示声音特征及来源引用。每项区分原文证据、人工确认、未知；创作建议不能写回为原文事实。

发声模式独立于性别、物种：

| 模式 | 允许的素材 |
| --- | --- |
| dialogue | 人类语言对白 |
| nonverbal | 非语言叫声等素材 |
| both | 两条独立素材分支 |
| none | 不生成该角色声音 |
| unknown | 补查来源；仍无依据时阻止自动付费生成，进入异常队列 |

不能把中性性别推断成兽类，也不能把非人类物种直接推断为不会说话。片段无相关描述时不得覆盖已有明确事实；相互冲突的证据保留冲突，不能凭默认值消除。

### 3.2 声音创作档案

复用 VoiceSpec 的 age_impression、pitch、texture、resonance、articulation、pace、accent、emotional_baseline 与 negative_constraints。创作档案另记录事实版本、设计来源、确认状态和修订号，不将版本管理塞入声学字段。

听感年龄优先级：请求的显式年龄槽位 > 已确定的声音设计年龄 > 有证据的角色年龄段。均缺失时省略年龄约束，或明确提出创作建议；禁止静默回退青年。显式年龄槽位不修改角色事实。

人声保留 default、child、youth、middle、elder 入口。非语言素材按用途管理，不设置人类年龄槽位。both 模式下，年龄槽位只作用于人声分支。

### 3.3 素材与版本

候选至少保存项目/角色稳定标识、类型、槽位或用途、档案修订、实际提示词、试听输入、实际模型/工作流与参数、供应商任务 ID、音频路径及摘要、生成状态、质检报告、尝试次数和时间。

验收报告保存检查器及策略版本、分项结果和原因。素材版本不可变；当前生产版本通过单独引用选择。更换声音或回退版本只修改引用，不删除旧音频。

沿用现有数据库与资产管理方式实现持久化，不另建一套生产内存存储。文件落盘成功、摘要校验与数据库记录完成后，候选才可进入验收；发布引用使用事务及修订检查。

## 4. 提示词编译与供应商适配

流程：来源事实 → 声音档案 → 发声分流 → 提示词编译与预检 → 生成候选 → 验收 → 发布版本。

编译器只接收经过校验的声学维度与当前生成目的。角色身份用于形成可听见的设计建议，不把外貌、职业、剧情全文直接拼进指令。未知性别不自动变为中性音色；仅在明确选择这种听感时使用中性声线描述。

固定声线与逐句表演要求分离。试听文本独立传递，不能把声音设计指令作为台词。完整合并后的规格进行矛盾检查；冲突不能通过重复拼接解决。自定义指令与明确槽位冲突时，返回可定位的校验错误，付费提交前停止。

保留已有对真人模仿请求的检查。避免固定刻板映射，例如所有老年人都沙哑、所有女性都高音。按语言选用一致、简洁的自然语言描述，不假定存在官方支持的兽声控制标签。

实际 API 与现有 pipeline facade 使用同一套编译和供应商适配逻辑，避免第三套独立实现。预检检查模型、节点契约、语言是否可控以及实际工作流配置；语言固定 Auto 时明确记录，不能声称 language 请求已生效。不擅自修改远端工作流。

## 5. 朏朏与兽声实验

朏朏依据来源设为 nonverbal，人类声音年龄不适用。禁止默认「我是朏朏……」试听；禁止为其自动填写人类年龄槽位或把兽声自动绑定为 IndexTTS2 对白克隆参考。

按剧集所需用途创建候选，例如警觉短鸣；这些用途是剧情需求或创作设计，不冒充原文固有设定。首轮不预生成完整叫声库。

现有工作流要求文本输入，是否能产生可用非语言声音必须通过受限实验验证。实验适配器必须记录确切输入；不得伪造空文本支持、特殊标签或模型能力。实际输出若是朗读「呜呜」等拟声词，则不符合兽声要求。

每个角色、档案修订、用途在一个生产批次中最多两次生成：首次一个候选，质量失败后最多一次针对性修改重试。并发请求、进程重启不能重置计数。耗尽后标记 awaiting_import，不自动切换付费供应商或降级成人声。新批次不得被系统自动创建以绕过上限。

导入素材同样记录来源、使用权说明、摘要和质检状态；导入不等于自动通过。

## 6. 质量检查与发布

质量检查与任务执行状态分开。供应商生成成功只代表候选可下载。

| 检查 | 要求 |
| --- | --- |
| 技术检查 | 音频可解码，时长符合请求用途的范围，无严重静音或削波；规则、测量值与阈值记录在报告中 |
| 人声内容 | 语音识别与试听台词对照，规范化标点等非语义差异；额外朗读指令或漏掉关键内容须拦截 |
| 人声听感 | 具备音频理解能力的独立审查判断目标年龄段、音色与表达是否符合档案，不声称精确识别生理年龄 |
| 非语言内容 | 检查用途、非语言性质及不应出现的人类语句；识别结果为空不能单独判定合格 |

统一质检结果：passed、rejected、uncertain、qc_unavailable。全部必需检查通过才可自动发布；人工审核通过要记录审核者与理由，不能伪装成自动检测通过。

uncertain 进入异常队列，不触发自动重新生成；qc_unavailable 保留候选，等待审查能力恢复后重检原音频，不为审查故障再次付费。非语言素材的音频理解审查能力未配置或未验证时，不能自动放行。

技术阈值作为版本化、可测试的策略配置，按人声与非语言用途分别设置。自动听感验收需先用已标注的正负样例验证；未完成校准前只能提供建议结果，不能开启无人值守自动发布。

发布时确认角色事实和声音档案修订仍与提交快照一致，并检查目标引用是否被其他任务更新。过时任务保留候选但不覆盖当前生产声音。相同候选重复发布应幂等。

## 7. 批量执行、费用与故障恢复

CLI 复用 API 和任务服务，提供按剧集需求的预检、补齐、进度查询、恢复、原音频重检、素材导入及版本选择能力；具体命令名在实现计划中对齐现有 CLI，本文不把设计命令作为现有功能宣传。

复用键至少包含项目、角色、声音类型、槽位/用途、档案修订、模型/工作流配置摘要；生成请求去重还包含试听输入及编译版本。供应商配置变化不会自动废弃仍被明确选用的旧素材，但不得把不同配置的新请求误判成相同任务。

提交前持久化请求意图并防并发重复提交，得到供应商任务 ID 后立即保存。重启后优先查询既有任务。若提交超时导致是否受理未知，进入提交状态待核对，不盲目重新提交；没有供应商幂等能力时不承诺严格 exactly-once。

轮询、下载、审查恢复与重新生成分开计数。网络或审查失败优先恢复已有任务，不消耗新的生成尝试。任务取消后不再提交重试；已受理的供应商任务可能仍计费，结果不得在取消后自动发布。

费用记录必须区分预估、供应商实际扣费与未知。CE 返回 0 不代表免费。需要付费时使用本轮明确授权的额度；若有可靠单次成本上界，批量并发前预留预算；无法估算上界或核对额度时暂停新的付费提交，不承诺自动守住金额上限。

批处理输出结构化状态与失败原因，区分可生产、需导入、需审查、费用不足和供应商状态未知。不把存在阻断项的剧集报告为完成。已有合格素材继续复用，不要求逐张/逐条人工审批。

## 8. 兼容与迁移

新增字段使用兼容读取；现有 youth 值不能一概清空。保留有原文证据或人工确认的年龄，无法区分历史默认与真实设定的记录标记需核对，并通过重新提取来源事实补足证据。

旧音频保留为历史资产，不能仅凭文件存在就迁移成质检通过。可对原音频重检；明显违反 nonverbal 事实的人类对白退出自动选用，不删除。迁移提供 dry-run 报告与变更前快照，可重复执行，不覆盖人工确认。

前端区分来源年龄、声音年龄与素材用途，展示实际提示词、版本、质检原因和处理动作。nonverbal 隐藏人类年龄试听入口，后端仍独立校验，不能只依赖 UI。

API 年龄槽位路径保留，语义修正为真正的版本年龄覆盖。统一错误原因覆盖未知发声模式、非法槽位、档案冲突、能力缺失、预算不足和过时任务；CLI 与 UI 都能据此定位处理方式。

## 9. 验收要求

### 无付费回归

1. 年龄未知不产生青年默认；中英文年龄别名正确归一，非法值不得静默转青年。
2. 同一角色选择 child、middle、elder 时实际提交的听感年龄分别变化；角色原始年龄不变。
3. 角色构建贯穿传递来源事实；缺失片段不抹除已有事实，冲突证据可追溯。
4. 朏朏不出现人类默认试听、不写人类年龄样本、不成为对白克隆参考；both 可分别保存两类素材。
5. 档案合并后检测冲突，模型/节点/语言不匹配在提交前暴露。
6. 解码失败、静音、台词错误、拟声词朗读等负例被相应检查拦截；无音频审查能力不自动通过。
7. uncertain 不触发付费重试；qc_unavailable 可重检同一文件；兽声跨重启仍最多生成两次。
8. 候选在重启后存在；并发与陈旧结果不覆盖新版本；重复发布幂等，取消不发布。
9. 提交受理状态未知时不重提；恢复下载或审查不重新生成。
10. 迁移保留旧文件、来源与人工确认；dry-run 不改数据，重复迁移无额外破坏。
11. CLI 批量只补缺失素材、返回可追溯状态；API/UI/CLI 使用同一规则。

### 单独授权后的真实验证

使用同一试听文本对比儿童、中年、老年设计，检查供应商实际收到的提示词及输出听感；再对朏朏一个用途进行最多两次的兽声实验。保存实际工作流、输入、音频、检测报告、耗时与扣费证据。

兽声实验失败可以验收「安全失败、有限重试、转导入」流程，但不能宣称 Qwen 兽声能力通过。离线测试通过不能替代真实听音验收；真实样例通过也不代表所有角色声音均可生产。

## 10. 实施顺序与审查记录

实施顺序：来源事实与迁移 → 统一声音编译和年龄槽位 → 持久化候选/版本与发布保护 → 质检适配 → 非语言实验与导入 → CLI/UI 集成 → 离线及授权实测。

2026-09-23：用户已确认数据分层、发声分流、旧素材保护，以及提示词编译、自动验收、版本恢复和兽声每用途最多两次的方案。本规格未执行数据迁移、服务重启或模型调用。

规格自检覆盖：事实与创作分离；质检状态与执行状态分离；按槽位年龄不修改原始设定；缺少审查能力不自动放行；两次上限不被恢复或并发绕过；费用未知不冒充零；历史素材可回退；不扩展至完整混音系统。
