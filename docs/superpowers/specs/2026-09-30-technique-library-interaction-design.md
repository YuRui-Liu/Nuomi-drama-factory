# 跨项目手法卡片库交互设计

日期：2026-09-30。用户已确认本设计的布局、范围、预览方式、跨项目共享及异常处理。实现直接在当前分支进行。

## 1. 背景与目标

现有画布视频导演台的手法选择控件同时显示原生下拉框和全部卡片文字列表。用户需逐行阅读模式、秒数与来源，难以先判断镜头效果；卡片增加后，导演片段也会越来越长。本设计把浏览卡片与编辑片段分开，让用户先按创作意图找到手法，再检查当前片段是否可用。

本设计是[MiniMax H3 精选手法卡片设计](2026-09-29-h3-technique-cards-design.md)的交互增量。保留每片段最多一张卡、用户手动选卡、AI 按素材改写、服务端适用性校验、生成快照与历史冻结、未选卡行为、失败时不回退原文提交，以及不增加 QC 闸门等既有规则。

首版验收目标：导演片段不再平铺整个目录；用户能从跨项目入口或片段入口浏览同一目录，按效果和创作目的找卡，明确理解为何适用或不适用，收藏常用卡，并在返回片段后看清当前选择。

## 2. 范围与入口

- 卡片目录与个人收藏跨项目共用。应用顶栏提供“手法库”入口，打开独立弹窗的**浏览模式**，不依赖项目或画布。
- 每个导演片段只显示已选卡片的短摘要、换卡和清除操作；未选时显示“挑选手法”。点击后打开同一弹窗的**片段选卡模式**，传入该片段的有效首尾帧、共享参考图、模型模式和实际对齐时长。
- 首版支持浏览、搜索、按创作目的筛选、查看收藏、收藏/取消收藏、查看详情和为片段选用一张卡。不开放用户新建、编辑、导入案例、自动推荐或跨片段批量应用。
- 全局浏览模式不显示“用于片段”操作；片段选卡模式选用成功后关闭弹窗并返回该片段，焦点回到触发按钮。

## 3. 弹窗信息层级

弹窗采用三栏，在窄屏可折叠为分类抽屉、列表和详情视图：

1. 左侧是“全部手法”“我的收藏”及按创作目的组织的类目，例如人物表演、双人关系、镜头运动、动作与揭示、首尾帧衔接。类目是浏览维度，不是 H3 模式的技术参数。
2. 中间是搜索、筛选和卡片网格。搜索覆盖标题、摘要、创作意图与类目；首版对已下载的小目录做即时本地筛选。片段模式默认“当前片段可用”，用户可切到“全部”查看不兼容卡与原因；不兼容卡仍可打开详情，但不可选用。
3. 右侧是选中卡片的详情，按“预期画面变化 → 动作/表演节奏 → 摄影机如何配合 → 最后落点 → 避免事项”排列。适用模式、时长、首尾帧约束和来源链接作为次级信息，仍可访问。

卡片网格优先显示标题、用一句话描述的效果、原创镜头示意、类别、收藏状态，以及片段模式下的适用状态。不得用小数长尾展示时长：用户看到人类可读的近似范围，精确秒数由兼容性校验使用。当前卡片因首尾帧、参考图或时长不适用时，详情解释具体条件，而不是只显示“不可用”。

默认按目录的人工精选顺序展示，不引入基于剧情的 AI 排名；搜索仅筛选匹配条目。时长显示最多两位小数并去掉多余的零，经过舍入的边界加“约”，兼容性仍使用未舍入的数值。筛选无结果时说明当前筛选并提供清除操作。收藏中的退役卡可在全局浏览或片段模式的“全部”筛选中查看，不能选用。

每张卡的示意图由项目自有素材制作，首版可使用与现有八张卡一一对应的简短关键帧/镜头运动图。必须明确标为“镜头示意”，不能暗示它是模型真实生成结果。第三方案例的视频和全文不嵌入、不打包；详情保留原有作者署名及外部来源链接。

## 4. 选择、收藏与数据边界

- 目录仍由服务端提供同一套版本化卡片定义。全局浏览不依赖项目 ID；片段选卡额外传入前端计算的有效片段上下文，服务端在生成时照旧独立校验，前端提示不能替代服务端验证。
- 收藏属于登录用户，跨项目可见并由服务端持久化，避免换设备或清浏览器后丢失。收藏按稳定卡片 ID 记录，而不是锁在某个版本；浏览时指向该 ID 的最新活动版本。卡片退役时收藏仍可见并标记退役，不能悄悄替换成其他卡。
- 片段选择继续保存 `id@version`，生成时冻结卡片内容哈希、投影和来源。收藏状态不进入生成输入或缓存键，也不能改变模型 Prompt。
- 切换片段、修改图片、时长或参考模式时，弹窗与片段摘要按最新有效输入重算适用性。若已选卡因此失效，保留选择和明确错误，阻止该次生成；用户可换卡或清除。不得静默删除或替换。
- 搜索、类目和“仅看可用”属于弹窗浏览状态，不修改草稿。收藏动作只修改用户收藏；点击“用于片段”才修改目标片段草稿。

## 5. 加载与失败状态

| 场景 | 交互 |
| --- | --- |
| 目录加载中或失败 | 显示明确状态与重试；目录失败时不能选新卡，未选卡片的原有生成流程继续可用。 |
| 收藏读取失败 | 目录浏览和选卡仍可用；收藏区提示读取失败及重试，不把空列表伪装为真实收藏。 |
| 收藏写入失败 | 恢复该卡原收藏状态，显示“未保存”及重试；不能出现已收藏的假成功。 |
| 已选卡的 ID/版本已不可解析 | 片段保留原选择并标记不可用，允许换卡或清除；生成校验继续阻止提交。 |
| 片段输入变化使卡片不兼容 | 片段摘要与详情显示具体原因，不自动改图、模式或时长。 |
| 弹窗关闭或选用 | 将焦点还给打开弹窗的按钮；再次打开时按当前片段重新计算。 |

弹窗需要语义化对话框、可见焦点、键盘搜索与选择、Esc 关闭和焦点约束；窄屏下详情可返回列表，不丢搜索条件或已选卡。

## 6. 组件和接口职责

目录读取、收藏读写、片段适用性计算、弹窗展示和导演草稿更新各有单一职责。弹窗接收可选的片段上下文与选用回调；无上下文即浏览模式。顶栏只负责打开弹窗，不加载导演草稿。导演片段只传入其有效输入与当前卡片选择，不承载整个目录列表。服务端目录接口应由跨项目路由提供；既有项目级路由可兼容保留，直到调用方迁移完成。

示意图作为自有、可版本化的展示资源关联到卡片 ID，不参与优化器投影、生成快照或内容哈希。若示意资源缺失，用文字效果摘要替代，不能影响选卡或生成。外部来源链接仅作溯源，不在运行时读取第三方站点。

## 7. 验收与测试

- 顶栏可无项目上下文打开全局浏览；所有项目看到同一目录与同一用户收藏；不同登录用户的收藏隔离。
- 片段打开默认筛选适用卡，切换“全部”能看到不兼容原因；键盘和窄屏可完成搜索、看详情、选卡、返回片段。
- 片段只显示当前卡摘要和操作，不再平铺目录；选卡、换卡、清除只修改目标片段。复制、重排、删除和刷新沿用既有选择绑定行为。
- 收藏成功、读写失败、退役卡及目录失败各有可见状态，且收藏不改变 Prompt、模型路由或生成快照。
- 改模式、帧或时长后，前端提示与服务端提交校验一致；已选不兼容卡被保留但不能生成。未选卡生成、优化失败暂停、历史冻结与无额外 QC 规则继续通过原有契约测试。
- 镜头示意与来源链接可访问，且不会被描述成实测生成效果。首版不声称手法卡已改善视频质量；效果仍需按既有离线成对评估方案验证。

## 8. 非目标

首版不做卡片作者后台、用户投稿、案例视频托管、自动根据剧情推荐卡片、向量检索、将收藏同步到片段选择、按收藏影响模型 Prompt，或接入叙事组/单 Beat 的生成路径。未来这些场景可复用通用目录和语义字段，但需分别定义入口与适用性。
