# 场景规划的资产库权威与宽松生成补充设计

## 背景

当前场景规划会把导演方案中的 `scene_anchor` 当作基础场景候选，并在候选不存在时调用普通文本模型重新校对。这样既会在未配置文本模型时令任务失败，也可能把 `### 1-1 谢家碑坊` 一类场次标题或导演生成的自由文本写入资产库。生成前引用预览随后又要求这些规划引用全部存在，最终以 409 阻止用户继续。

本补充设计覆盖原“规划期资产绑定与生成前引用选择设计”中关于场景来源和必需引用严格阻断的相应规则。

## 权威边界

- 项目场景资产库是基础场景身份的唯一权威来源；外部导入的场景表进入资产库后遵循同一规则。
- 场景规划可以新增基础场景，但名称必须来自场景表或剧本场次的规范化结果，不能来自导演方案的自由生成文本。
- 导演方案不是场景目录。它只描述镜头要使用的场景、时间和可见状态，并请求在规范基础场景上建立变体。
- 场次编号、Markdown 标记、内外景标记和时间标记只作为来源信息，不进入基础场景 ID。
- 找不到唯一基础场景时记录“待关联场景”，不自动创建、不模糊猜测，也不污染资产库。

## 场景规划流程

1. 读取现有场景资产库和本集已导入的场景表。
2. 从场景表或剧本场次头提取并规范化基础场景名称，去除 `###`、场次编号、内外景和时间等结构标记。
3. 精确匹配已有基础场景；规范来源明确且不存在时，允许场景规划创建新的基础场景。
4. 读取导演方案的 `scene_base`、`scene_state` 和场景锚点，将其解析为对规范基础场景的引用请求。
5. 匹配到唯一基础场景后，只在该基础场景上创建结构化变体；变体保存独立的 `base_scene_id` 和 `variant_id`。
6. 无法匹配时生成待关联记录，禁止把导演文本降级成新的基础场景。

AI 可以补充环境描述、光线和氛围，但不参与决定基础场景身份。AI 不可用或普通文本模型未配置时跳过可选补充，确定性的场景规划仍应成功。

## 道具和其他引用

导演方案中的道具需求可以作为道具规划输入，但正式道具仍由道具规划写入资产库。生成预览不能因为场景规划没有顺带完成道具规划而把场景关系改写成临时实体。

## 生成前引用

- 生成弹窗只展示已经绑定且有可用图片的正式资产，以及用户为本次生成上传的临时图片。
- 缺少、待关联或缺图的引用显示为警告，不再因为 `required=true` 统一阻止生成。
- 用户可以用当前可用引用继续生成；服务端只冻结实际选择且可解析的引用。
- 仍拒绝越权绑定、失效版本、路径越界、超过数量上限等数据安全问题。
- 409 等结构化错误必须显示后端的具体信息，不能退化为通用请求失败文案。

## 不变量

- 生成预览和生成提交永远不创建或重命名正式场景。
- 导演方案自由文本永远不能直接成为基础场景 ID。
- 场景变体必须属于一个已经存在或由规范场景来源创建的基础场景。
- 临时图片仅用于本次任务，不写入场景资产库，也不建立永久绑定。

## 验收标准

- 未配置普通文本模型时，基于资产库和规范场景来源的场景规划可以完成。
- `### 1-1 谢家碑坊` 只会解析或关联到 `谢家碑坊`，不会成为资产名称。
- 导演方案请求“暴雨天井”时，只能在已关联基础场景上创建变体；无匹配基础场景时进入待关联状态。
- 重新规划不会新增由导演自由文本产生的非标准基础场景。
- 缺少场景、变体、道具或图片时，生成弹窗显示警告并允许使用其余正式资产或临时图片继续生成。
- 引用错误显示可理解的具体原因，不再只显示通用 409。

## 测试重点

- 基础场景名称规范化及 Markdown/场次编号剥离。
- 外部导入场景的精确复用，以及规范剧本场景的受控新增。
- 导演场景状态只能创建子变体，不能创建基础场景。
- 无匹配、歧义匹配和文本模型不可用时不污染资产库。
- 缺失规划引用的预览与提交保持宽松，安全类错误仍严格拒绝。
- 前端正确解析并展示结构化后端错误。
