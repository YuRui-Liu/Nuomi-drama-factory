# 规划引用身份对齐与基础资产回退设计

## 背景

身份规划已经为角色选择了规范身份，例如「陆无咎 → 青年时期」，资产库中也存在对应身份图；但规划引用投影仍把导演镜头需求里的角色名「陆无咎」当作 `identity_id` 精确查询，因此生成前弹窗错误显示 `missing_asset`。场景存在相同断层：镜头要求某个场景变体时，只查变体资产；变体不存在或尚无图片时，已有的基础场景图也不能使用。

问题发生在规划绑定阶段，不是前端选择控件或图片文件本身。生成弹窗只是忠实地禁用了错误的 `missing_asset` 绑定。

## 目标

- 规划引用优先消费身份规划和场景规划已经建立的规范关系。
- 人物优先使用规划身份图；身份图不可用时默认使用角色基础头像。
- 场景优先使用对应变体图；变体不存在或不可用时默认使用基础场景图。
- 回退项默认选中，并允许用户在生成前取消。
- 最终绑定始终保存真实实体 ID 和真实资产槽位，不用显示名称充当 ID。
- 多候选或关系不明确时不猜测，保持 `pending_confirmation`。

## 匹配优先级

### 人物

1. 若镜头需求的 `entity_key` 精确等于一个 `identity_id`，直接绑定该身份。
2. 若镜头需求只包含角色名，读取本集身份规划结果 `episode.identity_ids` 与 `identity_default_map`，优先绑定该角色在本集已选的默认身份。
3. 若没有默认映射，但该角色在本集规划范围内只有一个身份，绑定该身份。
4. 兼容名称只在同一角色的已规划身份集合内比较；「青年期」与「青年时期」可归一为相同阶段标签，但最终写入资产真实 `identity_id`。
5. 身份资产存在且身份图可用时，绑定身份槽位并标记 `auto_matched`。
6. 身份已确定但身份图不可用、角色基础头像可用时，改绑头像槽位，标记 `ready + explicit_fallback`，默认选中。
7. 同一角色仍有多个可能身份时标记 `pending_confirmation`；不存在任何人物资产时才标记 `missing_asset`。

### 场景

1. 按结构化 `base_scene_id + variant_id` 精确匹配规划变体。
2. 变体存在且图片可用时绑定变体槽位，标记 `auto_matched`。
3. 变体不存在、无图或没有可采用版本，而对应基础场景图可用时，绑定基础场景槽位，保留原请求的 `base_scene_id` 和 `variant_id`，标记 `ready + explicit_fallback`，默认选中。
4. 基础场景关系不唯一时标记 `pending_confirmation`；基础场景也不存在时标记 `missing_asset`。

## 数据流

身份规划发布绑定时，将本集的 `episode_identity_ids` 和 `identity_default_map` 一并传给绑定投影器。投影器不再仅凭导演需求字符串扫描全部身份。

场景规划发布绑定时，投影器同时读取变体和对应基础场景。回退仍在规划事务内确定并持久化，生成预览阶段只解析绑定记录中的 `asset_slot_id`，不创建实体、不拼接名称，也不重新猜测关系。

生成前引用卡片继续以 `binding_id` 为选择键。所有 `ready` 绑定（包括 `explicit_fallback`）默认选中，点击卡片或复选框可取消。回退卡片应展示实际使用的资产名称，并提示它替代了哪个身份/变体请求。

## 错误与兼容

- 已持久化的错误绑定通过重新规划身份或场景生成新绑定，不在生成阶段静默改写数据库。
- 老项目没有 `identity_default_map` 时，仅允许“同角色、本集唯一身份”的确定性兼容。
- 名称归一只处理明确的阶段后缀，例如「青年期/青年时期」；不做跨角色模糊匹配。
- 找到多个候选时不按列表顺序选择。
- 回退槽位没有当前可采用图片版本时，仍返回 `missing_image`，不能伪装成可用。

## 测试

后端回归测试覆盖：

- 角色名需求解析到身份规划指定的「青年时期」真实 `identity_id`。
- 「青年期」兼容匹配同一角色的「青年时期」，但不跨角色匹配。
- 同角色只有一个本集身份时确定性绑定；多个身份且无默认映射时待确认。
- 身份图可用时优先身份图；不可用时回退基础头像并标记 `explicit_fallback`。
- 场景变体图可用时优先变体；变体缺失或无图时回退基础场景。
- 基础资产也不可用时保持结构化错误状态。
- 生成预览将 `ready + explicit_fallback` 默认选中，提交仍按稳定 `binding_id` 校验。

## 验收标准

- 资产规划显示「陆无咎 → 青年时期」且资产库已有该身份时，生成前引用不再显示 `planned binding status is missing_asset`。
- 用户无需重新添加或重命名资产即可选择规划身份图。
- 请求场景变体时优先展示变体；没有可用变体图时自动展示并选中基础场景图，用户可以取消。
- 人物身份图不可用时自动展示并选中角色基础头像，用户可以取消。
- 任何歧义都可见且不会静默绑定到错误资产。
