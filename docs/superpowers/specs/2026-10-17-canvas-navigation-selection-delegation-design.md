# 画布导航与选择委托交互设计

日期：2026-10-17。状态：用户已确认 A「按需展开」方案及「先选择内容，再发起委托」规则；本文待书面审阅。

## 1. 目标与范围

解决当前左侧画布列表、新建表单长期占用空间，以及画布右上多个配置入口与委托入口并列的问题。保持现有黑色画布、节点编辑器、任务机制及专业 Agent 能力；本轮只调整导航、配置入口与选择委托的交互，不重新设计生产管线。

这是对 `2026-10-16-professional-agents-interaction-design.md` 中画布入口组织的补充。此前 A01—A06 为实际前端还原参考，不代表本次新方案已实施。讨论原型位于 `.superpowers/brainstorm/interaction-20261017/content/layout-comparison.html`，使用模拟数据，未连接真实任务；脚本语法已检查，浏览器工具超时，尚未完成视觉验证。

## 2. 已确认的方案选择

- A：当前画布名称作为紧凑切换入口，按需展开列表；节点操作就近出现。用户已选择。
- B：常驻可折叠目录，频繁跨分集切换更直接，但占用左侧宽度。不采用。
- C：顶部画布标签，少量画布切换直接，但长名称和多画布拥挤。不采用。

## 3. 画布切换与创建

左上默认仅显示当前画布名称与展开标记，不常驻列表或创建表单。没有画布时显示「选择或新建画布」。打开后显示搜索、已有画布及底部「新建画布」。按现有构思／分集／自由分类组织已有项目，空分类不占单独分组空间。

选择条目后切换并收起浮层，恢复目标画布自身的视角和选择；不得将前一张画布的选择传给目标画布。点击外部或按 Escape 关闭浮层，焦点返回切换按钮。搜索无结果显示清除搜索与新建入口；加载失败显示重试，不清空当前可用画布。

点击新建才打开独立表单，包含名称与类型。默认沿用当前画布类型；项目没有画布时默认构思类型。空白名称不可提交，名称和类型校验遵循现有接口契约。提交中禁止重复点击；失败保留输入并允许重试。成功后切换到新画布并收起表单，不自动启动 Agent 或生成任务。取消创建保留原画布、视角与选择。

## 4. 项目设置入口

把项目机组、风格与手法、创作对象与约定、模板入口统一收进「项目设置」，移除画布右上横向排列的配置按钮。入口位于项目导航区域，内容使用现有面板和配置能力，不新增平行的数据模型或第二套编辑器。

设置面板明确显示项目作用范围。项目默认风格与选中内容的局部设置分开表达；现有选择相关能力保留在节点操作及相应编辑器中，不把局部修改静默提升为项目默认。打开设置不改变选择、视角或运行任务；关闭后回到原位置。

配置保存、模板应用继续遵循既有预览及采用规则，不因移动入口就自动执行任务。模板库本轮只迁移入口，不扩展应用范围或批量执行能力。

## 5. 选择与委托

未选中节点时，不显示委托入口。选择一个或多个节点后，在选区附近显示「编辑／委托选中内容」等适用操作。编辑仅在选区支持对应操作时提供，不虚构通用批量编辑能力。

点击委托，复用现有 Agent 侧栏作为唯一目标输入与进展入口；明确展示当前画布、所选节点数量及名称、任务目标、输入范围、允许修改的对象与交付方式。多选清单可展开。关联参考可作为只读上下文，不能因此自动扩大可修改范围。

打开委托时保存本次选区快照。其后画布选择变化不得悄悄改变已编辑的委托范围；面板提示选择已变化，提供「更新为当前选择」，用户更新时保留目标文字。提交前核对节点仍属于当前画布且仍存在；范围为空、节点删除或不可访问时阻止提交并说明原因。切换画布时关闭原委托面板，将未提交目标与范围保留为原画布草稿，不跨画布沿用。

提交沿用现有授权、能力检查、费用及重复提交控制。缺少权限、能力或输入时就地指出并保留草稿，不伪报已执行。提交成功给出任务回执并继续在侧栏显示状态，用户关闭侧栏不会取消任务。恢复任务沿用原任务范围，不能用当前选区覆盖原范围。

针对已有内容的修改以候选草案交付，采用前不覆盖原内容；不新增无条件自动采用行为。现有完整制作与运行选中节点等能力保留其既有语义，本规则针对新增委托入口，不删除既有运行能力。

## 6. 画布助手

保留独立「画布助手」入口，默认收起，打开与关闭均保留当前视角及节点选择。未选择内容时可讨论；从讨论进入新委托执行时，要求明确选择内容并绑定范围，不自动将当前画布或整个项目当作修改对象。普通消息和已有任务的进度查询不被误判为新委托。

原型中的「以故事节点演示委托」仅为演示快捷入口，不进入正式产品；正式交互由用户选择内容。

## 7. 实现边界与状态归属

- `CanvasWorkspaceSwitcher`：负责切换浮层、搜索和创建表单，通过现有 `onSelect`、`onCreate` 与项目画布数据交互。
- `CreationWorkspace`：继续管理当前画布及切换，不在导航组件内复制后端状态。
- `FreezoneShell` 与节点选择状态：负责按选择展示入口，保持每张画布视角及选择；项目设置负责聚合现有入口。
- 现有 Agent 侧栏及运行状态：承接目标、选区快照、提交检查、任务回执、候选与恢复。前端显示范围必须与服务端实际执行范围一致，不能只修改标签。

浮层开闭为本地临时状态；画布清单与创建结果仍以后端返回为准。草稿按项目与画布隔离，延续已有草稿持久化能力。异步返回时校验请求所属画布，避免切换后把结果显示到另一张画布。

## 8. 验收与交付

1. 初始画面无常驻新建表单、空分类或右上配置按钮排；主要空间保留给内容。
2. 鼠标与键盘均可打开切换列表、搜索、切换、创建及取消；浮层关闭后焦点可恢复。
3. 空选区无委托入口；单选、多选均准确显示范围；清空选择后不残留可提交空范围的入口。
4. 委托草稿遇到选区变化、节点删除和画布切换时，按第 5 节处理，不发生静默范围扩大。
5. 提交失败保留草稿；重复点击不创建重复任务；任务进度、候选采用及原任务恢复仍可使用。
6. 验证主流桌面宽度下列表、节点操作条和侧栏无越界、遮住关闭按钮或文字裁切；窄窗口中浮层保持在可见区域内。
7. 自动化验证重点覆盖选择与范围、创建失败／重试、切换状态保持；视觉验收使用实际前端截图与交互走查，不仅检查源码或静态导入图。

书面规格审阅后，制定实施计划，并据此更新 Pencil 的默认态、切换／新建态、单选／多选委托态及失败态。只有经实际操作验证的交互才能称为可点击原型或已实现功能。
