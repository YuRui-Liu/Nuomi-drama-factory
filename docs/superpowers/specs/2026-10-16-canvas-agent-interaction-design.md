# 画布与 Agent 创作交互改造设计

日期：2026-10-16。分支：`feat/canvas`。实现核查基线：`b59cc05`。

本文补充 `2026-10-13-agent-canvas-prd.md`，记录本轮已确认的交互选择，并作为后续实现计划的输入。当前阶段完成设计与演示原型，不表示产品功能已实现。

## 1. 目标与现状

用户应能在画布选取上下文、委托 Agent、看到真实生成内容直接成为可编辑节点，再继续修改、替换或撤销。创作流程不依赖切页或阶段流水线。

当前模型适配器和受限运行器已有实现，文本候选能够持久化，但尚未完成真实模型端到端验收。结果卡缺少采用、替换和领域撤销；相关操作类型的声明不能视为功能完成。受管理画布只有创建、查询和选择入口，旧 freezone 文件删除接口不能直接替代画布生命周期服务。

保留现有深色风格、主要节点及专业编辑器、跨集资产中心的基础／变体机制、风格库和手法库。重新组织工作台入口、状态与反馈。ontology 用于对象身份、关系、版本与来源约束，不要求创作者先操作技术配置。

## 2. 已确认的工作台布局

- 采用按需展开 Agent 的布局。默认收起；展开时占用右侧布局空间，画布同步缩窄，不覆盖节点。
- 保持画布缩放比例。展开时仅在选中内容被遮出可视范围时平移视口；多选范围大于可视区域时保持最近聚焦节点可见，不强行缩小全部内容。关闭侧栏释放空间，不重置缩放或创作上下文。
- 左侧列表管理构思、分集、自由画布。画布局部工具负责添加节点、引用资产和视图操作。项目配置归入二级面板。
- 顶部保留项目定位、画布、资产中心及风格／手法入口。运行情况汇总到任务状态，避免多个配置按钮散落在画布上。

## 3. Agent 侧栏

顶部仅呈现当前 Agent、会话切换、收起入口；模型、能力、版本、专业 Agent 与风格配置按需打开。主体为对话与任务卡，底部固定输入框和引用标签。

选中节点后可一键添加引用，引用加入后显示明确标签；改变画布选择不静默改写已经准备的引用，移除引用不删除节点。发送前校验作用域和节点版本；有语义变化时提示刷新引用。

未选主创时显示选择入口；模型不可用时显示具体原因和配置入口。模型配置可用与任务可以执行是不同状态，不使用笼统的“已就绪”掩盖缺失前提。

侧栏收起不停止任务。画布 Agent 按钮显示运行、完成或失败状态，重新展开可恢复会话。切换画布后显示该画布的会话，不把其他画布的引用或草稿带入当前输入框；原画布任务继续记录在原作用域。

## 4. 真实执行与结果落图

任务卡集中表达准备、生成、写入画布、完成、失败、停止及提交状态待核实。模型生成成功而画布投影未完成时，显示“正在写入”或“写入失败”，不能提前宣称落图完成。

新增内容自动创建草稿节点，无需在侧栏再次点击采用。草稿可直接编辑，保留 Agent、任务、输入版本与候选来源。草稿是持久化创作对象，不等于已批准的正式共享资产；引用既有资产继续使用固定版本与基础／变体关系。

生成时在目标附近显示任务位置提示，不提前创建伪成果。失败或停止后保留输入和已完成成果，未完成的提示可移除。模型请求状态不明时先查询／核对，不能直接重发；技术重试默认不自动执行。

一次生成多个节点，自动放入一个可解散分组，寻找引用节点附近的空白区域，不移动已有节点。无引用节点时以发送时的画布视口中心为布局锚点。分组支持整体移动、定位及继续委托；解散仅移除分组关系，保留节点和连线。布局由画布服务确定，模型不能提供任意写入指令。

任务恢复、页面刷新或重复回执不能创建重复草稿和分组。由固定任务输出身份绑定创建操作，并通过既有事务与投影机制完成。

## 5. 替换与撤销

修改既有节点先生成候选，不静默覆盖。侧栏提供差异预览，明确目标及版本；点击“采用并替换”本身构成针对这次替换的授权，不叠加重复确认。

执行前再核验目标版本。发生后续编辑则保留候选和当前内容，提示冲突并重新比较，不强制回滚或覆盖。涉及共享资产的改动必须明确影响范围，普通画布替换不隐含共享资产修改权限。

采用、替换的撤销采用服务端补偿操作，刷新后仍可用。仅撤销本次变更；目标已有后续编辑或引用依赖时，提示具体冲突并保留现场。不能以浏览器的本地视图 undo 代替领域撤销。删除画布恢复与内容替换撤销为不同操作。

## 6. 画布管理

- 列表条目 `⋯` 提供重命名、移到回收站，双击名称也可改名。名称去除首尾空白，长度沿用现有服务约束，不允许空名称。改名不改变画布身份、节点或会话归属。
- 删除为软删除，保留节点、连线、视图、会话与来源；回收站可恢复。删除不删除分集本身、不修改跨集资产、风格库和手法库。本期不提供永久清除入口。
- 删除前显示具体影响。有运行任务时提供“停止任务并删除”；先建立停止／写入围栏，再完成软删除。即使外部请求无法取消，迟到回执也不能向已删除画布新增内容，费用和结果记录仍需接收并保留。
- 删除当前画布后切换到列表中的相邻可用画布；无可用画布显示创建入口。已删除画布的旧链接显示删除状态和恢复入口，不启动任务或隐式创建画布。
- 保留每集唯一主画布、每项目唯一构思画布的身份约束。软删除后再次创建对应画布时引导恢复原画布，不另建第二个身份；自由画布不受此唯一性限制。
- 恢复不自动恢复已停止任务，不重发模型调用。权限验证、重复请求和恢复均由服务端处理。

## 7. 费用与停止语义

沿用 PRD 的严格金额预算要求。任务卡展示预计费用、调用范围及必要授权；调用次数不等于金额上限。无法证明金额上界时，严格预算模式暂停，只有明确的不确定费用授权可以进入对应受限调用，不能以一般“发送”替代该授权。

停止阻止后续准入与应用，保留已完成内容；已经提交的请求和待结算费用不被清零。未知请求先核实。当前计量接口尚无可信币种与最小货币单位上界凭证，实现计划必须明确其适配边界，不能从 token 数或内部积分伪造金额。

## 9. 验收标准

1. 在常用桌面宽度下展开／收起侧栏，画布缩放不跳变，当前聚焦节点仍可见，输入与运行状态保留。检查首次空画布、已有复杂节点画布及窄窗口布局。
2. 改名后刷新仍保留；删除后当前画布切换正确，旧链接不误写；恢复节点／连线完整，共享资产和分集身份保留。
3. 使用已配置的真实文本模型，引用两个节点发起一次明确授权调用，获取真实 request／usage 证据，自动形成可编辑草稿；不得用 mock 结果宣称真实联调通过。
4. 多节点输出只有一个分组，位置不覆盖或移动既有节点；解散后内容保留。重复点击、回执重放和刷新不重复创建。
5. 对比后替换指定节点，刷新后可撤销；并发修改造成冲突时双方内容均保留。普通新增不出现额外的采用确认。
6. 收起侧栏、切换画布不会让任务错写；停止和删除与发送并发时禁止新准入，迟到回执保留记录但不复活画布。
7. 失败保留输入和部分成果；投影失败可幂等恢复；提交状态不明不自动重试；没有可用模型时准确显示阻塞原因。
8. 模型链路测试、领域操作测试和前端交互验证并行执行，最后用同一个真实创作场景贯通。只复跑受影响的检查，不重复全量测试来替代缺失的真实验收。

### 12.1 视觉与布局修订

延续当前 NuomiDrama 深色、黄绿色强调色、点阵背景及节点视觉。底部按用户提供截图采用工作室悬浮栏：工作室入口、白色添加按钮、历史、快捷键与帮助；右下角为连线、整理、缩放、吸附、小地图及视口书签；最底部保留任务、连接和版本状态。控件相对可见画布定位，不覆盖 Agent 输入区。

### 12.2 变体生成修订

资产中心负责管理与引用，变体图在画布生成节点内生产。流程为基础资产／既有变体 → 选择目标画布 → 关联版本引用与生成节点 → 描述差异并生成 → 选取结果 → 保存为共享变体或新版本。创建节点不代表付费生成授权，保存结果也不代表自动更新其他引用。画布产物在显式保存前仍是本地创作结果；保存后关联资产身份，保留原画布内容。
