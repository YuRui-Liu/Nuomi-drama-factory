# 导演分镜审核页可读性改版

日期：2026-10-10

## 已确认的方向

用户选择 A「镜头阅读优先」，主要阅读目标为镜头动作、对白和叙事顺序。原型见 `.superpowers/brainstorm/67757-1791561964/content/director-review-layouts.html`。原型是布局讨论材料，示例状态与中文 QC 摘要不作为生产数据。

## 问题和范围

当前页面将版本信息、逐镜导演参数、审核历史、结构编辑和素材迁移依次堆在同一个长滚动区。正文使用较小字号，镜头动作与操作按钮共用一行；完整版本 ID 和素材种类枚举直接呈现，影响扫描阅读。

本次修改现有 React 前端的排版和信息组织，复用已有 API、数据、状态和操作。重点是阅读体验，不修改导演规划、QC 标准、版本派生、素材采用和激活权限。已有未提交修改必须保留，不覆盖其他工作的实现。

## 页面结构

1. 页头保留标题、当前集数、重新导演分镜和关闭入口。
2. 左侧保留版本历史，使用「版本 1」等短显示名、时间和状态；完整 ID 收进可复制的版本详情。显示名按创建时间稳定编号，实际选择和操作仍使用 revision_id。
3. 主区顶部显示当前版本、叙事组数、镜头数及现有状态。数量由当前版本数据计算，不硬编码。
4. 内容区提供「镜头内容」「审核问题」「素材复用」「版本变化」入口，默认打开镜头内容。审核问题入口显示当前反馈的未解决问题数量；不能从缺失数据推断通过或零问题。
5. 镜头内容按原 groups 和 shots 顺序连续显示。宽屏阅读正文在左，审核摘要在右；窄屏改为单栏，所有信息与操作仍可访问。
6. 固定底部保持原放弃、恢复、激活及进入分镜生图操作，增加可从现有数据解释的禁用原因，内容末尾留出高度，避免被底栏遮挡。

## 镜头卡片

每个叙事组显示序号、目标及组内镜头数量，组编辑操作收进「调整结构」菜单。每个镜头是独立卡片，按以下顺序展示：

- 镜头序号，场景/时间锚点，以及可用的时长。
- 「画面与动作」：完整 action 正文，使用 15–16px 字号、约 1.8 行高、限制阅读行宽，保留已有换行。不能截断关键正文，也不能为视觉分段修改实际 action。
- 「叙事意图」「观众注意」：分别展示已有字段，缺失字段不编造。
- 「所需素材」：用中文类型标签和实体名称的可换行标签展示；完整类型和证据进入详情。
- 「导演细节」：默认折叠，展开后展示景别、机位、构图、运镜、光影、表演与衔接等现有字段。缺失数据保持原有缺失提示。
- 镜头级移动、拆分入口独立于正文，保持原有可执行条件和命令参数。

当前 ShotPlan 只有 dialogue_source_ids，没有独立对白文本字段。因此不从 action 猜测或生成对白。若复用现有原文查询可以按真实 source ID 无歧义取得对白，则展示独立的原文对白区；否则保留完整动作文本并提供对白来源标识详情。独立对白排版不是新增后端字段的前提。

## 审核问题和导演详情

镜头内容右侧只显示现有审核状态、当前待修问题简述和复查入口。完整问题、验收条件、作者响应、QC 响应和检查证据放入审核问题区。历史默认折叠，保留完整原文。

原型中的中文摘要由人工为讨论整理。正式实现不引入自动翻译，不把英文替换为未经核验的中文，也不伪造问题与镜头的关联。使用现有明确 shot_id 的 assessment 才提供对应镜头定位；仅有 description 的 issue 按版本级展示。

导演参数继续使用现有中文字段名映射。原始字段、完整 ID、证据路径以详情呈现，未知字段仍保留。不能因改善可读性隐藏阻塞问题。

## 数据和组件责任

- `director-review-workbench.tsx`：版本选择、栏目切换、整体布局与既有 mutation 调度。
- `group-editor.tsx`：叙事组和镜头阅读卡片、结构操作。
- `creative-review-panel.tsx`：复用导演决策显示、问题列表及历史详情；必要时提取独立展示组件，避免重复显示全部镜头参数。
- `asset-migration-panel.tsx`：保留现有复用判断与操作，改善名称换行和空状态，在素材复用栏目展示。
- `revision-comparison.tsx`：版本变化栏目，未提供对比数据时显示真实空状态。
- `activation-bar.tsx`：原有操作和禁用条件、禁用原因与底栏布局。

只在这些职责需要时拆分组件；不进行无关重构，不改变 query keys 或 API 返回契约。

## 状态和错误处理

保留加载、空版本、旧版未审查、QC 提交中/失败/完成、结构操作中及素材迁移错误反馈。版本切换后不保留失效的镜头定位。原有 busy/disabled 条件作用于新的菜单与按钮，不允许排版改动绕过审核和激活限制。

栏目按钮和详情可通过键盘操作，具有清晰焦点和选中状态。选择菜单和折叠区使用已有 UI 组件或语义元素。暗色正文对比度目标为 WCAG AA；状态同时使用文字与颜色。

## 验收与验证

1. 默认进入即可按剧情顺序读到镜头内容，不需先滚过全部导演参数与 QC 历史。
2. 长 action、英文 QC、完整 ID 和长素材名称都能换行，不撑破卡片或产生水平页面滚动。
3. 导演细节、审核历史和版本完整 ID 可访问，默认不占据主体阅读区域。
4. 原文、镜头顺序和结构编辑命令不被改写；移动、拆分、合并仍派生新版本。
5. 复查、素材决策、恢复、放弃和激活沿用现有约束；错误和处理中状态可见。
6. 执行相关 director-review 前端测试，补充真正有行为价值的栏目切换、折叠可访问性和激活约束回归验证。
7. 在浏览器用真实项目验证宽屏、常见桌面宽度和窄屏布局，保存改版截图，检查固定底栏不遮正文。

## 规格自检

已明确前端改版边界、原型与实际数据差异、对白字段限制、问题关联规则、组件责任和验收方式。不存在待定实现项；当前规格待用户审查，审查后编写实施计划。
