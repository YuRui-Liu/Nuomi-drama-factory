# 角色头像性别与纯头面部构图修复设计

## 背景

角色资产中心中的角色记录已经包含明确性别，例如“女”，但头像生成结果仍可能成为男性；当前头像还会生成肩部、胸像、服装和手部，而用户需要的是仅包含完整头发、耳朵、面部和下巴的头像。

根因位于头像生成请求边界：

- 角色主头像使用已确认 VisualBible 编译提示词后，没有继续携带角色记录中的 `gender`。
- 主头像和身份头像的最终提示词明确要求 `head and shoulders`，与纯头面部构图冲突。
- 当前默认 `2:3` 纵向比例进一步鼓励模型补全上半身。

## 目标

- 明确性别的角色必须在主头像和身份头像请求中获得一致、强制的性别约束。
- 头像统一采用 B 型纯头面部构图：完整头发、耳朵、面部和下巴可见，画面在下巴附近结束。
- 头像禁止出现颈部、肩部、胸部、衣物、手和道具。
- 性别为空或无法识别时不推断性别、人类体貌或二元性别表现，允许非人类主体保持自身设定。
- 保留 VisualBible 中已确认的脸型、五官、发型、显著特征和身份锚点。

## 非目标

- 不修改 VisualBible 数据结构或现有持久化格式。
- 不修改身份三视图、角色全身图、服装图或其他资产生成流程。
- 不增加生成后的人脸分类、性别识别、自动裁切或重试服务。
- 不尝试通过角色姓名推断性别。

## 方案选择

采用在角色头像后台任务的最终请求边界统一添加性别与构图约束的方案。

未采用以下方案：

- 将性别写入 VisualBible：需要提案、确认、存储和迁移链路的更大范围改造。
- 生成后检测、裁切或重试：增加成本和不确定性，且无法从源头保证身份正确。

## 性别约束

新增一个小型、可独立测试的性别规范化逻辑，只接受明确的已知值：

- `女`、`女性`、`female` 规范为女性约束。
- `男`、`男性`、`male` 规范为男性约束。
- 空字符串、未知值、非人类标记或其他未识别文本不产生任何性别分类。

明确性别时，最终提示词同时包含正向与反向约束：

- 女性：主体必须为女性，禁止生成男性面部、男性身份或男性化体貌。
- 男性：主体必须为男性，禁止生成女性面部、女性身份或女性化体貌。

性别约束的优先级高于 VisualBible 中可能含糊或冲突的文本，但不覆盖脸型、五官、发型和身份锚点。

未知性别时，不写入 `male`、`female`、`man`、`woman`、中性人类或类似推断词。提示词只描述“主体身份”，由已确认 VisualBible 决定其外观；这允许非人类生物不被强制套用人类性别表现。

## 构图约束

主头像与身份头像共用同一头像构图提示词，要求：

- 单一主体、正面或轻微三分之四角度。
- 完整发顶、发型轮廓、双耳、完整面部和下巴均在画面内。
- 面部占据画面主体，画面在下巴附近结束。
- 不显示颈部、肩部、胸部、上半身、衣物、手、道具或环境。
- 中性、干净背景，无文字、水印或签名。
- 使用 `1:1` 输出比例，避免纵向画布诱导上半身构图。

删除或替换现有冲突措辞，包括：

- `head and shoulders`
- `minimal visible clothing`
- `plain simple dark top`
- 任何要求展示服装、肩部或胸像的描述

## 数据流

1. 后台任务从 SQLite 角色记录读取 `gender`。
2. 已确认 VisualBible 继续编译脸型、五官、发型和身份锚点。
3. 头像请求构建器将规范化性别约束、B 型构图约束、VisualBible 快照、项目风格和种族配置组合成最终提示词。
4. 主头像和身份头像调用相同构图构建器；身份头像额外保留身份名称与年龄等有效身份信息。
5. GRSAI 请求使用 `1:1` 比例生成图片。

## 错误与兼容性

- 未确认 VisualBible 时仍保持现有拒绝行为，不调用图片传输层。
- 未知性别不视为错误，也不阻止生成。
- 不修改 API 请求和响应结构，不需要前端迁移。
- 不修改现有头像文件路径、历史记录和替换逻辑。
- 现有项目不需要数据库迁移。

## 测试策略

在生产代码修改前先添加失败测试，覆盖：

- 女性主头像最终请求包含女性正向约束及男性反向约束。
- 女性身份头像保留相同性别约束。
- 男性角色获得对应的男性约束。
- 空值、未知值和非人类标记不产生任何男女推断词。
- 主头像与身份头像均要求 B 型完整头面部裁切并使用 `1:1`。
- 最终请求不包含 `head and shoulders`、服装、胸像或手部展示指令。
- VisualBible 的脸型、五官、发型、显著特征和身份锚点仍存在于最终请求。
- 未确认 VisualBible 时仍不会调用图像传输层。

完成后运行角色头像定向测试、相关角色视觉编译测试、Ruff 和 `git diff --check`。

## 验收标准

- 性别为“女”的角色生成请求明确且不可歧义地要求女性主体。
- 主头像和身份头像都只生成完整头面部，不包含颈肩、衣物、手或上半身。
- 性别未知或非人类主体不会被推断为男性、女性或中性人类。
- 既有 VisualBible 身份细节、资产路径和 API 合同保持不变。
