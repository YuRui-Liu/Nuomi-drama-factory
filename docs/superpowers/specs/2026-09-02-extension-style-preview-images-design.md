# 扩展风格预览图生成设计

## 目标

为 `src/novelvideo/extension_styles/catalog.json` 中 18 个扩展风格生成缺失的预览图，使视觉风格页不再显示破图，并让用户可以在相同题材下直观比较不同风格。

## 生成策略

- 每个风格独立调用一次图像模型，不使用宫格生成与切分。
- 每次调用直接使用该风格的 `prompt_fragment.medium/rendering/lighting/color/camera/constraints`。
- 所有风格共享同一个故事中性基准场景：一名成年虚构旅行者站在有前景、中景和远景层次的城市街角；画面包含人物、建筑、植物、天空和多种材质，便于观察人物、环境、光影、色彩和材质差异。
- 不绑定现有项目角色，不复用任何用户图片，不生成受版权保护的具体角色。
- 禁止标题、标签、对白、标识、水印、边框、分屏和宫格。

## 输出契约

- 一项风格对应一张独立图片。
- 构图比例为 16:9。
- 最终资源统一转换为 WebP，尺寸为 640×360。
- 文件名严格取自目录中的 `preview_asset`，写入：
  `frontend/public/images/extension-styles/`。
- 不修改风格 ID、风格提示词、展示顺序或 API 数据结构。

## 质量检查

- 18 个 `preview_asset` 均存在且可以被 Pillow 解码。
- 每张图片尺寸均为 640×360，格式均为 WebP。
- 图片不得包含明显文字、水印、白边、宫格分隔线或错误纵横比。
- 前端现有 `preview_url` 无需改造即可访问对应静态资源。

## 失败处理

- 单张生成失败时只重试该风格，不覆盖其他已完成资源。
- 模型返回非 16:9 图片时采用中心裁切后缩放，不拉伸。
- 转换使用高质量重采样，原始临时文件不进入版本库。

## 验收标准

刷新视觉风格页后，18 个扩展风格均显示与各自提示词一致的缩略图；选择风格时不再出现破图占位。
