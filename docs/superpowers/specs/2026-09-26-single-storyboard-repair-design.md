# 单张分镜图修复

## 已确认的需求

用户确认：点击格位中的“重新生成分镜图”，只生成当前分镜，其他分镜不变。打开沿用现有 Dialog、Textarea、Button 样式的编辑弹窗，展示原出图提示词，允许直接编辑并另填修改意见，确认后生成新版本、保留旧版本。此次不调整页面布局、导航、颜色或卡片风格，不引入语言 QC 打回循环。

## 现状与方案选择

`group-beat-inspector.tsx` 对 shot id 目前回退到整组重生成；`narrative_group.py` 按组生成网格，再切分为 cell_assets。已有 image-prompts 接口返回当前拼装文本和覆盖文本，不能保证是历史图片的实际输入。

选择新增单张生成任务：只请求一张目标分镜，成功后更新其资产绑定。整组重生成会改变其他图片，不符合已确认范围；重新生成整组后只取一格仍浪费生成资源，也不采用。复用现有图片生成适配器、任务管理、参考资产解析和版本存储机制，不从前端直接调用供应商。

## 交互与提示词

1. 格位按钮改为“重新生成分镜图”，传入明确的 group、stage、shot 和当前资产版本。
2. 弹窗展示当前图片、只读的原始实际输入、可编辑的本次分镜提示词，以及独立的“修改意见”。生成提交前可以检查本次输入；取消不修改任何资产。
3. 初始网格生成的历史原文包含公共风格和其他格位时，完整原文保留可查看；本次可编辑内容只针对目标分镜，公共风格及人物参考继续沿用，移除多格排版指令。
4. 修改意见作为独立段落直接加入本次生成输入，不额外调用语言模型重写或 QC。例如可输入“保留窗外雨景，室内仅保留明确漏水处的滴水，去掉桌面和动物旁无来源的水花”。系统不自行假定剧情中不存在屋顶漏水。
5. 历史任务存在真实输入记录时读取该记录；无法恢复时明确显示“此版本未保存原始提示词”，以当前分镜描述作为可编辑起点，并标注其来源。不得把当前重建文本标为历史原文。
6. 生成时显示当前格位的进度、防止重复提交；失败保留旧图和编辑内容。沿用现有版本查看方式提供历史查看和恢复能力。

## 数据与执行

生成请求冻结目标 shot、stage、源资产标识/版本、编辑后提示词、修改意见、风格与参考资产及模型配置。服务端校验目标属于当前组，使用现有任务系统排队、记录费用；不在保存提示词或打开弹窗时调用模型。

每次生成保存实际发送给供应商的最终提示词、来源、原图版本、修改意见、参考资产标识、实际模型及生成结果，和图片版本绑定。首次整组生成也保存真实输入快照，便于后续查看。

只生成目标单图，使用对应分镜宽高比。成功后在锁及版本检查保护下替换目标 cell 的绑定，保留其他 cell 的路径和内容；旧版本不可变。失败或源版本已变化时不覆盖当前绑定，返回可理解的错误；已生成结果保留，不能静默触发又一次付费生成。

更新分镜来源及下游引用所依赖的标识/摘要，使后续视频生成使用新图。若下游依赖组合网格，用原有其他格位和新图本地重组，不额外调用生成模型；预览与实际引用须保持一致。已生成视频保留，不自动重生成，沿用现有依赖版本机制标记输入变化。

## 验收

- 对两个以上格位的组修复一张，供应商只收到一次单图请求，其余图片内容、路径及映射不变。
- 编辑提示词与修改意见出现在实际请求及新版本快照中；原始提示词与当前重建文本来源清楚。
- 旧图可查看和恢复；取消、供应商失败、重复提交及并发版本冲突不会丢失旧图或错误覆盖。
- 预览、分镜来源及后续视频引用一致；已有视频不被自动重生成。
- 组件测试覆盖按钮目标、预填、编辑、提交及错误保留；后端测试覆盖快照、单图请求、局部替换、版本恢复和并发冲突。验证使用模拟供应商，不触发付费生成。

## 范围边界

不修改剧本、选角、视频提示词，不改其他页面视觉风格，不引入自动审美评价、自动修复循环或独立的图像涂抹编辑器。
