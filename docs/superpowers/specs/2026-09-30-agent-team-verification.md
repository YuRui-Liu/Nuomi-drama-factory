# Agent 团队实现与验收记录

## 实现范围

创作工作室新增 Agent Team 入口，按流程岗位查看子任务。方法编辑支持项目模型路由、补充提示词、固定版本的技法与参考资料，以及导演偏好。草稿保存、启用、回退分别执行；字段覆盖与模板继承分别显示。模板发布不自动升级项目，资源发布不自动替换现有固定引用。

内置方法检查器从当前源码及引用文件读取内容、来源和摘要。编剧技法可复制为个人资源；固定输出协议只读。补充提示词在原有协议内追加创作指导，编剧技法引用用于替换该阶段的默认技法，不取消结果校验。

## 真实接入清单

| 岗位 / 子任务 | 正式入口 | 隔离试运行 |
| --- | --- | --- |
| 编剧：简报、大纲、人物、场景、道具、分集梗概、分集剧本 | `script_creation/generation.py` | 支持 |
| 剧本解析：剧本语义解析 | `screenplay_semantics/extractor.py` | 支持 |
| 分镜导演：分镜规划 | `director_plan/planner.py` 主规划与修复调用 | 支持 |
| 视频导演：整集视频规划 | `media_capabilities/video/h3_episode_pack.py`；叙事组与片段视频任务消费该方法 | 暂不支持 |
| 一致性审查、资产提取、分镜审查、资产设计与审查、片段修复方法、自由创作导演 | 目录中明确显示未接入，不能启用自定义配置 | 暂不支持 |

导演自定义可显式导入已保存方法到共同草稿；不会因打开页面而迁移或启用。原有单镜头建议仍保留。正式任务提交时冻结方法、模型、资源内容；编剧逻辑运行重试保留初次提交的快照，包含任务状态过期后的重试。

## 浏览器实测

使用临时独立数据目录和假模型服务，未调用付费模型。测试项目为 `agent_team_acceptance`，与用户项目隔离。

- 修改创作简报 Prompt 后保存：草稿 v1，仍显示尚未启用。
- 选定保存的简报版本后双侧试运行：两侧输入摘要一致。
- 主动模拟草稿侧首次失败：基线侧完成，草稿侧失败；仅重试草稿侧后两侧完成，基线尝试数仍为 1，草稿尝试数为 2。
- 两侧费用均未回传，界面显示“未提供”。
- 从项目复制模板，再应用该固定版本：项目 Prompt 覆盖保持原内容。
- 启用两次后回退到第一版：新增启用版本 v3，草稿保留。
- 后续修改和启用没有改变历史试运行记录中的原 Prompt。
- 试运行后，正式文档仍是原文档及同一修订 ID；文档修订总数为 1，正式生成候选数为 0。

测试服务与测试脚本仅用于本地验收，不作为产品模型或默认配置。
