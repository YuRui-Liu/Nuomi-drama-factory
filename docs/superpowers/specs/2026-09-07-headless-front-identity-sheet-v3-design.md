# Identity Sheet v3：无头正面身体板设计

## 背景

Identity Sheet v2 使用「脸部特写 + 完整无五官正面全身 + 背面全身」三联图。正面板保留完整头部，再把面部处理为光滑平面。该表达容易产生塑料假人感，并让模型把「去除可识别五官」理解成一张异常的人脸。

本设计参考用户提供的角色造型图，将正面服装展示与脸部身份展示分开：

- 正面身体板不生成头部；
- 背面身体板保留后脑与发型；
- 独立脸部特写提供唯一可见五官。

本设计取代以下既有文档中关于「正面板保留完整无五官头部」的决定：

- 2026-09-07-complete-faceless-front-body-design.md
- 2026-09-07-identity-sheet-reference-only-generation-design.md

上述文档的其他身份隔离、参考图使用和质量控制原则继续有效。

## 目标

1. 消除正面身体板中的光滑无五官脸、假人头和第二脸源。
2. 保留正面服装、体型、配饰、手部、腿部与鞋履信息。
3. 保留背面发型、后脑、头颈连接、背部轮廓与服装结构。
4. 让右侧脸部特写成为整张图唯一可见五官和身份权威。
5. 让血迹、污渍、伤妆、服装破损等状态完全来自角色当前造型，不写入固定模板。
6. 保持历史 v2 资产可读，不重写已生成图片。

## 非目标

- 不修改角色的身份事实、VisualBible 或造型状态模型。
- 不固定添加血迹、伤口、战损或其他剧情状态。
- 不通过遮罩、涂抹、裁切或图像修补删除模型生成的头部。
- 不迁移或重新生成历史 Identity Sheet v2 资产。
- 不改变项目既有的 2D、2.5D、写实 3D、风格化 3D 渲染选择。

## 视觉契约

### 版本与画布

- 新版本：identity_sheet_v3
- 画布比例：3:2
- 标准画布：1536 × 1024
- 面板顺序：front_headless、back_fullbody、portrait_3q

面板使用归一化宽度计算：

| 面板 | 横向范围 | 标准画布像素范围 | 作用 |
| --- | --- | --- | --- |
| 无头正面全身 | 0%–40% | 0 ≤ x < 614 | 正面体型、服装、配饰、手部和鞋履 |
| 背面全身 | 40%–70% | 614 ≤ x < 1075 | 后脑、发型背面、头颈连接、背部轮廓和服装背面 |
| 脸部特写 | 70%–100% | 1075 ≤ x < 1536 | 唯一可见五官与身份权威 |

实现以 round(width × 0.4) 和 round(width × 0.7) 计算边界，避免把契约绑定到单一分辨率。

### 左侧：无头正面全身

- 人物自然正面站立。
- 从服装领口、肩部到鞋底完整可见。
- 头部、后脑、头发、耳朵、脸部轮廓和五官全部缺席。
- 领口与肩颈区域保持干净、完整，不出现断颈、伤口、血肉、孔洞、黑色空洞或恐怖元素。
- 不使用面具、头盔、布料、道具、马赛克或光滑假人头替代缺失头部。
- 双手、衣袖、武器挂载、服装下摆、裤腿和鞋履不得被面板边界裁切。

### 中间：背面全身

- 人物自然背对镜头，从头顶到鞋底完整可见。
- 保留后脑、发型背面、耳后轮廓和头颈连接。
- 不允许回头、侧脸、镜像脸、反射脸或任何可见五官。
- 发型、体型、服装、配饰、鞋履与其他面板一致。

### 右侧：真实脸部特写

- 使用清晰的三分之四脸部近景。
- 眼睛、鼻子、嘴、下颌线和可识别脸部轮廓完整可见。
- 手、头发、衣物、武器、道具不得遮挡五官。
- 该面板是整张图唯一可见五官和身份权威。
- 肩颈可以有限出现，但不能挤压脸部判断面积。

### 状态一致性

角色当前造型状态是血迹、污渍、妆容、伤痕、服装破损和配饰变化的唯一来源。

- 当前状态没有受伤信息时，不生成血迹、伤口或战损。
- 当前状态包含受伤或污损时，各面板在对应可见部位保持相同程度和材质表现。
- 参考图中的血迹与伤妆只用于说明版式，不进入固定 Prompt。

## 生成流程

数据流为：

角色当前造型状态 + 已确认肖像 + 服装参考 → v3 Prompt → 供应商生成完整三联图 → 画布校验 → 视觉 QC → 保存候选版本

生成阶段遵循以下约束：

1. Prompt 明确要求 40/30/30 的面板顺序和无头正面身体板。
2. 已确认肖像只提供身份参考，不把历史图片像素直接拼贴到新图。
3. 供应商返回完整 3:2 画布；保存逻辑只做格式规范化，不改写面板内容。
4. 系统不通过后处理删除头部。供应商输出不符合契约时，由 QC 拒绝。

## 质量控制

QC 使用与 v3 相同的 40% 和 70% 边界。

### 稳定问题码

保留现有问题码，避免历史 API 与前端数据迁移：

- front_face_detected：v3 中扩展为「正面身体板出现头部、头发、耳朵、脸部轮廓或五官」。
- back_face_visible：背面板出现回头脸、侧脸、镜像脸、反射脸或五官。
- portrait_too_small：右侧脸部不足以判断身份。
- portrait_face_occluded：脸部被手、头发、衣物、武器或道具遮挡。
- panel_boundary_intrusion：人物或身体部位跨越 40% / 70% 分界。
- body_cropped：正面或背面身体板缺少契约要求的身体部分。
- state_inconsistent：三个面板的造型状态不一致。
- 其余材质、风格和中性展示问题码保持现有语义。

### 失败处理

- 命中 front_face_detected 时，候选图不得采用或确认。
- 系统在现有生成预算内重试，不修改角色状态或放宽版式约束。
- 重试耗尽后返回明确的 QC 失败信息。
- 已采用的历史版本保持不变。
- QC 不可用时沿用现有 fail-closed / 人工确认策略，不把未知结果当作通过。

## 版本与兼容性

- 新生成和主动重新生成使用 identity_sheet_v3。
- v3 元数据写入：
  - layout_version: identity_sheet_v3
  - panel_layout: [front_headless, back_fullbody, portrait_3q]
- v2 元数据及图片保持原样。
- 前端按 layout_version 显示文案：
  - v2：无面部正面全身 / Faceless front full body
  - v3：无头正面全身 / Headless front full body
- 机器键 front_headless 保持不变；版本号决定其展示语义。
- 读取缺少版本信息的历史资产时沿用当前兼容路径，不推断为 v3。

## 测试

### Prompt

- 包含 HEADLESS FRONT FULL BODY 和 40/30/30 顺序。
- 明确禁止 smooth faceless head、mannequin head、mask、helmet、void、wound 和 exposed anatomy。
- 不再要求正面板保留 complete head、hair outline、ears 或 smooth neutral facial plane。
- 角色状态无伤时不引入血迹或战损。
- 角色状态有伤时保留输入事实，不扩大程度。

### 几何与元数据

- IDENTITY_SHEET_LAYOUT_VERSION 等于 identity_sheet_v3。
- 面板顺序为 front_headless、back_fullbody、portrait_3q。
- 1536 × 1024 画布的边界为 614 和 1075。
- 非标准 3:2 分辨率使用 40% / 70% 归一化边界。
- API、任务结果和 Freezone metadata 使用相同版本与顺序。

### QC

- 正面板出现完整头部、光滑无五官头、头发或耳朵均触发 front_face_detected。
- 正面板领口以上为空且无异常伤口时不触发该问题。
- 背面后脑与发型合法；侧脸、回头脸和反射脸触发 back_face_visible。
- 右侧脸部清晰、无遮挡且面积足够。
- QC 使用 40% / 70% 分界检查跨面板和裁切。

### 前端兼容

- v2 与 v3 使用各自准确的中英文标签。
- v3 按正面、背面、脸部顺序展示。
- 历史 v2 不被标记成 v3，也不触发迁移。

## 验收标准

1. 新生成造型图与参考图结构一致：左侧无头正面、中间完整背面、右侧真实脸部特写。
2. 正面板没有光滑无五官脸，也没有任何替代头部。
3. 背面保留后脑与发型，不出现可见五官。
4. 右侧是唯一真实脸源，五官清楚且无遮挡。
5. 伤妆和污损只由当前角色状态决定。
6. 不合格候选由 QC 拒绝和重试，不通过后处理掩盖。
7. 历史 v2 资产继续可读，标签不被错误改写。
