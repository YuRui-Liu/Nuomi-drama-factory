# Agent 面板：对话优先与显式委托

日期：2026-10-17。范围：现有画布助手面板的信息架构、视觉层级和发送语义。

## 已确认的决策

用户选择对话优先、布局 A：委托入口位于输入框上方，点击向上展开配置。普通消息用于讨论，只有明确点击“发起委托”才能创建执行任务。画布“委托选中节点”直接打开助手并展开配置，同时保留未发送文字。

## 默认面板

顶部保留紧凑的会话切换、新建、助手状态和关闭入口。消息区占主要空间，输入框固定在底部。未选择节点时只显示轻量“创建节点委托”入口，不展示空成员表单、岗位列表、授权项或调用次数。

项目主创设置、岗位浏览、加入机组放入独立的“项目机组”管理面板，通过助手菜单与委托配置内的管理链接到达。它们不常驻聊天消息上方。已有项目设置入口保留，不复制编辑器和业务状态。

## 普通讨论与执行边界

普通“发送”与 Enter 只发送讨论消息；Shift+Enter 换行。讨论不得创建委托、运行节点、修改节点、自动采用候选结果或隐式授权。选择节点、选择成员、展开配置均不得自动发送。讨论可以读取用户可访问的项目上下文，但不得绕过项目和会话权限。

当前 `superchat-panel.tsx` 在 managedWorkspace 分支把 submit 直接交给 `agentRuntime.send`，而后者要求非空节点范围。因此普通讨论不是纯布局调整：实现必须建立或验证独立的只读讨论通道，不能直接解除现有委托的节点门禁，也不能无审查地启用旧聊天工具执行能力。没有可用讨论通道或模型时，明确显示不可用原因与配置入口，保留输入内容，不伪装成功。

委托配置使用同一份未发送文字作为目标，展示“本次委托目标”并允许编辑；打开、关闭和切换配置不得清空文字。底部聊天发送仍只讨论；配置内独立的“发起委托”按钮才提交执行任务。提交成功且当前草稿未被修改时才清空已提交文字；失败保留目标、范围和授权。不得用 Enter 隐式触发委托。

## 委托展开与范围

从画布点击“委托选中节点”：捕获明确选中的节点 ID，打开助手，展开底部配置并展示目标、负责人和授权。没有活动会话时保留这次意图，先提示选择或新建会话，绑定成功后再展示；不得自动替用户创建会话或执行。

摘要显示节点数量、负责人和权限摘要，避免常驻长解释。配置为单层、可滚动区域，按“目标范围 → 负责人 → 节点操作授权 → 高级设置”排序；关闭按钮和底部主要动作可达。展开时覆盖部分消息区域，不让整个聊天页面无限增高，不使用卡片嵌套卡片。

冻结的节点范围不会随画布选择变化自动替换。变化时显示“更新为当前选择”；更新保留目标文字并清除旧操作授权。节点删除或失去访问权限时标出失效节点并阻止委托，允许移除或重新选择，不能按同名节点替换。

负责人允许项目主创统筹或直接委托已加入项目的成员；候选专家只在主创统筹时出现。更换执行成员不能扩展既有权限，需重新核对适用的授权项。

## 授权与高级设置

逐节点的修改授权、具体运行操作授权默认关闭，明确展示在委托配置内，不藏进高级设置。不支持的操作显示原因，不提供可勾选的假能力。运行额度与相应操作放在一起。模型调用上限等低频参数进入高级设置，保留现有约束。

只准备方案不等于允许修改或运行。已选授权在折叠摘要中有可读概览；发起委托前可完整检查。机组成员管理与本次节点操作授权保持独立。

## 运行、错误与恢复

成功发起后收起编辑配置，显示紧凑状态条，保留查看详情和停止入口；结果进入消息区或可展开结果记录。不得把模拟进度当真实后端进度。停止使用现有后端语义，不承诺撤销已经发生的操作。

错误显示具体原因及适用的重试／恢复操作。未知提交结果先恢复原请求，不重新创建重复任务。历史任务、原运行恢复及 canvas 范围历史契约保持兼容。关闭面板、切换会话不终止现有任务；草稿按用户、项目、画布、会话隔离。

## 视觉与可访问性

沿用深色界面和黄绿主强调色。减少边框，使用间距、文字层级和细分隔线组织内容；避免岗位数量、说明文案抢占视觉焦点。普通聊天发送与“发起委托”的名称和位置不同，不只靠颜色区分。

窄面板保持内容可读、按钮可达、无横向溢出。展开、关闭、错误和返回均有合理焦点；图标按钮有名称；状态不可只靠色点表达。验证实际 1024、1280、1600 视口及约 480px 助手面板，不假定浏览器窗口宽度等于面板宽度。

## 实现边界与验收

拆分展示组件：助手顶栏、消息区、底部委托摘要、委托配置、项目机组管理、运行状态。复用已有运行与持久化逻辑，不为视觉改版另造一套任务状态。

必须验证：普通消息不会调用执行入口；无节点可讨论但不能委托；画布委托可首次打开并捕获范围；打开配置保留草稿；逐节点授权默认关闭；选择变化和失效节点门禁；重复提交与未知结果恢复；A→B→A 草稿隔离；运行停止及历史恢复；键盘和窄屏可用。

交互原型位于 `.superpowers/agent-panel-chat-first.html`，仅演示界面与模拟消息，无真实 API。原型中的人物、节点和运行状态不代表真实项目数据。用户已确认的方向以本规格为准；完整规格审阅后再编写实现计划。
