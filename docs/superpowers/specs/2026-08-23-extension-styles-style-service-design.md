# 漫剧扩展风格注册到视觉风格管理页设计

## 目标

将已经发布的 18 项 `drama_ext.*` 漫剧扩展风格注册为 StyleService 的正式只读预设，使其与现有 6 项默认风格一起出现在项目“视觉风格”管理页，并可设为项目默认风格。

本功能只新增风格，不修改现有 6 项默认风格的文件、ID、名称、提示词、预览或运行行为。

## 产品语义

- 视觉风格总数从 6 项增加到 24 项。
- 左侧列表分为“默认风格（6）”与“漫剧新增风格（18）”。
- 两类风格均可查看详情并设为项目默认。
- 漫剧新增风格是正式预设，保持只读，不允许重命名、编辑、覆盖或删除。
- 项目只能有一个默认视觉风格。选择 `drama_ext.*` 时，它替代当前基础默认风格，而不是与基础风格叠加。
- 原有自定义风格创建、编辑、删除流程保持不变。

## 单一数据源与 StyleService 适配

18 项风格继续以 `src/novelvideo/extension_styles/catalog.json` 为唯一人工维护数据源。不得复制一份 StyleService JSON 目录。

StyleService 增加一个确定性适配层，将每个 `ExtensionStyle` 暴露为现有风格 API 可消费的只读预设：

- `id`：保留 `drama_ext.*`。
- `name` 与 `label`：使用目录中的中文名称。
- `type`：`preset`。
- `is_preset`：`true`。
- `style_instructions`：按 `medium → rendering → lighting → color → camera → constraints` 固定顺序编译六段提示词。
- `avoid_instructions`：留空；`constraints` 是正向保真约束，不得错误映射为负面提示词。
- `style_tag`：使用稳定的扩展风格 ID 或分类标识，不能改变提示词语义。
- 详情响应附带扩展元数据，供前端展示 `summary`、`category`、`use_cases`、`preview_asset` 与 `version`。

适配结果必须沿用 ExtensionStyle schema 的冻结、ID 唯一性、来源审计和故事偏置校验。

## API 与权限

现有 `/api/v1/styles` 列表与 `/api/v1/styles/{id}` 详情接口同时返回默认预设、自定义风格和漫剧新增预设，不新增运行时网络依赖。

- 对 `drama_ext.*` 的更新、重命名、覆盖创建或删除请求必须拒绝，并返回稳定的只读预设错误。
- 项目更新接口允许将 `visual_style` 保存为已注册的 `drama_ext.*`。
- 未知或未注册的 `drama_ext.*` 仍按非法视觉风格处理。
- API 返回顺序稳定：原 6 项默认风格保持原顺序，随后是目录中确定顺序的 18 项，再显示自定义风格。

## 视觉风格页

左侧列表增加分组标题与数量：

1. 默认风格（6）
2. 漫剧新增风格（18）
3. 自定义风格（如存在）

漫剧详情面板显示：

- 本地预览图或缺失占位；
- 中文名称、分类和只读标记；
- 中文摘要与适用场景；
- 编译后的风格指令；
- 保真约束；
- “设为项目默认”操作。

详情面板不得显示重命名、保存、JSON 编辑、上传预览或删除操作。预览缺失不得联网、不得阻断选择或设为默认。

## 生成链路与画布去重

项目 `visual_style=drama_ext.*` 后，所有通过 StyleService 解析项目默认风格的图片生成链路直接获得适配后的完整风格指令。

ImageGenNode 继续支持节点级漫剧扩展选择，但执行以下规则：

- 节点没有显式扩展选择：使用项目默认视觉风格生成。
- 项目默认与节点扩展 ID 相同：只编译一次，禁止重复追加。
- 项目默认是 `drama_ext.*`，节点显式选择另一个 `drama_ext.*`：节点选择覆盖项目默认漫剧风格，不叠加两个漫剧风格。
- 项目默认是原 6 项或自定义风格，节点显式选择 `drama_ext.*`：保留现有节点级追加行为。

覆盖与去重只影响最终请求提示词，不回写用户原始提示词或风格目录。

## 错误处理

- 目录加载失败属于启动或构建边界错误，不静默丢弃 18 项。
- 单项适配失败必须指出风格 ID 和字段，不允许返回部分目录。
- 预览资源加载失败使用本地占位和可访问文本。
- 只读写操作返回明确错误，前端不依靠隐藏按钮作为唯一保护。
- 项目默认引用已移除或未知风格时，沿用现有安全回退机制并给出可诊断警告。

## 测试与验收

后端：

- 冻结原 6 项预设的 canonical JSON 语义哈希，确保零修改。
- 列表恰好包含 6 项默认预设与 18 项 `drama_ext.*`，ID 唯一、顺序稳定。
- 18 项详情适配与六段编译顺序正确，扩展元数据完整。
- 项目默认可保存并解析 `drama_ext.*`。
- 18 项的创建覆盖、更新和删除均被服务端拒绝。
- 未知扩展 ID 被拒绝，不发生静默回退或部分加载。

前端：

- 左侧三类分组、计数、选择态和项目默认标识正确。
- 漫剧详情显示摘要、分类、适用场景、约束及预览 fallback。
- 漫剧详情无编辑、删除、上传和 JSON 操作。
- 可将漫剧风格设为项目默认。
- ImageGenNode 覆盖与去重的四种组合均通过行为测试，最终请求使用预期提示词且不修改输入对象。

验收标准：现有视觉风格页可查看并选择全部 18 项新增风格，原 6 项语义不变，选择后的项目出图链路真实使用对应风格，且不会重复叠加同一漫剧提示词。

## 非目标

- 不修改原 6 个默认风格。
- 不把 18 项变成可编辑或可删除的自定义风格。
- 不增加运行时 GitHub、远程图片或上游目录请求。
- 不在本任务中生成缺失的 18 张预览图。
- 不支持同时叠加多个漫剧扩展风格。
