# 导演交接、专业分镜与成片节点 PRD

日期：2026-10-17

状态：用户已批准；已有导演业务基础接入，但专业交互、Agent 操作及导出合同尚未完整实现。当前覆盖见 [2026-10-17 代码核对](../../design/integrated-production-2026-10-17/PRD-COVERAGE-AUDIT.md)，E01 媒体真机验收未完成。

## 1. 目标与依据

承接 [专业剧本节点](2026-10-17-professional-screenplay-node-design.md) 的“交给导演”，在统一画布内形成可编辑的场景调度、组分镜、专业方案和媒体结果，并通过每集统一音画时间线导出可播放成片。

本规格细化 [专业岗位契约](2026-10-16-manga-production-agent-contracts.md)，遵循 [统一画布 PRD](2026-10-13-agent-canvas-prd.md)。研究依据及证据边界见 [导演研究稿](../../research/2026-10-17-director-production-nodes-research.md)：LibTV、小云雀、DramaClaw、OpenMontage、H3 cases、Hell Grind，以及 Shot Designer、Storyboarder、Storyboard Pro、set.a.light、Cascadeur 等专业工具。研究用于提炼方法，不表示引入这些产品的执行能力。

用户最新明确选择优先于旧规格中默认自动推进的概括：采用方案、开始制作、局部重生成和正式导出是分开的动作。已启动任务在其授权范围内正常推进，不对每个岗位、组或阶段重复询问。

## 2. 已确认的八项决策

| 决策 | 确认结果 |
| --- | --- |
| 空间共同依据 | 每场共享一份场景调度，各叙事组引用具体版本 |
| 调度交互 | 平面调度图与镜头预览联动，复杂动作按需展开时间轴，现有 3D 能力作为辅助 |
| 分镜组织 | 每个叙事组一张分镜节点，内部有序镜头卡，可切换图板、镜头表和时间预演 |
| 专业协作 | 导演按内容需要调度岗位，融合为可编辑方案；用户可直接局部委托 |
| 动态预演 | 默认使用已有图片、调度示意与时间信息；缺图占位，不自动购买媒体 |
| 制作启动 | 采用导演方案固定版本，另行点击“开始制作”提交明确范围 |
| 局部返修 | 先展示影响，采用修改与必要重生成分开，保留未受影响产物 |
| 音画与导出 | 每集一个“剪辑与声音”主节点；默认时间线预览，显式“导出成片”才生成正式文件并验收 |

## 3. 内容身份与节点关系

| 内容／呈现 | 负责承载 | 身份与关联 |
| --- | --- | --- |
| 整集导演方案入口 | 导演画面版、资产拆解、组方案、覆盖情况与采用版本 | 引用已采用剧本修订，不复制一份独立主剧本 |
| 场景调度 | 空间、人物／道具、光源基线、轴线和路径 | 引用剧本场景稳定 ID；不同场次可以引用同一场景资产，但剧情时刻与调度不同 |
| 组分镜节点 | 组内镜头、专业细节、预演及媒体状态 | 绑定生产 group_id、导演修订、来源场景／文本范围及 shot_ids |
| 关联镜头视图 | 单镜头的专注编辑与局部委托 | 引用同一镜头内容与修订，不产生另一份正式镜头副本 |
| 图像／视频／声音产物 | 实际生成结果、候选和采用记录 | 沿用已有媒体节点、版本与任务身份 |
| 剪辑与声音主节点 | 整集时间线、轨道、字幕、预览和导出 | 引用确定媒体版本与裁切范围；导出绑定时间线修订 |

画布视觉分组不是生产叙事组。场序来自剧本，镜头顺序来自组方案，成片顺序来自时间线；移动节点不改变这些顺序。一场可以对应多组；跨场组明确每个镜头归属和转场，不能强制 scene_id 等于 group_id。

共享内容的修改先形成新版本，已经采用的组继续引用旧版本并显示差异，用户明确采用后才变更依赖。不能为了“联动”静默追改所有正在运行任务。

## 4. 从剧本交接到导演准备

“交给导演”读取采用剧本、确认设定和现有资产，生成导演画面版、资产拆解与叙事组方案，并在画布上建立关联视图。三类结果分别记录状态，不能用其中一项成功代表全体完成。

导演画面版保持剧情、关系和对白含义，补足空间、出入场、动作、表情与声音承接。资产拆解引用已有实体和变体，缺失项明确标记；文字需求不是可用媒体。组方案标出剧情目的、来源范围、镜头时序和必要引用。

必要依赖按顺序处理，独立场景／组可以并行。准备过程可生成文字／结构候选和本地示意，但不自动提交图片、视频、配音或音乐生成。若需要新增媒体预演，作为另行显式操作展示。

## 5. 场景调度交互与专业语义

### 5.1 平面图与镜头预览

默认平面图可选择、拖动人物、道具、摄影机和光源；编辑朝向、视线目标、进出路径及光源方向。选中摄影机或镜头后，预览显示其构图与关键对象位置。人物与资产使用稳定关联，可用简化符号或已有素材表达。

调度图、镜头表和预览操作同一份场景／镜头数据。人工编辑与 Agent 修改均通过受支持的版本操作。构图示意、参考图与真实生成画面明确标记；示意不冒充实际生成效果。

现有 3D 工具按需辅助，不要求用户先建完整三维场景。只有接入支持相应参数的渲染器时才显示精确物理预览；常规模型提示词中的焦段、曝光或步点属于创作意图，不能伪称已严格实现。

### 5.2 专业内容

| 维度 | 可编辑内容 | 约束 |
| --- | --- | --- |
| 站位 | 人物／道具初始位置、朝向、视线轴、路径、出入点、遮挡 | 共享空间基线；有意越轴、遮挡或换位需有可解释事件 |
| 摄影 | 景别、视点、构图、运动起止、焦点与关注对象 | 能呈现关键行动和反应，遵守已采用场景依据 |
| 灯光 | 来源、方向、软硬、冷暖、明暗关系与事件性变化 | 与时间天气／美术相容；镜头差异应能追溯到光源或有意设计 |
| 动作 | 起始状态、预备、关键动作、接触／受力反馈、落点 | 与对白和时长一致，交互对象明确；不是只有“激烈打斗”等标签 |
| 表情 | 情绪动机、视线目标、反应时刻、强度和变化 | 绑定剧情事件与人物目标，不默认夸张或精确到模型不支持的面部控制 |

复杂动作可展开时间轴，用关键事件和起止状态连接人物、摄影机及表情；不要求逐帧填写。不同场景的坐标系明确，不能把画布像素位置当作剧情空间坐标。

## 6. 组分镜、时间与轻量预演

每组分镜节点收起时展示组名、叙事目的、镜头数、时长、采用版本和媒体进度。展开后支持三种视图，三者引用同一组内容：

- 图板：镜头画面、动作摘要、对白／声音及来源；缺图显示占位。
- 镜头表：顺序、景别、视点、运动、动作与表演、声音、时长和必要引用。
- 时间预演：按时间播放已有图像或调度示意，显示摄影运动、关键动作／对白区间与切点。

用户可增删、重排、选择镜头、局部委托或展开关联视图。镜头修改不自动拆成独立付费任务。删除／拆合需显示来源覆盖、组时长和下游引用影响，保留历史关系。

轻量预演不购买模型生成，不暗中合成新的配音或音乐；使用已有音轨，没有声音时以文本／时间标记说明。估算对白时长标为估算，不能冒充实测音频。预演可检查节奏与明显时长冲突，不代表最终运动、口型、物理效果或供应商输出已验证。

## 7. 专业机组的调度、调用和冲突

导演根据内容需要选择专业岗位，不要求所有镜头经过所有 Agent。有依赖的任务依次执行，无冲突任务可并行；合并模型调用也须保留实际参与角色、输入和贡献，未运行岗位不伪造回执。

| Agent | 受支持操作的目标 | 交付 |
| --- | --- | --- |
| 导演 | 读采用稿、编辑方案、编排必要岗位、融合候选 | 版本化导演准备包与冲突处理记录 |
| 分镜师 | 编辑组内镜头、顺序、切点与叙事用途 | 可追溯组分镜 |
| 站位师 | 编辑共享调度及镜头空间变化 | 位置、轴线、视线、路径与遮挡 |
| 摄影师 | 编辑构图／运动与镜头视点 | 摄影方案及预览依据 |
| 灯光师 | 编辑光源基线及局部事件 | 灯光方案与跨镜头承接 |
| 动作师／表情师 | 编辑事件时间、动作交互与反应 | 可执行的动作与表演说明 |
| 美术／资产师 | 选择真实资产、提出缺项；授权后调用资产生成 | 版本化引用与实际素材 |
| 连续性师 | 比较前后场／组与结果 | 定位到对象／镜头的问题，不默认额外付费深审 |
| 图像／MiniMax 等执行师 | 适配冻结方案、调用正式组入口、查询／恢复 | 实际媒体、执行合同与错误；不静默改剧情／模型／组范围 |
| 声音师／剪辑师 | 操作授权轨道、片段及混音／字幕设置 | 时间线候选、预览与补充任务 |
| 交付检查 | 检查正式输出与交付要求 | 可播放性、内容和音画字幕问题记录 |

角色配置不授予无限执行权限。每次操作绑定具体场景／组／节点、动作、修改范围和输入版本。用户可直接选中内容委托岗位，回到同一内容位置比较结果。

导演协调空间、摄影、灯光和表演的冲突；采用剧情和用户硬约束优先。改变故事事实的建议回到主稿候选，不由执行师在提示词中暗改。无法在授权内消解的冲突明确指出，其他独立工作可继续。

## 8. 采用导演方案与开始制作

“采用导演方案”固定剧本来源、场景调度、组分镜、专业设置及引用选择的版本集合。该动作不购买媒体。文字方案完整与实际媒体齐备分别展示；允许保留明确列出的缺失资产需求，开始相应生成前必须满足真实引用条件。

“开始制作”展示目标集／选定组、需要补齐的资产、生成阶段、保存的模型／画幅／并发、可复用产物、费用估算或计费不确定性及重试范围。读取实时保存配置，不以文档示例代替。

授权后在指定范围内完成必要资产准备、整组分镜图和组视频，不逐组重复确认。道具仍遵守现有外部导入约束；缺少必需道具时说明需选择／导入，不擅自扩库。可独立执行的组按保存并发推进，失败组不阻塞其他独立组。

生产执行复用 [nuomi-production](../../../skills/nuomi-production/SKILL.md) 支持入口与真实执行合同。正式单位为叙事组；供应商物理片段由服务端处理，Agent 不编写单镜头循环或直连替代流程。

本次“开始制作”停在约定媒体阶段与结果回填，不自动执行最终整集导出。现有 batch 默认 `through=compose`，但已支持 `render`／`video`／`compose`；本产品制作链路应显式使用相应媒体终点，例如 `--through video`，不修改 CLI 其他调用者的默认行为。不能靠界面文案掩盖自动导出。

## 9. 局部修订、影响与恢复

修改表情、动作、机位或灯光时，先显示直接受影响内容及下游分镜图、组视频、时间线片段和导出引用。用户可保存候选、比较和采用；采用只更新内容依据，不触发重生成。

另行“重生成受影响内容”展示服务实际支持的最小范围。若只能整组重做，明确说明，不能承诺按单格费用完成整组修复。未受影响产物保留；旧媒体仍作为历史可访问，但不能标为最新方案结果。

时间线固定媒体版本。新媒体完成后提供替换候选，显示时长、裁切、声音与字幕受影响范围，不悄然替换已编辑片段。停止保留已完成结果；状态未知先查询原任务，不能重复购买。输入改变则旧运行仍绑定原快照，新修订需新的执行记录。

## 10. 每集统一“剪辑与声音”主节点

复用既有视频合成和声音能力，在一个主节点内组织组视频、对白、原生声音、环境声、音效、配乐和字幕。现有媒体节点继续可独立使用，时间线作为整集编排视图，不重建媒体生成系统。

片段保存来源媒体版本、入点／出点、时间线位置和必要变速／音量信息。声音师、剪辑师只操作授权轨道与范围。可复用原生音频优先保留，不无条件重配、生成音色样本或重复购买背景音乐。

用户能在同一时间线查看音画同步、选择片段局部委托、调整顺序和裁切。字幕从已有对白／字幕资料关联和校对，不默认增加 ASR；缺少实际对白定位时标记需处理，不伪造精准时间码。

缺镜或补充反应需求回指来源组／镜头，形成明确补充任务，显示原因与范围，不自动购买生成。缺关键组、缺素材或未解决的关键冲突可保留为草剪预览，不作为完整正式交付。

## 11. 显式导出与必要验收

时间线默认可预览。必要预览渲染明确标为预览缓存，不标为正式导出，不触发供应商媒体生成。

用户点击“导出成片”，冻结当前时间线修订、采用媒体版本、音轨／字幕与目标格式。沿用项目已保存导出规格，缺少必要设置时在同一操作中说明，不暗改画幅、帧率或分辨率。

导出前检查必需素材可访问、关键内容未缺失及配置有效。导出完成后核验文件存在、实际可播放、关键剧情无明显遗漏，以及目标音画／字幕表现。验证结果绑定该导出文件与时间线修订，不能用旧文件验收新版本。

正式文件、预览缓存、部分草剪和失败结果分别标记。显示进度、下载／打开入口与失败原因；文件可取回且验收通过后才报告成片交付完成。默认不增加 ASR、反复付费 QC 或自动补镜；发现问题先定位并保留结果。

## 13. 验收用例与实现拆分

| 用例 | 必须观察到的结果 |
| --- | --- |
| 同场多组 | 共同调度可追溯到同一版本；采用新调度前旧组快照不变 |
| 图表联动 | 拖动、镜头表编辑及 Agent 修改指向同一内容，冲突不会静默覆盖 |
| 分镜三视图 | 镜头顺序、内容与时间一致；单镜头展开不复制正式内容 |
| 岗位调度 | 实际需要的岗位有输入／输出／修改依据；未运行岗位无虚构记录 |
| 轻量预演 | 可播放已有图或占位和时间信息，供应商新增调用为零 |
| 采用与制作 | 采用时供应商调用为零；开始制作仅提交授权组，成功素材复用 |
| 局部返修 | 影响范围可查；采用不重生；实际重生范围与声明一致 |
| 音画编辑 | 片段与声音版本固定，补镜回指来源；新候选不自动替换已剪辑媒体 |
| 显式导出 | 制作／剪辑完成不自动产生正式导出；点击后记录冻结输入、真实文件与播放验收 |
| 中断／冲突 | 旧任务可查询，未知提交不重复生成，人工编辑保留 |
| 真机 E01 | 从立意到采用剧本、导演准备、媒体制作、音画剪辑和正式导出均有真实记录 |
