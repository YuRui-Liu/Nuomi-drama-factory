# 项目制作成本

成本账本记录项目调用的供应商成本，与应用内积分报价分开。金额统一展示为人民币；订阅费用单列，不分摊至项目。

## 读懂金额

- **已确认**：具有单次扣费证据。只有明确的零扣费证据才表示零费用。
- **估算**：有明确计量信息及匹配的价格版本。请求时长、张数或字符数属于请求用量，不表示供应商已结算。
- **待核算**：缺少价格、用量或汇率等依据，不按零费用处理。
- **订阅覆盖**：账户在调用发生时有明确订阅配置。额外的实际扣费仍计入项目。
- **待确认提交**：已保存调用意图，但尚无确定提交结果，暂不计金额，并提示数据不完整。

总额、分类和曲线从同一账本快照计算：每笔人民币金额先按四舍五入换算为分，再求和。每日统计使用北京时间，迟到扣费与退款修订更新原调用发生日。累计曲线显示已知小计；缺失历史不会补成已知零支出。

## 计价与补算

价格支持按张、秒、次、字符、输入或输出 Token、渠道积分计量，可设置单价、计量基数、计费步长、最低计费量、币种和人民币换算率。没有内置第三方价格，管理员应根据自己的账户计费约定填写。

规则按渠道、账户、模型或工作流、媒体、规格和生效时间匹配。更具体的规则优先；同优先级冲突会被拒绝。新价格版本不会自动改写历史已计价调用。

对未计价记录，先生成补算预览，检查影响记录和金额，再应用。若预览后用量、费用修订或匹配规则发生变化，旧预览失效，需要重新预览。应用成功后保留历史修订及当次价格快照，后续轮询继续沿用补算规则。

项目查看需要查看权限；补算需要编辑权限。全局规则和订阅管理仅限管理员或所有者的用户会话。

## 当前采集范围

| 渠道 | 当前应用入口 | 可用的安全请求计量 |
| --- | --- | --- |
| Grsai | 图片生成 | 调用次数、图片张数 |
| RunningHub | 图片、TTS、H3 视频 | 调用次数、图片张数、指定 TTS 字符数、指定视频时长 |
| Codex CLI | 项目文本生成，包括结构修复重试 | 调用次数；不虚构 Token 数 |

当前已验证的渠道解析器没有可靠的单次实际金额字段，因此实际生成通常需要配置规则后估算，或保留待核算。账本支持实际扣费证据，但这不意味着已自动接入第三方账单。

Codex 默认账户别名 `codex-cli:local` 代表本机凭据槽位，不能识别历史登录用户切换，也不代表免费或已被订阅覆盖。共享订阅金额由管理员维护；缺失金额显示未登记。

在供应商接受请求后，如果成本写入失败，系统保留返回的供应商任务 ID，避免因记账失败重复生成。若随后进程也丢失，部分直接调用无法自动恢复关联，会保留待核对意图，不能声称历史完整。

账本保存在当前节点 `STATE_DIR/local/costs.db`。只持久化费用所需字段，不保存提示词正文、密钥或完整供应商响应。项目数据仍受原有节点归属和项目访问控制保护。

## 手动回填历史提交

回填是显式的本地运维写入，不随启动或打开成本页面自动执行。请在项目所属节点、仓库根目录，使用与应用相同的虚拟环境和环境配置运行；`NOVELVIDEO_STATE_DIR` 必须指向该应用已有的状态目录。CE 使用应用原有的 `ST_EDITION=ce` 配置；EE 保留应用原有的 `ST_CONTROL_PLANE_DSN` 和节点身份配置，不要临时切换版本或指向新的状态目录。

```bash
PYTHONPATH=src .venv/bin/python -m novelvideo.costs.backfill --project '<项目注册表中的稳定项目 ID>'
```

`--project` 只接受注册表中存在的稳定 ID，不接受项目名称、用户名或自行计算的哈希。工具经 `ensure_bootstrap()` 连接现有项目注册表，确认项目属于当前节点，再使用注册表的 `runtime_dir` 和应用的成本账本。它不扫描其他项目目录或媒体文件。命令输出各源的导入、已存在、跳过数量及固定原因代码；失败源不会阻止另一个有效源的处理。

仅支持读取 `runtime_dir/media_h3/tasks.db` 与 `runtime_dir/media_h3_ref/tasks.db`，以 SQLite `mode=ro` 打开，不运行任务库迁移。有效记录必须包含稳定 attempt/task ID、明确的 RunningHub 工作流、账户、远端任务 ID 和带时区的 `submitted_at`。缺失提交时间时不会用文件时间、任务创建时间或输出文件数猜测调用与费用；不支持的数据库结构会产生覆盖缺口。

导入记录保留原始 ID，只记录已证实的调用一次及有效请求时长（如有），用量来源为请求。旧 `cost_json` 不是已验证的扣费证据，因此历史调用首先进入**待核算**，随后可使用成本页的补算预览、确认应用流程。已有实时记录或已计价记录保持原样；重复运行不会重复计费，跨项目身份冲突只报告缺口，不转移归属。账本审计记录使用固定来源标识，不复制提示词、输入、输出、诊断内容或密钥。

即便两份任务库均成功导入，历史仍标记为部分覆盖。旧版 Grsai 直连、TTS、放大和 Codex 调用无法由这些任务库完整重建；已有缺口与更早的覆盖起点会保留。此功能的验证使用临时测试数据，未自动执行生产项目回填。
