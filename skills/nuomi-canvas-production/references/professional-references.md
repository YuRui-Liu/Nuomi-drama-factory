# 专业岗位参考：资产、分镜、表演、声音

外部生产手册的可迁移规则，用于写 brief、panel_spec 与 H3 提示词。它们不是硬性校验，不覆盖用户锁定的事实；与 `canvas capabilities` 或供应商契约冲突时以运行能力为准。

来源：Higgsfield Hell Grind 生产手册、LibTV 视频 Agent、OpenMontage、DramaClaw、Qwen3-TTS、IndexTTS2。完整出处与调研记录见 `docs/research/2026-10-19-professional-agent-external-references.md`。

## 1. 资产（造型师／场景师／道具师）

- 资产 = **文字描述符 + 定版图**。描述符逐字复用，不缩写、不换词。
- 角色定版图：脸部特写 + 正面全身 + 背面全身，**全图只有一张可读的脸**。远景常糊脸时，可把正面全身改成“去头”版本。
- 定版图保持中性：灰底、平光、不烘焙电影感。风格由软件设置与镜头提示词承担。
- 局部变化（衣服、伤、血）在定版图上点改后**用蒙版叠回原图**，不要让整图再过一次模型。
- 场景定版：3/4 视角，留锚点物（柱、灯、沙发），**一套光逻辑**（一个光源、一个投影方向）。
- 每张参考图声明用途：“只取空间与材质，不继承构图、角度与调色”。

## 2. 分镜与空间（分镜导演／执行导演）

每个场景写一份空间图，逐镜原样复用；**只有地标、左右、机位侧、轴线，没有人物与动作**：

```
GEO SPATIAL LAYOUT (locked across every shot):
— PLATFORM = ...（地标与材质）
— PROP-ANCHOR: 相对平台的位置（如 MID-RIGHT）
— ACTION CENTER: CENTER-LEFT, 距离地标约 N 米
— 180° AXIS: 机位始终在 X 侧，不越轴
— LIGHT: 主光来自平台后方，形成轮廓光
```

- 屏幕方向只从机位说：“画面左/画面右”，不写“角色左边”。
- 位置用地标 + 米数表达，不用世界坐标数字。
- 每格写人数头：“画面内恰好 2 人”；计数物件用正向锁（“恰好一个背包”）。
- 每场第一段开头 1 秒宽景：只交代位置，无台词、无动作；宽景不是空镜。

## 3. 表演（表情／动作）

- 情绪用肌肉与身体写：下颌收紧、鼻翼一动、呼吸变浅、手指发颤；不写“愤怒/悲伤”。
- 静止写成“被压住的张力”，不写“所有人不动”。
- 每 1–2 秒一个微事件：呼吸、眨眼、视线移动。
- 反应先于对方台词结束；情绪不瞬间关闭，尾段带入下一镜。
- 手上有活：整理、计数、倒水，边做边说；最强的重音是他因听见而停下的那一刻。
- 内心独白标 `INNER (unspoken)`，永不进声音。

## 4. 台词与声音（编剧／配音师）

- 台词结构固定：**声音与情绪 → 引号台词 → 物理动作 → 面部反应**。
- 台词只出现在音频段；动作段不出现台词。
- 未说话角色写“嘴部静止”，防止模型加台词或含糊声。
- 跨接缝：新段开头带上上一段结尾的台词尾句。
- 混音写清：人声近、环境声在其下、说话时环境声下压。

### 音色设计（Qwen3 VoiceDesign）

由身份、年龄、性格与剧情状态生成自然语言描述：

```
{性别}，{年龄}岁，{音域}，{音色质感}，{共鸣}，{咬字}，{语速}，{口音}，
情绪基线：{基线}；本剧状态：{随剧情变化的限制}。避免：{播音腔/过度甜美/气声}。
```

- 年龄、性别、音域必填；情绪只写“当前状态”，不把场景情绪写死成音色。
- 先设计一段短参考音，再用它建立克隆提示，多句复用（官方推荐：Voice Design → Clone）。

### 克隆表演（IndexTTS2）

- 身份与表演分层：身份层 = 参考音 + 克隆提示；表演层 = 语速（0.9–1.1）与句内停顿。
- 不加强情绪权重：身份优先时强情绪会降低相似度。
- 对白逐字来自剧本，不改写、不截断；超长先挤气口，再 ≤5% 变速，仍不够就请用户决定。

## 5. 迭代纪律

- 一次只改一处，其余逐字不动；每版记录改动与判定。
- 同一镜改 10–15 次仍不成立，问题在镜头设计：拆镜、减动作、换角度，而不是继续重抽。
- 重抽前先查参考图里是否有要排除的元素；模型对参考图忠实、对文字健忘。

## 6. 边界

- 这些是经验规则，不是供应商契约；帧模式、引用上限、时长以 `canvas director capabilities` 为准。
- 用户锁定的事实、对白与资产优先于任何外部经验。
- 不搬运外部案例的剧情、台词或整段提示词；只提炼可迁移方法。
