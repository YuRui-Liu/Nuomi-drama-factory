# 付费生成前把输入准备完整

目标是减少可预防的失败，一次提交完整输入，再复用成功结果。检查不会保证供应商每次都遵守提示词，也不替用户提高验收门槛。局部美术偏差可按用户要求保留；新增人物、提前揭示剧情、关键动作缺失、身份跨镜变化需要如实报告。

## 锁定这次真正要生成的内容

- 读取用户最新的画幅、复用范围、费用授权和并发要求。用户从竖屏改横屏后，检查真实图片尺寸；只修改项目或节点的 `aspectRatio` 不会把已有竖图变成横图。
- 固定每镜的起始状态、动作因果和结束状态，包括谁可见、谁只在画外、物件归属、盖子状态和动物首次出现时刻。每个动作说明“触发 → 可见反应 → 结果”，避免只把一句剧本文字画成静态画面。
- 用现有正式剧本和已采用资产作唯一来源。只复用用户允许的资产；不要从旧项目顺带继承场景、剧情、音轨或人物关系。复用角色身份不等于引用了视频阶段的身份图。

## 各环节付费前的最小证据

| 环节 | 必须看真实输入，而非只看界面选项 |
| --- | --- |
| 角色、场景、道具 | 已采用身份、设计描述、实际引用文件、已解析的风格片段、所选模型真实支持的尺寸档位。不能把 VIP 才支持的 2K 参数交给只支持 1K 的型号。 |
| 360° 场景 | 先完成四壁、门窗、地面、天花和全景投影约定，再提交一次。2:1 尺寸本身不证明是可用全景；按用户用途检查球面，保留用户已接受的局部缺陷。 |
| 分镜图和端点 | 表格与图片同时存在；静帧仅描述确切瞬间，风格字段真实生效；看实际宫格布局再裁切。首尾属于同一机位，起止状态可由一个连续动作到达。 |
| H3 视频 | 外部 typed plan、对应端点 SHA、实际工作流、实际已选身份参考、帧数和最终编译 wire 全部对应同一输入。单独的只读 preview 不能证明组队列已选这些引用。 |
| 独立配音与合成 | 明确采用的音色、对白、环境声分轨和真实片段时长；对白未完成时只能标注为画面预览，不称完整成片。合成使用实测时长，避免按请求时长累积错位。 |

## 逐镜清理提示词

检查完整的最终 wire，而不只是动作段落。共享物理、灯光、质量、人物表演和正向约束同样会诱导画面：未出场的动物不能出现在“保持动物解剖”规则里；闭盖镜头不要带开盖动作规则；背景说明不能悄悄增加人物。只保留本镜需要的约束，避免用大段通用模板掩盖实际动作。

区分手持物清单和画面内道具：没有手持物不等于桌上不能有木匣、铜钱等布景。数量规则必须指明对象和范围，不能把手持物数量编译成全画面道具数量。

局部或手部特写无法凭空提供脸、服装和动物身份。如果中间动作会露出端点未提供的身份，先核对真实引用选择和组合路线；不要期望名称文字替代身份参考。需要身份参考＋首尾帧时，使用支持该组合的已配置工作流。若外部计划入口尚不支持该路线，先修入口，不切回内部 Agent、不用付费抽样来试接口。

画幅改变时先完成构图适配。只有裁切不会丢失关键人物、手部或道具时才复用裁切结果；否则准备目标画幅的端点。禁止拉伸图片凑比例，也不要默认让模型在大幅扩画时自行补全未知人物或空间。

把端点联系表与已采用身份图同屏看一遍，检查跨镜的脸、服装，以及动物的物种、毛色、尾部形态。名称相同不证明图像身份相同。预演可用不代表这些端点已通过身份检查；不能让形象不一致的端点分别约束同一角色，再要求视频模型自行统一。

## 只读预检与提交

按 [video-keyframes.md](video-keyframes.md) 取得当前公开上下文并编写外部计划。执行 `scripts/h3_preflight.py --help`，将当前 context、prepared package、已知角色和目标画幅放进 bundle；需要核对真实图像时提供项目产物根目录。预检只读取文件，不提交任务。它能拦截输入不匹配、明显比例冲突和已知未出场角色混入通用约束，不能替代因果、表演和构图判断。

Bundle 的字段是 `target_aspect_ratio`、`character_names` 和 `groups`。`groups` 每项包含 `context`（公开 GET 响应的 `data`，不含外层 envelope）和 `prepared`（将要提交的完整 `prepared_h3_plans`）。画幅来自用户当前目标，不能从不合格的旧端点反推。运行输出为 JSON；`blockers` 非空时退出码为 1，普通建议留在 `warnings`。把同一份检查结果用于提交准备，不为通过检查改写来源哈希。

预检通过后按组提交一次，记录返回的任务 ID 和供应商任务 ID。并发以运行时生效值为准；本地槽位满且明确未入队时，等空位再提交该组。未知提交结果先查原任务，不能换 request ID 重复发送。不要在付费任务运行时重启服务。

生成后检查整段播放和关键剧情证据，区分文件成功与内容通过。若文件已生成而裁切、投影、分轨或合成失败，先恢复后处理并复用现有媒体。发现内容问题先指出是哪句输入、哪项引用或哪段输出有问题；不自动整集重抽，不增加用户没有要求的审阅点。后续处理遵循用户已有的复用与重新生成授权。

先回写真实媒体 URL 到对应画布节点，再固定 progress 的当前产物哈希。若结果回写导致进度失效，先核对有效任务、媒体字节和实际输入；仅有展示字段变化时重新记录已有产物，不因此重新收费生成。技术产物 ready 不等于内容验收通过，预览也不能把未完成的配音或完整成片阶段标为完成。

交付前从重新打开的画布实际播放结果，确认节点展示的是本次产物而非只在聊天中给出文件。若采用独立配音，静音原混音后仍要接回已分离的环境声；有音频流并不证明有声音，检查实际音量和播放器静音状态。对白未制作或音色未采用时明确标注待配音。不要把静音画面预览作为用户请求的有声成片交付。
