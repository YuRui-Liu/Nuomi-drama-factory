# script-master · 剧本创作总控技能

> **版本**：v3.1 ｜ **更新日期**：2026-08-21
> **定位**：剧本创作流水线的总控编排器，用户侧**唯一交互入口**。
> **核心理念**：把"灵感"稳定推进为"完整可执行剧本"，而不是停在一次性创意回答。

---

## 一、这是什么

一套从**灵感 → 完整可执行剧本**的全链路创作系统。它不是单一工具，而是一个**总控编排层**：判断你当前在哪个创作阶段，自动调用对应的专家能力，管理版本交接与质量迭代，最终产出可直接投拍 / 投流 / 交付的剧本包。

**适用场景**：
- 你只有一个灵感 / 大纲 / 初稿 / 会诊需求 / 台词诊断需求
- 写竖屏短剧、AI微电影、长篇电影、网剧
- 需要把剧本转成 AI 视频可用的导演画面版

---

## 二、九阶段流水线

| 阶段 | 名称 | 产出 |
|------|------|------|
| S0 | 灵感输入 | 明确类型/平台/受众/核心情绪 |
| S1 | 核心信息收集 | 方向卡 |
| S2 | 项目档案生成 | 项目档案 v1.0（角色九维/伏笔表/规则表/大纲判断） |
| S3 | 大纲锁定 | 大纲 v1.0 |
| S4 | 剧本初稿 | 剧本 v1.0 |
| S5 | 圆桌会诊 | 会诊报告 + 修改任务清单 |
| S6 | 结构修订 | 剧本 v2.0 |
| S7 | 台词诊断 | 台词替换清单 + 语言指纹矩阵 |
| S8 | 台词整合 | 剧本 v3.0 |
| S9 | 最终可执行剧本包 | 12 项完整包 |

> 支持**正式模式 / 压测模式**、**自动/半自动/手动三档衔接**、**任意阶段回退**。

## 四、快速开始

直接对总控说话即可，例如：

- **"我有个灵感：外卖员穿越成皇帝"** → 走 S0-S2
- **"帮我写完整剧本"** → 需先补档案+大纲（S1-S3），再进入写作
- **"帮我看看这个剧本"** → 进入 S5 会诊
- **"台词不行"** → 进入 S7 台词诊断
- **"交付给甲方"** → 输出【项目介绍】+【项目剧本】两个净化版文档
- **"画面版 / AI分镜版"** → 输出导演画面版
- **"压测"** → 快速跑通全流程验证

**风格锁**：开写前必须确认语言风格（**标准 / 白描 / 浓烈 / 喜剧**），一旦确认全链路不可擅改。

## 五、核心特性

1. **九阶段流水线**：从灵感到可执行剧本包，版本化推进
2. **五层知识库 + 2 个用户触发库**：规律/技法/台词/打戏/声音/命名/合规
3. **圆桌会诊**：24 评委池按题材动态加载，只诊断不开方
4. **质量飞轮**：P0/P1/P2 问题分级 + 跨集累计追踪，防止质量滑坡
5. **状态快照 + 工作区文件协议**：长项目续集衔接不丢上下文
6. **交付净化模式**：自动隐藏所有创作过程记录和内部术语，输出干净对外文档
7. **导演画面版**：普通剧本 → AI分镜友好的画面版（不改变剧情）
8. **合规预检**：交付/投流前内容安全红线自查（P0/P1/P2）

---

## 六、使用建议

- **短项目（≤5集）**：单会话可跑完，文件协议可选启用
- **中长项目（6-15集）**：建议启用工作区文件协议，避免上下文压力
- **长项目（>15集）**：必须启用快照 + 工作区文件，否则必然上下文丢失
- **续集衔接**：续写时贴"状态快照 + 项目档案"，并让总控读取前文文件
