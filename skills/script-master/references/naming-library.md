# 命名与宣传库（naming-library.md）

> **定位**：剧本总控的用户触发型参考库，与五层知识库平行。解决"剧本写完了，但剧名、集名、slogan、切片标题、发布文案怎么起"的问题。
> **原则**：这里是**公式与机制库**，不是模板库。调用时必须填入本项目题材、核心爽点、目标平台、风格锁，禁止直接套用。剧名/切片标题要能**被传播验证**，起完一批让用户挑，而不是只给一个。
> **边界**：本库做"剧名 / 集名 / slogan / 切片标题 / 发布文案"；不做具体投流策略（那是 douyin-content-operations 的领域），只提供文案侧产出。
> **用户可随时输入**"添加剧名样本"/"更新命名库"蒸馏新爆款剧名规律。

---

## 一、剧名类型库（按机制分）

> 核心机制：一个好剧名 = 让目标受众在 3 秒内**产生一个具体期待**（想看"他/她怎么翻盘/反转/打脸/相爱"），而不是"文艺但空"。
> 判断标准：陌生用户扫过片单，会不会停下来？停下来的那个瞬间，他脑补出的情节是不是你剧里真的有的？

### 1. 身份反差型（短剧最常见，占比最高）
**公式**：`[底层身份] × [隐藏身份]` 或 `[标签反差]`
- 例：外卖员 × 隐藏继承人 / 保洁阿姨 × 首富之女 / 赘婿 × 战神
- 适用：战神、赘婿、逆袭、甜宠（身份反转）
- 变体：`[日常身份]的[隐藏身份]`（例：被开除的保安竟是龙王）

### 2. 动作冲突型（强钩子）
**公式**：`[动作] + [对象]` 或 `[谁]要[做什么]`
- 例：《离婚后我成了全球首富》《重生后我杀疯了》《退婚后我娶了女总裁》
- 适用：逆袭、重生、复仇、打脸

### 3. 悬念/疑问型（勾好奇心）
**公式**：`[反常现象]？` 或 `[身份]的秘密`
- 例：《我的老公是头狼》《她消失的第七天》《全城都在找她》
- 适用：悬疑、甜宠（反差萌）、都市
- 注意：疑问必须指向"具体未解的事"，不能是空泛的"命运的秘密"

### 4. 情绪/关系型（戳共情）
**公式**：`[关系] + [极端情绪]` 或 `[两个人的一句话关系]`
- 例：《你是我的荣耀》《先婚后爱》《前夫求我复婚》
- 适用：甜宠、虐恋、家庭伦理

### 5. 数字/时间型（具体、可量化、有紧迫感）
**公式**：`[数字] + [单位]`（七天/三年/七日后/第99次）
- 例：《七日生死局》《三年后我回来了》《第99次求婚》
- 适用：悬疑、重生、逆袭（倒计时压迫感）

### 6. 地点/世界型（世界观+IP感）
**公式**：`[独特地点/世界] + [人物或事件]`
- 例：《长夜难明》《雪中悍刀行》《大奉打更人》
- 适用：仙侠、武侠、历史、权谋、长篇电影
- 注意：纯地点名对短剧太"淡"，短剧优先身份反差/动作冲突型

### 7. 类型拼贴型（出海/新颖题材）
**公式**：`[类型A] + [类型B]`
- 例：《末日女神》《星际赘婿》《神豪医生》
- 适用：海外市场、题材混搭

## 二、剧名分题材速查

| 题材 | 优先机制 | 反例（太淡） | 正面示例方向 |
|------|---------|------------|------------|
| 战神/赘婿 | 身份反差+动作冲突 | 《我的传奇人生》 | 《战神归来：三个儿子跪求原谅》 |
| 甜宠 | 情绪关系+悬念反差 | 《甜蜜的爱情》 | 《我的男友是只猫》《错把总裁当司机》 |
| 逆袭打脸 | 动作冲突+数字时间 | 《奋斗》 | 《被赶出家门的我成了首富》 |
| 重生 | 数字时间+动作冲突 | 《重活一次》 | 《重回1990：我靠炒股翻盘》 |
| 复仇 | 动作冲突+情绪关系 | 《复仇》 | 《灭我满门，我让她血债血偿》 |
| 悬疑 | 悬念疑问+数字时间 | 《谜案》 | 《死者留下的第七封信》 |
| 都市/职场 | 身份反差+情绪关系 | 《都市生活》 | 《隐婚大佬是保洁》 |
| 仙侠/武侠 | 地点世界+身份反差 | 《修仙之路》 | 《废柴剑神》《魔尊今天也在装死》 |
| 历史/权谋 | 地点世界+动作冲突 | 《历史的天空》 | 《我在大周当奸臣》 |

> 通用规则：**短剧剧名优先"身份反差 + 动作冲突"，8-15 字，口语化，能一句话讲清"这剧爽在哪"**；长篇/电影可更文艺，但要能承载主题。

## 三、集名设计（每集标题）

**核心**：每集标题要写**这一集的"戏眼"**（本集最关键的事件/反转/钩子），不是概括，是"预告片标题"。
**标准**：5-15 字，能勾起"这一集发生了什么"的好奇。

- 好例：第1集《天狼异耀》（点出异常事件）、第3集《身份暴露》
- 弱例：第1集《相遇》、第5集《发展》（太平，无戏眼）

**集名类型**：
1. 事件型：点出本集关键事件（《封印裂隙》《首富归位》）
2. 反转型：点出本集反转（《他不是司机》《原来是她》）
3. 情绪型：点出本集情绪高潮（《她终于哭了》《众叛亲离》）
4. 悬念型：留疑问（《他到底是谁？》）

> 单集剧名建议在**写完整集后**回填（先写剧情再拟名），比先定名更准。

## 四、Slogan / 一句话宣传语

**公式**：`[主角] + [极端处境] + [唯一出口/爽点]`（一句话讲清核心冲突和反转）
- 例：《被赶出家门的我成了首富》→ "所有人等着看我笑话，我转身成了他们高攀不起的人。"
- 例：悬疑剧 → "她听见了旧照片里的声音，也听见了真相的代价。"

**要求**：
1. 必须有**反转或反差**（不能平铺直叙）
2. 有**情绪张力**（爽/虐/怕/燃）
3. 口语化，能被复述（像朋友跟你安利这部剧）
4. 一句话，别超过 40 字

## 五、切片标题钩子（短视频传播）

> 短剧传播主力是**切片**（精彩片段）。切片标题 = 3 秒钩子，决定点击率。

**公式**：`[冲突/悬念/爽点] + [具体信息] + [情绪词]`
- 例：《婆婆当众羞辱她，下一秒她亮出身份全场傻眼》
- 例：《他以为她在哭，结果她在笑——这段我看了十遍》

**切片标题类型**：
1. 反转预告型：先抑后扬，点出"下一秒反转"
2. 悬念留白型：留一个非知道不可的问题
3. 情绪爆发型：直接给最强情绪点（泪/爽/怒）
4. 身份揭露型：隐藏身份揭晓瞬间
5. 互动提问型："如果你是她，你会怎么选？"

**规则**：
- 前 3 秒的钩子要在**前 8-10 个字**内给到冲突/反常
- 可加情绪词（"炸了""绝了""哭死""当场"）但别滥用
- 每个切片标题对应**一个具体画面/台词**，不能泛泛

## 六、发布文案 / 剧集简介

**结构**（150-300 字）：
1. 第一句：核心钩子（用 slogan 或最强反差）
2. 中间：故事引子（主角处境 + 关键冲突，带 1-2 个具体场景）
3. 结尾：引导（"第X集已更新" / "看后续戳主页"）

**规则**：
- 文案要**具体**，带画面感，别堆形容词
- 面向平台算法：关键词要含题材、类型词（方便推荐分发）
- 短剧简介忌剧透关键反转（留钩子）
- 出海项目：简介要本地化，避免中文成语直译

## 七、与总控的衔接

| 触发时机 | 调用内容 |
|---------|---------|
| S1 建档时 | 按题材匹配剧名类型方向（表二），记入项目档案【剧名方向】 |
| S3 大纲锁定后 | 拟 3-5 个候选剧名 + 1 个 slogan 供用户选 |
| S9 最终包 | 回填最终剧名、slogan、分集集名表 |
| 交付模式 | 项目介绍的"剧名/集名/卖点"使用本库产出 |
| 用户触发 | "起剧名"/"拟集名"/"写切片标题"/"写简介" → 加载本库 |
| 导演画面版后 | 可另出切片标题清单（每个切片钩子对应画面） |

> **交付净化**：本库产出的剧名/slogan/集名/简介是**对外成品**，可进入交付文档；但"剧名类型公式""切片标题类型"等机制术语要隐藏，只输出成品文案。
