# 合规与审核红线库（compliance-check.md）

> **定位**：剧本总控的内容安全参考库，解决"剧本写得好但发不出去/投流被拒/被限流"的问题。S5 会诊时加合规评委，S9 交付前做合规预检。
> **原则**：本库是**红线自查清单 + 风险分级机制**，不是创作模板。合规是"底线校验"，不替代创作自由度——在红线内照样能写好戏。
> **边界**：本库做**内容审核红线**（平台可发布的边界）；不做广告法合规（那是 aigc-ad-film-studio 的领域）。出海的**文化敏感度**与本库并行（见第十四部分 14.4 场景三）。
> **重要提醒**：平台审核规则会实时变化，本库是**通用底线基线**，不代表任何平台最新细则。高价值项目/上架前，仍应人工核对目标平台现行《内容安全规范》。用户可随时输入"更新合规库"补充新踩到的红线。

## 一、内容安全总则（跨平台通用底线）

**优先级**：以下红线按"平台硬性封禁风险"排序，P0 = 必改（可能封禁/拒审），P1 = 高风险（限流/下架风险），P2 = 敏感需谨慎。

### P0 硬红线（出现即必改，可能封禁账号/拒审）
1. **违法内容**：涉毒、赌博教学、诈骗、传销、制售假、组织卖淫、恐怖主义、极端行为
2. **血腥暴力过度**：断肢/内脏/大量出血/分尸/虐待的特写呈现（尤其无剧情必要性时）
3. **色情露骨**：露骨性行为、色情擦边（低俗露点、性暗示的直白呈现）
4. **危害未成年人**：未成年人涉性、校园霸凌美化、诱导未成年人不良行为
5. **迷信邪教**：宣扬封建迷信骗财、邪教思想、伪科学治病
6. **危害国家安全**：分裂、颠覆、涉密、损害国家荣誉
7. **违法涉政**：攻击现行体制/政策、敏感历史事件的具体演绎

### P1 高风险（可能限流/下架，需谨慎处理）
1. **血腥但剧情必要**：战争/犯罪/医疗场景——用"结果暗示"替代"过程特写"
2. **擦边**：暧昧/性暗示台词、打擦边球画面（短剧高发区）
3. **价值观问题**：宣扬拜金/不劳而获/以暴制暴且无反思、歧视（地域/性别/职业/民族）
4. **复仇尺度**：私刑正义、以暴制暴的"爽"处理过度（战神/逆袭剧高发）
5. **医疗/法律/金融**：涉及专业领域给出"具体操作"且错误引导
6. **未成年人形象**：未成年角色涉成人剧情

### P2 敏感需谨慎（不违规但要注意分寸）
1. **宗教**：虚构宗教影射现实宗教
2. **历史人物**：真实历史人物丑化/虚构，尤其近现代
3. **社会热点**：蹭真实社会事件/灾难
4. **职业形象**：系统性丑化某个行业/群体（警察/医生/教师）
5. **地域**：地域黑、方言丑化

## 二、分题材红线重点

| 题材 | 高频红线 | 处理建议 |
|------|---------|---------|
| 战神/赘婿/逆袭 | 以暴制暴、私刑、血债血偿、拜金、歧视 | 暴力用"结果"暗示；复仇要有"被逼无奈"的正当性铺垫；别宣扬"钱=一切" |
| 甜宠 | 擦边、性暗示、霸总PUA、未成年感 | 亲密戏留白；"强取豪夺"要逐渐转向尊重；女主不能纯依附 |
| 重生/复仇 | 私刑、违法复仇、极端仇恨 | 复仇要"智取"+"合法边界"意识，或加入"代价"（不能零成本爽到底） |
| 悬疑/犯罪 | 血腥、犯罪细节教学、同情罪犯 | 还原案情用"描述"不用"教程"；罪犯要有落网/代价 |
| 仙侠/玄幻 | 迷信、邪教、伪科学 | 明确"架空世界观"；别套用现实宗教仪轨 |
| 历史/权谋 | 真实历史、历史人物、涉政 | 架空朝代为主；涉及真实历史需考据且不歪曲 |
| 都市/职场 | 行业丑化、职场霸凌美化、拜金 | 平衡正反面形象；霸凌要批判不美化 |
| 家庭伦理 | 重男轻女、家庭暴力美化 | 议题可写但要"批判立场"明确 |

## 三、常见拒审/限流点自查清单（S9 交付前逐项过）

**画面/情节层面**：
- [ ] 有无血腥/暴力特写（断肢、大出血、虐待）？→ 改用暗示/结果
- [ ] 有无擦边/性暗示直白呈现？→ 留白、用反应替代
- [ ] 有无未成年涉成人剧情？→ 调整设定（明确成年）
- [ ] 有无以暴制暴/私刑且无反思？→ 加正当性铺垫或代价
- [ ] 有无宣扬拜金/不劳而获/纯爽无代价？→ 加价值观落点
- [ ] 有无具体犯罪/医疗/金融操作教学？→ 模糊化、不具可操作性

**台词层面**：
- [ ] 有无歧视性用语（地域/性别/职业/民族）？→ 删除
- [ ] 有无露骨性暗示台词？→ 改含蓄
- [ ] 反派台词有无煽动性违法内容？→ 反派坏但不教唆

**题材/设定层面**：
- [ ] 是否影射真实敏感事件/人物？→ 架空化
- [ ] 是否套用现实宗教仪轨/迷信？→ 架空设定、明确虚构
- [ ] 是否系统性丑化某行业/群体？→ 加正面平衡

**出海额外项**（与 14.4 并行）：
- [ ] 目标市场宗教/种族/性别/历史禁忌是否触碰？
- [ ] 价值观是否本地化（如"重男轻女""霸总控制欲"在部分市场敏感）？
- [ ] 有无中文语境梗/成语直译造成误解？

## 四、与总控的衔接

| 触发时机 | 调用内容 |
|---------|---------|
| S1 建档时 | 按题材标记红线重点（表二），记入项目档案【合规红线重点】 |
| S5 圆桌会诊 | 评委池加入"平台审核官"，按表一/表二检查，输出合规风险（P0/P1/P2 并入质量飞轮） |
| S6 修订 | 合规 P0 问题必改；P1 视采纳 |
| S9 最终包 | 运行表三自查清单，输出"合规预检报告"（通过/需调整项） |
| 交付模式 | 合规预检通过后才建议交付；未过则提示先修 |
| 导演画面版 | 检查画面补充是否引入新的血腥/擦边呈现 |
| 用户触发 | "查合规"/"过审检查"/"会不会被封" → 加载本库 |

**质量飞轮对接**：
- 合规 P0 → 硬阻断，必须先修（同现有 P0 机制）
- 合规 P1 连续 2 轮（S5→S7）→ 注入修正指令
- 出海项目：合规 + 文化敏感度 双轨检查

**交付净化**：合规预检报告是**内部文档**，不进入对外交付；只以"已通过合规预检"一句话体现。红线清单/风险分级等机制术语不出现在交付文档。
