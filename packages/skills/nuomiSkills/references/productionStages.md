# 长漫剧制作阶段契约

这是目标制作契约，不是现有功能通过证明。作品以 Toonflow 为基座，由 Agent 加载 Skill 并调用公开业务操作。作品总览关联各集制作画布；画布显示成果和简明状态，工作台编辑同一版本源，资产库管理资产。技术过程写入追溯文件，不要求用户逐步展开。

## 资产与采用规则

- 专属资产库可以复用现有全局素材库，但文件目录管理不等于资产管理。需要作品归属／引用、稳定身份、不可变版本、候选与采用、跨作品固定版本复用。
- 本体知识图谱仅组织人物、人物变体、场景、场景变体、道具、音色及其关系。剧本、镜头和成片通过制作引用关联，不扩入资产本体。
- 已确认具名人物可提前制作基础设计；不据此增造人物。音色按对白需要，场景、道具和变体按已采用内容的实际需要创建。
- 每个新增变体说明原资产为何不足；表情、姿势、视角、切片、一般打光不自动升级为资产变体。不枚举全套服装、年龄、天气。
- 用户对话确认可经公开操作记录，无需再要求用户到界面点击。关键阶段可批量确认，同一批准范围不逐节点重复询问。

## H3 中文对白与精简审阅

- 写 H3 提示词前完整读取官方 Base 或 Ref 指南并按实际模式执行：T2VA 无画面对齐首行；I2VA 首行使用官方 `<Picture 1>` 在 0.00 秒对应 `[Shot 1]` 的完整对齐句；FL2VA 首行明确首图对应 0.00 秒、尾图对应实际有效时长及最终镜头；L2VA 首行明确尾图对应最终镜头与实际有效时长。空行后按 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music` 顺序输出。有效时长取 `effectiveFrames / fps`，尾帧时间保留两位小数，不用请求秒数替代。
- I2VA 首行直接使用官方模板：`For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`；其他首尾帧模式从官方 Base 指南逐字取对应首行并填入真实尾帧时间及镜号，不能用中文概述代替。每个镜头使用 `[Shot N]`，按时间写明动作及转换；没有切镜时不虚构切镜。
- Ref2VA 按 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 顺序输出。逐项定义实际使用的 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 和素材角色，同一标签在各字段中始终指向同一内容；不得编造不存在或当前适配器不支持的素材。描述按 `[Shot N]` 和实际播放时间组织动作、说话人、运镜与场内声音，并保证时间线与有效时长一致。
- 提示词描述使用英文，只保留对白、歌词和画面实际可见文字的原语言。声景描述环境声、动作音及非语言人声；对白和场内音乐放在画面／动作描述中，不重复塞入声景。配乐字段只描述非画内音乐；无配乐使用 `N/A`。不能将“禁止对白”误写为禁止环境声。提交前逐项核对格式、素材标签、对白归属、时间线、音效和配乐，字段顺序通过不等于官方格式通过。
- 先核对当前段的对白来源。没有对白的段落，不插入说话人、发音、口型或保留对白的通用模板；在声景中明确无对白、无旁白，仅描述所需环境音与音效，避免出现互相矛盾的指令。不要因没有对白而禁止所需的环境声和音效。
- 有对白的镜头必须在生成前提供逐字原文，中文写作 `<d>[Chinese] 哥，别开门。</d>`。英文画面描述不代表对白语言；不能仅写「说一句话」，不能同时要求不生成对白。
- 按官方格式在标签外标明稳定说话人 ID、人物身份、语气与动作；对白放在 `integrated_multimodal_description`（参考模式为 `detailed_description`），不放在环境声字段。画外对白明确标注，画面中的听者不跟着张嘴。
- 多人对白逐句写出说话人，不只在段首汇总人物顺序。先依据剧本 `speakerId` 和实际参考图中的位置、衣着等区分人物，分配跨镜稳定的 `(S1)`、`(S2)` 等标识；每句 `<d>` 前紧邻对应人物的身份、标识及发言动作，标签内只放语言和逐字原文。依次标明发言先后、各句的可用时间、停顿及其余可见人物闭口；不同人物的台词不能共用未指明说话人的连续标签。示例：`The person holding the jade slip (S1) says: <d>[Chinese] 原文</d>. The others keep their lips closed.` 仅在剧本确有合声时使用组合说话人标识。
- 先以实际对白时长和镜头时长核对是否容纳发言及停顿；一个连续镜头无法清楚安排多人轮流发言时，保持剧本顺序并拆成每段单一说话人的短镜头，明确每段首尾画面和相邻衔接，不删改台词、不自行增加情节。音色、身份、画内／画外及说话者切换均须与剧本一致；候选提示词按逐句检查后再进入现有方案与授权流程。
- 依据已确认独立配音的实际时长安排句子、停顿及先后顺序，给可见说话人对应的发音动作。原生中文对白用于生成声画关系，后期保留环境声和音效，只替换人声；同一句中文也不能保证两种语速天然口型一致，须按生成对白节奏对齐独立配音。当前首尾帧适配器不接收音频参考，不宣称已具备精确音频驱动口型。
- 每批只做一次提交前核对：素材与模式、台词/语言/说话人、时长和已有授权。自动校验不增加用户确认轮次；已确认的正文、音色和分镜不反复询问。
- 授权批次按账号实际并发额度执行，稳定任务编号查询，默认约 60 秒查询一次；等待期间不反复抽帧、回读全量记录或重复报告同一状态。用户需要的进度仅显示完成数、失败和最终成果。
- 完成后一次技术检查（可解码、时长、音轨、缺失）和一次集中内容审阅。无异常镜头不重复生成联系表、逐镜多轮 QC；仅语言/角色错误、关键动作违背剧情、严重口型错位等问题进入局部检查。轻微瑕疵集中列出，不自动重生。
- 新语言/声音方案先用一个必要的对白镜头验证，再放行同批剩余镜头；复用此次结果作为正式素材，不额外制作无用样片。不把已知缺陷标成通过，不自动重复付费。

依据：[MiniMax 官方 Base 提示词指南](https://huggingface.co/MiniMaxAI/MiniMax-H3/blob/main/docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md)，说话人及对白见 4.4 节。

## 正式验收

先 E1 全链路，再 E2 跨集复用。六集约两分钟是当前作品规模，不是一次性授权制作六集媒体。

E1 要求 Codex 通过公开操作完成：定位作品 → 创作交接 → 完整必要资产 → 全景切片 → 按镜头需要的 3D 导演 → 正式分镜 → 独立配音 → H3 → 合成 → 实际视听与局部返修证据。画布上能看到对应成果和有效引用，工作台可编辑，采用资产可在资产库追溯。

还需证明中断恢复不重复提交、局部返修不重做无关内容。简单镜头的 3D 跳过记录合法，但不能据此声称 3D 操作已验证；缺失路径单列未验证。

旧 E1 的图片、音色、配音和视频任务是早期试制。保留记录和文件，不自动采用、入库或作为正式验收。不得用旧 24 秒试制代替本次约两分钟 E1。
