# H3 生成模式判断

提交前根据镜头目的、实际素材和当前模型能力逐镜选择模式，不能未经判断整批使用同一模式。

| 镜头需求 | 当前 Toonflow 帧模式 | 素材 |
| --- | --- | --- |
| 约束起点，镜头内连续运动 | `endFrameOptional` | 一张图时作为首帧，尾帧可选 |
| 起点和终态都需控制 | `startEndRequired` | 分别提供真实首帧和尾帧 |
| 只约束终态 | `startFrameOptional` | 一张图时作为尾帧，首帧可选 |
| 需要多主体身份参考 | 运行时返回的参考模式 | 按实际槽位提供参考素材 |
| 不使用参考素材 | `text` | 不提供参考图 |

模式名称以运行时 `node:getConfig` 返回值为准；其他适配器可能采用不同命名。首尾帧必须是该镜头对应时点的真实画面，不以相邻镜头的首帧冒充。核对机位、人物和道具状态是否能够连续衔接；需要稳定终态时，不将单首帧冒充首尾帧方案。

有对白时逐句核对剧本原文、语言、说话人及时间窗；无对白时可以写明无对白，同时保留需要的环境声。生成后检查实际画面和声音，不能仅凭格式校验认定结果合格。
