# 写作、对白与证据审稿

## 写一场有效的戏

从进入状态开始，让人物通过行动追求目的。阻力可以来自他人、环境、制度或自身矛盾；不必每场争吵。场景结束应改变信息、关系、权力、风险、行动或情绪理解。安静的相处和余韵也可以有作用，不能仅因没有冲突升级就删除。

尽量从有效动作进入，在本场作用完成后离开。描述可见可听的动作与必要环境，不用抽象心理解释替代表演，也不强制把每个过渡动作拆成流水账。

动作戏写清目的、空间、行动与反应、优势变化和后果；只在涉及打戏时加载相关方法。叙事声音说明来源和作用，不为了“高级感”给每场塞环境声、音乐或额外道具。

## 对白

- 先判断人物在争取、回避、试探、掩饰、安慰还是逼迫，再选措辞。
- 删除已经由动作演清的信息复述；保留必要说明，但避免人物互相讲双方早已知道的背景。
- 潜台词来自人物目的与关系，不要求每句话都隐晦。
- 检查主要人物互换台词是否仍成立；若成立，回到具体身份、关系和策略，而不是批量添加口头禅。
- 碎句、沉默、重复、寒暄和反常反应只有在此人此刻有依据时才用。正常情绪不是错误，简洁有效的对话也不是天然“AI 味”。
- 允许庄重、诗性或类型化语言，服从用户采用的风格，不一律改成现代口语。

## 审稿顺序

先修事实与因果，再修场景，再修对白；不要在主线不成立时只润色词句。

| 检查 | 必须给出的证据 | 常见修复 |
| --- | --- | --- |
| 事实与连续性 | 冲突的两处正文／来源位置 | 修订错误状态，或提出需用户确认的设定变化 |
| 动机与因果 | 人物当前知道什么，哪次选择缺依据 | 补已有动机的表现、调整行动；不临时造秘密 |
| 分集回报 | 承诺位置、实际兑现位置、仍欠什么 | 兑现已有承诺，压缩重复拖延 |
| 转折与伏笔 | 铺垫、揭示、揭示后果的位置 | 调整信息顺序，移除无依据反转 |
| 场景功能与节奏 | 哪场删除后没有损失，哪里动作容量不足 | 合并／删减／调整停顿，不按固定秒表硬切 |
| 人物与对白 | 原句、关系与目的、问题所在 | 定点改写并解释变化，避免全员同声 |
| 制作可读性 | 关键出入场、持物、动作或声源缺口 | 补执行信息；若改变剧情则回编剧阶段确认 |

问题记录格式：严重程度、集／场定位、短引文或精确内容、问题、观众影响、建议、是否改变已确认事实、处置状态。没有正文位置时标为待核实，不能给假引文。

严重程度：

- 阻断：已确认事实冲突、关键动机或因果断裂、漏掉批准的核心事件／对白、无法说明关键谜底或能力来源。修复前不能标为可制作。
- 需修订：重复拖延、回报不足、人物声音趋同、说明过量或场景无作用。展示具体影响，按批准范围修复。
- 创作选择：节奏偏好、开放式结尾、诗性对白等。不能把个人品味强制当成错误。

审稿与写作分开进行：只读正文能否理解，再对照规划看是否兑现。可以换审阅视角，但同一模型的角色扮演不等于独立专家或观众验证。不强制召集多代理，不用多数票或分数替代证据。修订后复查原问题和受影响的邻接场次；未解决项保留。

## 原创对照例（非既定剧情）

薄弱写法：守门人看见归来的妹妹，她说“别开门”，敲门后黑场。它提供异常，却尚未证明人物选择和可持续主线。

改写方向可以提案为：守门人必须在某个已确认的职责和救妹妹之间作选择，妹妹的请求让他的惯常做法失效。必须先明确两边代价、她为何这样请求、后续怎样回应，再写正文。**职责、代价和真相在用户确认前都是提案，不能为修复例子擅自加入真实项目。**

不能以“已有漂亮画面”“模型一次只能生成15秒”“先出片再补剧情”为理由跳过上述问题。
