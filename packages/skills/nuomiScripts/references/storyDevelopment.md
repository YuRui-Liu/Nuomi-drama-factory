# 长线开发与分集

## 事实与范围

优先顺序：用户明确修订 > 已批准的创作事实与改编边界 > 原作事实 > 当前草稿 > 方法库建议。用户修订引发冲突时列出影响，再更新采用版本；不得静默覆盖。改编要保留原作出处（章节／段落或用户材料位置），区分保留、压缩、合并、删改和新增提案。

长原作按真实章节分批读取。记录已读范围、未读范围与材料版本；摘要不能证明原文没有某事，关键身份、谜底、胜负和规则回查原文。输入截断必须明示，不凭书名补剧情。

## 全剧主线

用具体人物和行动回答：

- 谁要得到或守住什么？为什么现在非行动不可？失败会失去什么？
- 对抗方为何合理地阻止他？双方会如何根据对方行动调整策略？
- 主角的惯常办法为何既有效又会制造后果？关系矛盾如何不断产生新选择？
- 每个篇章改变哪些信息、权力、关系、资源、风险或代价？变化怎样成为下一篇章的原因？
- 故事在什么条件下结束？结局如何由前面的选择累积而来？

闭合长篇先论证可持续到结局的冲突，不要求无限续订。单元剧需要可重复但有变化的事件来源；连续剧需要累积后果。两者不可用同一固定“百集公式”评判。

全剧设定只记录制作所需的世界规则、人物动机与关系、不可改项、风格、主线、篇章和结局方向。设定要成为行动限制，不写无人使用的百科。

## 人物

主角和承担核心冲突的人物记录：追求、害怕失去的东西、惯常策略、矛盾与底线、当前知识／误信、关键关系、变化方向。功能角色保持简洁，不强制秘密和成长弧。

人物语言由身份、关系、当下目的与压力决定：同一个人面对上司、亲人、敌人不会始终同一语气。不要只贴“高冷”“腹黑”等标签，给能在剧中表现的行为依据。

文字人物档案可覆盖全剧已确认人物；并不授权全部出图。下游规则：已确认具名人物本体可提前设计，音色首次需要配音时制作；人物变体、场景和关键道具仅按已批准分集的必要性制作。

## 分集地图

每集用一条紧凑记录表达：

| 字段 | 要求 |
| --- | --- |
| 进入状态 | 继承前集已经发生的事实，不重置人物记忆、伤势、关系或持物 |
| 开场吸引力 | 让观众看懂一个具体异常、目标、危险、关系张力或情绪承诺 |
| 当集追求与阻力 | 谁采取行动，对抗来自何处 |
| 因果与转折 | 行动如何改变局面，重大变化的铺垫与代价在哪里 |
| 当集兑现 | 观众本集实际获得什么，不能只写“更悬疑” |
| 退出状态 | 哪些已发生事实必须被下一集继承 |
| 后续期待 | 具体的选择、问题或压力；收束集允许闭合，不硬加新危险 |

不按秒强制钩子，不以固定集数强制高潮。先确认题材、集长和观看体验，再安排节奏。爽、甜、悬疑、悲剧、喜剧、治愈可以采用不同的回报机制。

## 钩子、伏笔与回报

钩子应让观众有理由关心答案，而不只是“不知道”。区分开场吸引力、场内压力、集尾期待，不机械堆叠三套悬念。

伏笔记录只覆盖真的计划回收的内容：首次出现位置、观众能看到什么、相关角色知道或误信什么、计划回应范围、实际回应位置、状态（待埋／已埋／部分兑现／已兑现／修订移除）。

- 转折必须能回看找到依据，不能靠临时补关键证据或新增能力解释。
- 回答一个问题后，应改变人物行动或关系；不把答案换一种问法继续拖。
- 误导要有真实可解释的依据，不能让叙述欺骗已明确呈现的事实。
- 合理巧合可触发困境；不能反复用无铺垫巧合解决核心困境。

## 续写与修订

写下一批前读取全剧采用版本、当前篇章、相关人物、未兑现伏笔、前集退出状态和后续已锁定安排。不要一次读全库，也不要只凭上一轮聊天印象续写。

全局规划可以先完成；正式正文按批准范围分批写。修订要检查已写后续集是否依赖被改事实，列出受影响范围。未获授权不自动重写，不把候选剧情当作已发生事件。
