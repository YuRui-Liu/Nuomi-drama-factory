# 交付、采用与下游交接

## 持久化

先发现宿主现有制作对象、文件和公开工具，复用同一事实源。以下是逻辑产物，不要求为每个字段新建文件或强制改名；已有系统有对应记录就原位维护。禁止为满足模板复制出互相漂移的第二份主剧本。

| 逻辑产物 | 最少内容 |
| --- | --- |
| 创作简报 | 输入来源、原创／改编边界、题材、受众、调性、集数与时长目标、必须／禁止事项 |
| 全剧设定 | 主线、人物关系与动机、规则、篇章、结局方向、采用版本 |
| 分集地图 | 进入状态、追求、阻力、因果转折、回报、退出状态、后续期待 |
| 剧本正文 | 集名、场次、地点与时段、动作、对白、必要声音／画面文字 |
| 连续性记录 | 已建立的角色知识、持物、伤势、关系、伏笔及规则变化；不复制所有正文 |
| 审稿与交接 | 具体问题、处置、采用依据、源版本、下游所需事实与未决项 |

新文件按宿主命名规则。无宿主结构时可使用 brief.md、seriesBible.md、episodeMap.md、episodes/e01/script.md、continuity.md、review.md、handoff.md，按需创建，不生成空模板群。文件操作走宿主公开能力与统一文件入口。

记录稳定集／场标识、源版本与采用状态。修改新增版本，保留原采用稿；用户确认绑定具体版本。草稿、审阅完成、用户已采用、可制作是不同状态，不自动等同。

## 正文样式

```text
# E01 集名
## E01-S01 内／外 · 地点 · 时段
△ 可见动作与必要环境。
人物（必要表演提示）：台词。
[OS] 人物：画外对白。
[VO] 旁白：内容。
[SFX] 具有实际叙事作用的声音。
[画面文字] 必须出现在画面的文字。
```

标签按实际需要使用，不为填满格式添加旁白或音效。正文不混入评分、检查清单、模型提示词、工具日志或内部推理。已有规范稿保留用户格式和语言，除非用户要求统一。

## 时长

剧本时长是估计：分别考虑对白、动作和停顿，不用总字数机械换算。独立配音生成后以下游实际时长复核；若超时，先调整停顿和执行拆分，需要改变对白或事件则回主剧本修订。H3 规划负责每次不超过15秒及模式格式，编剧不伪造已验证视频时长。

## 交接给影视父流程

交接必须包含：

1. 已采用剧本的实际路径／对象引用及版本；范围是哪些集／场。
2. 已确认人物及身份／别名、实际出场场景、必要关键道具、逐句说话人。
3. 不可改事件、对白核心含义、人物关系、规则、伏笔及信息揭示时点。
4. 必须继承的进入／退出状态和有依据的变体需求。
5. 待确认项、未解决审稿问题、时长估计与依据；未知明确标出。
6. 采用确认来源与实际范围，不能把一般制作授权伪写成人工审稿通过。

资产需求只描述必要性和出处，不创建资产图谱实体，不冒充媒体已经生成。人物本体可按全剧确认清单提前设计；人物变体、场景和道具只按已批准分集需要；音色首次配音时制作。瞬时表情、姿态、取景和打光不是新增资产变体。

下游导演可补不改变叙事的执行细节；涉及新增人物／规则、改变动机、胜负、关键证据、对白含义或观众获知真相的时点，必须回编剧阶段处理。主剧本更新后标记关联分镜和片段待复核，不自动重做全部媒体。

## 交付结论

有阻断问题：列出具体范围，交付为待修订稿。
审稿完成但未获用户采用：交付为待确认稿。
问题已处理且用户采用确切版本：交付该范围为可进入制作的剧本。

以上均不能表述为成片完成、观众留存验证、爆款保证或整个影视管线验收通过。
