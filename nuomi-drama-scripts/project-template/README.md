# Nuomi-script 红果漫剧项目模板

这是一个不含具体故事的初始化模板。

## 使用方式

1. 复制整个 project-template 为具体剧名目录。
2. 先填写 project.yaml、项目简报、来源台账和版权台账。
3. 完成选题确认后，再填写立意、大纲、剧本圣经和节拍表。
4. 通过节拍闸门后，先写覆盖开篇、关系冲突、情绪回报的样稿，使用 reviews/craft/样稿审查.md 记录证据与用户读样反馈。
5. 样稿校准后逐集写作、语言编辑和复审。用户明确要求跳过时记录理由，不伪造通过状态。
6. 首交完成后执行创作、连续性、合规和按需 DOCX 交付验收。

## 目录约定

- manuscript 是唯一稿件源。
- reviews 记录阻断原因和人工确认。
- sources 记录平台规则与版权证据。
- templates 记录 DOCX 排版画像与可选创作工作卡，卡片不进入正文。
- deliverables 只存可重建的交付文件。

模板中的 30 集、80 集和 300 字均为项目默认配置或内部质量指标，不是红果公开统一规则。

旧项目不必迁移 schema。可选 craft_calibration 只是人工流程记录，导出器不强制执行；缺少记录时读取 reviews，不能推定已校准。改稿先分析影响，候选稿另存，保护已确认事实。
