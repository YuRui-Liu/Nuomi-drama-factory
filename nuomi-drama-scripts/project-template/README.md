# Nuomi-script 红果漫剧项目模板

这是一个不含具体故事的初始化模板。

## 使用方式

1. 复制整个 project-template 为具体剧名目录。
2. 先填写 project.yaml、项目简报、来源台账和版权台账。
3. 完成选题确认后，再填写立意、大纲、剧本圣经和节拍表。
4. 通过闸门后，将 E001.md 复制为对应集数并逐集写作。
5. 30 集完成后执行结构、连续性、合规和 DOCX 交付验收。

## 目录约定

- manuscript 是唯一稿件源。
- reviews 记录阻断原因和人工确认。
- sources 记录平台规则与版权证据。
- templates 记录 DOCX 排版画像。
- deliverables 只存可重建的交付文件。

模板中的 30 集、80 集和 300 字均为项目默认配置或内部质量指标，不是红果公开统一规则。
