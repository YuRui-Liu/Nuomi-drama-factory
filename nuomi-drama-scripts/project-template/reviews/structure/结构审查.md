## 检查项

- [ ] 主角目标明确且持续。
- [ ] 每集有人物选择、推进和具体回报，中间集有后续期待，终集允许收束。
- [ ] 主线、人物线、情感/悬疑线有独立推进。
- [ ] 冲突不是连续重复同一误会。
- [ ] 角色做出选择，而不是被旁白推动。
- [ ] 首交末集有阶段性回报；若已是全剧终，不强开扩写接口。
- [ ] 关键场景有利益与策略变化；余波/静观按情绪作用判断，不强求每场不可逆。
- [ ] 对白能体现人物和关系，未用作者道理替代戏。
- [ ] 创作判断引用正文证据，与连续性、格式和交付结论分开。
