# 漫剧剧本工艺

输入：单集节拍、圣经、人物状态、场景表、时长和交付协议。先想清人物正在做什么，再把它写成可见行动和可开口的对白。

## 重要戏剧场景的写法

1. 明确谁现在要从谁那里得到什么，以及对方为什么不给。阻力也可以来自环境或人物自身。
2. 给角色一次具体尝试：藏东西、拖延、换条件、激将、求助、动手做事。不要只用双方轮流发表观点。
3. 让尝试遇到反应。碰壁后角色换一种办法，暴露更多代价或私心；策略变化须符合已知信息。
4. 让结尾留下可辨认的差别：谁答应了、拒绝了、发现了什么，谁必须承担后果。变化可以很小，不必每场不可逆。
5. 回看因果：若删掉角色的选择，事件还会原样发生吗？若会，检查主角是否只是旁观导游。

只在难写或关键场景使用 `project-template/templates/scene-card.md`。卡片是工作材料，不进入交付正文。

## 安静场景、过渡与余波

不强求议程碰撞、反转或新的灾难。确认场景使观众看见了什么具体的感情或关系：一个人仍摆两副碗筷，另一个人收起多余的筷子又放回去。关系可以暂时不变，但观众的理解或感受应有依据。

若删去场景不影响空间理解、关系体验或情绪余波，再考虑合并。不要以“缺不可逆变化”否决所有安静片段，也不要用留白为无内容的重复辩护。

## 动作与信息

- 写人物可做、观众可见的行为。用拿起又放下的东西、距离、打断的日常习惯承载感情，不解释“他终于懂得了”。
- 画面已说明的事不再让人物复述，除非复述正在安慰、欺骗或改变对方。
- 交代空间和动作因果，特别是救援、道具转手、伤势和出入。不要为了短而让人瞬移、让物体失去来处。
- 字符数和场次数不能代替戏。时间是拍摄/表演目标；未经朗读或排练不宣称精确计时。
- 保留剧本场景、人物行、动作、对白和必要音效；不写出图或视频 prompt。

## 失败后的返工位置

| 症状 | 回到哪里 |
|---|---|
| 大家都很有道理，立即同意 | 人物利益、拒绝理由和交换代价 |
| 台词换个人也成立 | `character-and-dialogue.md` 的关系和声音检查 |
| 三场都在问问题、讲答案 | 让一项信息迫使人物行动或改变策略 |
| 正文解释作者没有违反设定 | `language-editing.md`；约束说明移到审查 |
| 危机忽然发生 | 查节拍中的因果与预埋条件 |

缺场景/人物行、编号错误属于格式问题；行为因果断裂或关键冲突靠违反设定解决属于必须返工的创作问题。两者分别记录。
