# 语言编辑：去掉替人物说话的作者

在场景因果与对白初稿完成后执行。不通过替换标点判断或承诺“去 AI 化”；先处理空泛、重复、解释和不合语境。

## 按功能修改

| 症状 | 弱句 | 修改方向及边界 |
|---|---|---|
| 作者总结情绪 | 他终于懂得，真正的爱是放手。 | 写他松开行李带，侧身让路。主题留给观众理解，不把每个情感都改成“松手”。 |
| 向审稿者解释禁用设定 | 她没有施展神力让死者复活。 | 删去不存在的动作；写她折好死者的衣服。能力边界记录在圣经/审查。 |
| 动作被台词重复 | 门锁着。他说：“门锁着，我们进不去。” | 若目标是让同伴另找入口，可写“窗户呢？”；若故意拖延，重复可能有效。 |
| 工整宣言 | 我要守护的不是规则，而是人心。 | 回到他正在阻止或索取的事，例如“把门打开，我爹还在里面。”措辞须符合人物。 |
| 虚假悬念 | 他打开信，瞳孔骤缩：“难道你就是——” | 呈现信中足够的信息及具体后果，不任意藏住人物已知事实。 |
| 空泛表演提示 | 她露出复杂而意味深长的微笑。 | 写她要掩饰什么及可见行为；不能演清时删去形容词。 |

## 标点与否定句

- 真实打断可以保留：“我去叫爹——”随后想起父亲已不在。断点必须有动作或情境依据。
- 犹豫可以用省略号，也可以通过换词、避开问题或动作表达；不要三种方法同时叠加。
- “不用再热水了”改变现场行动并传达死亡，可以保留。“大家没有因此忘记悲伤”只是替观众解释，应检查删除。
- “他没接那把钥匙”是可见拒绝，不属于无效否定。判断依据是本句是否带来信息、行动或情绪，不是有没有“没有”“不是”。

## 一次编辑的步骤

1. 标出作者解释、设定说明、信息重复和假停顿；先不改事实。
2. 对每处写明本句要完成的功能。没有功能则删；有功能则用符合角色的行动或语言重写。
3. 连读整场，检查删改后是否丢了因果、时空或必要信息，是否把不同角色都改成短促狠话。
4. 查相邻场景，避免同一道具动作、否定句式或结尾停顿连续复用。
5. 按既有交付协议检查格式。编辑理由写到 reviews，不夹进正文。

若语言问题源自角色没目标或场景没阻力，回到人物与场景重写，不只做同义词替换。不得以“破折号为零”或“台词全短句”作为质量通过条件。
