# 剧本审查量规

输入：简报、圣经、节拍、单集正文、相邻集、已确认 reviews 与来源记录。先读实际场景，再看作者填写的目标，防止把意图当效果。

## 证据审查

| 维度 | 必须回答的问题 | 返工证据 |
|---|---|---|
| 人物 | 他为自己要什么，选择付出什么？ | 只有使命宣言，实际事件与他的行为无关 |
| 场景 | 谁阻止谁，碰壁后怎样换办法？ | 数场都在报告结论，利益冲突一句正确道理就消失 |
| 关系/对白 | 这两个人为何这样对彼此说话？ | 关键台词可任意互换，人人同样工整、全知 |
| 回报/期待 | 观众本集得到什么，还关心什么？ | 钩子无因果或连续拖欠回报 |
| 语言/表演 | 信息与感情能通过动作、声音呈现吗？ | 作者说明代替表演，画面信息反复解释 |
| 连续性 | 信息、道具、时间、能力是否成立？ | 用新能力或角色突然知道秘密解决冲突 |

安静场景按情绪、空间和关系作用评价，不要求每场不可逆变化。终集收束不判缺钩子。不要为了填问题数否定有效场景；同时指出值得保护的原句或动作。

## 意见格式

每条写：集号/场次及原句 → 对理解或情绪的影响 → 修改要求 → 受影响文件/后续集 → 复核证据与状态。泛评“更有灵魂”“加强冲突”不能单独作为可执行意见。

无项目的片段用段落与原句定位，后续集和文件可标“不适用”；按请求范围评审，不要求建立整剧。

示例：某场甲乙先后说“必须查清真相”，职业和关系没有进入对话，无法辨认说话者；让甲追问明早供货、乙阻止在孩子面前指控，保留失窃未查明的事实；复核人物表、该场和下一场调查。

## 分级与结论

- P0：关键事实、权利或因果存在根本冲突，阻断相关交付，先定位冲突来源。
- P1：核心人物动机不成立、关键冲突被说明代替、回报未兑现或关键对白同声；返回人物/场景/语言模块返工，复审受影响集。
- P2：局部措辞、节奏或动作可改善，不因个人偏好升级为阻断。

分别记录 `craft_status`、`continuity_status`、`format_status`、`delivery_status`。格式与渲染不能抵消创作 P1；创作改善也不能抵消连续性或权利问题。

创作样稿的 `craft_status` 使用 draft / needs_review / passed。编写者自审不能代替用户读样校准；无确认记录时保持 needs_review。用户要求继续则记录例外，不改为 passed。其他审查维度按各自证据判定。

## 审查身份与交付

明确是编写者自审、独立编辑/子代理检查还是用户反馈。评分如果使用，必须附证据；不靠总分冲抵严重问题，不声称预测留存或专业认证。审查者不直接覆盖正文，候选改写另存。

P0/P1 未解决、rights_blocked、必要来源缺失或导入契约失败时不得给出整体 ready。DOCX/PDF 交付另需结构与渲染证据；仅 Markdown 不要求无关的渲染流程。复审说明哪些问题消失、哪些仍需用户判断。
