## 模型选型调研：混元 Hy4 preview vs DeepSeek V4.1 Flash
- 混元 Hy4 preview（2026-08-28，Apache 2.0）：MoE 770B 总参 / 49B 激活，78 层，256 路由专家，1M 上下文，**纯文本（无视觉）**，内置 MTP 推测解码层。官方 API ¥6/M 输入、¥18/M 输出、缓存命中 ¥0.3/M。官方自认短板：复杂任务推理偏久、过度自我验证。
- DeepSeek V4.1 Flash（2026-09-10，MIT）：CED 架构 40 层（20 编码+20 解码），骨干 552B + Engram 196B，输入激活 ~8B / 输出 ~16B，1M 上下文、输出上限 384K，**原生图文输入**（DeepSeek-ViT）。KV Cache ~890B/token。API 名 `deepseek-flash`，闲时 ¥1/M 输入（未命中）、¥0.02/M 命中、¥4/M 输出，高峰翻倍。
- 结论倾向：Flash 在代码/Agent/工具调用/成本/速度上占优且带视觉；Hy4 在推理/数学/HLE 上占优且可私有化。若流水线需要理解参考图/分镜图或批量跑量 → Flash；若剧本长文推理 + 数据不出内网 → Hy4。
- 注意：网上二手评测互相打架（同一 Terminal-Bench 2.1 分数在不同来源差异很大），选型时以自测为准，不要采信单一榜单。
